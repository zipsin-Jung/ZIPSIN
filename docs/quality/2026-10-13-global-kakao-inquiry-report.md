# 전역 카카오톡 문의 품질검수

날짜: 2026-10-13
대상: `REQ-SUPPORT-KAKAO-001`
결론: Preview 반영 가능, Production 배포는 사용자 별도 승인 필요

## 검수 결과

| 항목 | 결과 | 근거 |
|---|---|---|
| 전 화면 노출 | 통과 | 루트 레이아웃 단일 렌더 테스트 |
| 공식 채팅 주소 | 통과 | HTTPS 주소와 새 창 속성 단위 테스트 |
| 외부 링크 보안 | 통과 | `noopener noreferrer external`, referrer 차단 |
| 모바일 터치 크기 | 통과 | 최소 56×56px |
| 하단 메뉴 비가림 | 통과 | 모바일 하단 5rem+safe-area 확보 |
| 반응형 | 통과 | 320·390·768·1440px 브라우저 검사 |
| 키보드 접근 | 통과 | 포커스 가능, 명확한 새 창 접근성 이름 |
| 자동 접근성 검사 | 통과 | 네 해상도 axe 위반 0건 |
| 개인정보 경계 | 통과 | URL에 식별정보 없음, 고객지원 안내 표시 |
| 권한 경계 | 통과 | 외부 링크가 집·계약 권한을 생성하지 않음 |

전체 E2E 회귀검사는 20개 통과·9개 운영 계정 미준비로 제외됐다. 병렬 실행 중 `ERR_NETWORK_IO_SUSPENDED`가 난 기존 시나리오 2개는 한 작업자 순차 재실행에서 관련 3개 테스트가 모두 통과해 기능 실패가 아님을 확인했다.

Vercel Preview의 인증된 `/home`에서 `빠른 고객지원` 영역과 `카카오톡으로 집신 대표에게 문의하기 (새 창)` 링크가 공식 채팅 주소로 노출되는 것을 확인했다.

## 제한사항

- 카카오 서비스 장애와 응답 가능 시간은 집신이 보장하지 않는다.
- 카카오 대화는 집신 기록에 자동 저장되지 않는다.
- 실제 운영 환경에서 채널 관리자 수신 여부는 Preview 반영 뒤 대표 계정으로 한 번 확인한다.

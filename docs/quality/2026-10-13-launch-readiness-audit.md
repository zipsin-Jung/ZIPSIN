# 집신 정식 출시 준비도 긴급 검수

> 2026-10-13 추가 확인: 담당 배정 없는 사무소 집 권한은 로컬에서 구현·검증했다. 다만 `codex/public-v1-auth` 원격 Preview는 예전 랜딩 빌드라 최신 가입·로그인·`/home` 왕복은 아직 미검증이다. 전체 판정은 계속 FAIL이다.

- 일자: 2026-10-13
- 검수 대상: `codex/public-v1-auth` 로컬 최신 커밋과 미커밋 메인 홈 변경
- 판정: **실패 — 정식 출시 또는 배포 승인 불가**

## 결론

현재 코드는 인증·사무소·집·기록·첨부의 일부 기반을 가지고 있지만, 정식 출시 가능한 하나의 제품 흐름으로 연결되지 않았다. 특히 최신 제품 결정과 기존 담당 배정 코드가 충돌하고, 집신 챗과 관계자 연결이 구현되지 않았으며, 실제 Supabase가 연결된 브라우저 시나리오 증거가 없다.

## 출시 차단 결함

### P1-01 제품 권한 모델 충돌

- 기대: 채팅과 공식 사용자 흐름에 별도 담당자 개념을 사용하지 않는다.
- 실제: 집 상세, 초대 문구, 담당자 관리 경로와 기존 명세 일부가 담당 배정을 전제로 한다.
- 영향: 대표·직원·임대인·임차인의 접근 기준을 사용자가 이해할 수 없고 구현 권한도 서로 달라질 수 있다.
- 조치: 기존 코드를 삭제하지 말고 노출을 중단한 뒤 소속·계약·방 초대 기준으로 권한 문서와 화면을 통일한다.

### P1-02 핵심 집신 챗 미구현

- 기대: 개인·단체·집·사무소·수리·집신 고객지원 대화.
- 실제: 명세만 존재하며 방, 메시지, 첨부, 읽음, 차단, 신고, 공식 고객지원이 구현되지 않았다.
- 영향: 사용자가 요구한 핵심 서비스 가치가 동작하지 않는다.

2026-10-13 로컬 후속: 공통 메시지 저장, 활성 참여자 검사, 20회 중복 재시도 방지, 사용자별 읽음 위치, 개인정보 없는 알림 기반을 구현했다. 방 종류·방 생성·초대·채팅 UI·첨부·실시간·차단·신고·고객지원은 아직 남아 있으므로 P1-02는 계속 열어 둔다.

추가 후속: 여섯 방 유형과 채팅 목록·대화·오프라인 초안·비공개 첨부·실시간 재조회 코드를 구현했다. 차단·신고·공식 고객지원 안전장치와 최신 Preview의 실제 다계정·반응형·키보드 검수는 남아 있으므로 P1-02와 전체 FAIL 판정은 유지한다.

추가 후속: 개인방 차단, 메시지 신고, 위조 방지 공식 신원, 대표 한 명의 지원 권한, 사용자별 지원방과 지원 UI까지 로컬 구현했다. 지원 대표 계정 연결, 최신 migration 적용, 일반방 열람 거부를 포함한 실제 Preview 다계정 검증 전까지 전체 FAIL 판정은 유지한다.

### P1-03 실제 가입·로그인·업무 왕복 미검증

- 기대: 가입부터 로그인, 사무소·집·기록까지 실제 Preview에서 완료.
- 실제: 로컬 작업 폴더에는 실제 Supabase 설정이 없고, 이번 검수는 로그인 화면 표시만 확인했다.
- 영향: 빌드가 통과해도 사용자가 실제로 가입하고 사용할 수 있다는 증거가 없다.

### P1-04 임대인·임차인·수리기사 연결 미완성

- 기대: 역할별 초대와 종료, 이전 계약 차단, 수리방 제한 접근.
- 2026-10-13 로컬 조치: 현재 계약 임대인·임차인과 기간 제한 수리기사의 초대·수락·종료 RPC와 화면을 구현했다. 초대 전 개인정보 비공개, 토큰 해시, 일회성 소비, 이전 계약 차단, 감사 기록을 자동 검사했다.
- 남은 검증: Preview DB에 migration을 적용한 뒤 실제 다계정·동시 수락·계약 종료·수리 만료·브라우저 시나리오를 확인해야 한다.
- 판정: 로컬 구현 완료, 외부 검증 전까지 출시 차단 상태 유지.

## 주요 P2 결함

- `/about`에는 체험, 데모, 가상 수치, 예상 요금과 작동하지 않는 기능 표현이 남아 있다.
- 일부 로그인 제공자는 실제 설정 여부에 따라 준비 중이며 실제 OAuth 왕복 증거가 없다.
- 현재 메인 홈은 자동 테스트와 빌드만 통과했으며 인증된 브라우저 시각 검수가 없다.
- 첨부파일 부분 실패 복구와 실제 Storage 검증이 남아 있다.
- 최신 변경 기준의 네 커버리지 지표 80% 증거가 아직 없다.

## 금지

- 빌드 성공을 출시 준비 완료라고 표현하지 않는다.
- 작동하지 않는 메뉴나 가상 성과 수치를 실제 서비스 첫 화면에 노출하지 않는다.
- Preview 증거 없이 실제 가입·채팅·파일 공유가 된다고 말하지 않는다.
- 기존 기록이나 migration을 삭제해 방향 충돌을 숨기지 않는다.

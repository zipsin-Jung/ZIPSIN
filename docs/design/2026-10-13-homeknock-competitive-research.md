# 홈노크 심층 경쟁 분석과 집신 적용안

- 작성일: 2026-10-13
- 조사 대상: 홈노크 공식 홈페이지, 임대료 자동수납, 세금계산기, 공식 이용약관, 하나은행 제휴 안내
- 목적: 홈노크를 복제하지 않고, 신뢰를 만드는 구조를 배워 집신의 독자적 제품 전략을 정한다.

## 1. 한 줄 결론

**홈노크가 ‘집을 자산으로 관리’한다면, 집신은 ‘집에서 일어난 일을 기록하고 함께 처리’한다.**

홈노크는 확실한 경쟁사이지만 집신과 완전히 같은 제품은 아니다. 집신이 홈노크처럼 자산·세금·시세·수납을 하려 하면 무료이고 제휴를 갖춘 기존 서비스와 직접 경쟁하게 된다.

집신의 독자적 자리는 다음이다.

- 사진·문서·일정·채팅이 `집 한 채`에 연결된다.
- 임차인·임대인·공인중개사가 같은 사건의 진행을 본다.
- 사람의 권한은 끝나도 집과 사무소의 업무 기록은 남는다.
- 이전 계약자의 개인정보는 다음 계약자에게 자동으로 넘어가지 않는다.

## 2. 확인된 사실

### 홈노크의 공개 포지셔닝

공식 홈페이지는 홈노크를 부동산 자산가를 위한 통합 자산·임대 관리 서비스로 보여준다.

- 부동산 자산 모아보기
- 등기부등본 열람
- 임대차 계약서 보관과 공실 현황
- 임대료 자동수납·미납 알림
- 실거래가·예측시세·자산 분석
- 부동산 갈아타기
- 취득세·양도소득세·증여세·보유세 계산
- 정책·시장·절세 콘텐츠

임대료 자동수납은 공식 안내상 무료이며, 호실별 전용 계좌, 입금 확인, 지연·미납 알림, 초과·부족분 정산, 임대차 계약서 보관을 안내한다.

공식 웹사이트는 **2023년 12월 가입자 기준**이라고 표시하며 다음 수치를 게시한다.

- 부동산 보유 회원: 110,000명+
- 등록 자산: 145,000건+
- 관리 자산 규모: 75조 6,000억원+

> 이 수치는 홈노크가 공개한 자체 집계이며 기준일이 지난 자료다. 현재 실적으로 재해석하지 않는다.

### 가입과 인증에서 확인된 범위

- 공식 약관에는 휴대전화 또는 실명 본인인증을 요청할 수 있다고 나와 있다.
- 하나은행의 2023년 제휴 안내에는 `홈노크 앱에서 임대인 인증 → 자동수납 신청 → 임차인에게 계좌 안내 → 임대료 수납`이라는 순서가 나와 있다.
- 공개 웹페이지만으로는 자산 소유 확인, 가족 자산 추가, 계약서 인증의 세부 예외 처리까지 검증할 수 없다.

## 3. 홈노크가 잘하는 일

### 3.1 부동산 서비스임을 즉시 보여준다

부동산 실사 영상, 자산 규모 수치, 건물과 계약서를 형상화한 3D 비주얼을 이어붙여 산업을 오래 추론하지 않게 한다.

### 3.2 기능이 아니라 이득을 제목으로 쓴다

- `흘어져 있는 부동산 자산 찾기`
- `임대 계약 현황을 한눈에`
- `알아서 챙겨주는 월세 관리`
- `올해 내야 할 부동산 세금은 얼마일까?`

사용자는 기능명을 해석하지 않고도 얻는 결과를 이해한다.

### 3.3 신뢰를 객관적인 모양으로 보여준다

회원·자산·규모 수치, 제휴 은행, 주소·사업자번호·약관·개인정보처리방침, 명확한 무료 표시를 함께 사용한다.

### 3.4 무료 핵심기능으로 진입을 낮춘다

임대료 자동수납을 `0원`으로 명확히 제시한다. 다만 홈노크 전체의 수익 구조는 공개 페이지만으로 단정할 수 없다.

## 4. 집신과 홈노크의 차이

| 기준 | 홈노크의 공개 중심 | 집신의 중심 |
|---|---|---|
| 첫 고객 | 부동산 보유자·임대인 | 초기 결제는 공인중개사무소, 사용은 임대인·임차인까지 |
| 주요 단위 | 자산·임대차 계약·임대료 | 집·계약·사건·사무소 업무 |
| 핵심 문제 | 자산 현황·시세·세금·수납 | 사진·문서·대화·일정 분산과 업무 단절 |
| 협업 | 공개 페이지에서 다자간 사건 협업이 중심으로 보이지 않음 | 임대인·임차인·공인중개사의 같은 기록 확인 |
| 기록 | 계약 정보·계약서·수납 정보 | 입주 사진, 수리 전·중·후, 채팅, 일정, 문서 |
| 권한 | 공개 페이지만으로 상세 확인 불가 | 역할 + 집·계약·사무소 관계 + 기간·조건 |
| 자료 연속성 | 임대인의 자산 관리 중심 | 사람이 바뀌어도 집과 사무소에 업무 기록 유지 |
| 가격 | 공개된 자동수납·세금계산기 무료 | 공인중개사무소 유료 가격 검증 |

## 5. 가장 위험한 경쟁 지점

1. **브랜드 선점:** 홈노크는 자산·임대·수납·세금을 한 브랜드로 묶었다. 집신이 `부동산 관리의 모든 것`처럼 말하면 비교 우위가 사라진다.
2. **무료 수납:** 집신이 임대료 수납을 핵신 가치로 내세우면 무료·은행 제휴를 갖춘 서비스와 붙게 된다.
3. **데이터 연결 기대:** 홈노크는 가입만으로 자산을 모아본다는 경험을 제시한다. 집신은 `한 번 기록하면 다시 설명하지 않음`으로 수동 등록의 보상을 분명하게 보여줘야 한다.

## 6. 홈노크에서 배워 집신에 적용할 것

1. **첫 화면에서 산업과 이득을 즉시 알려주기**
   - `사진·문서·대화·일정을 집 한 채에.`
2. **기능명 대신 사용자가 얻는 결과를 제목으로 쓰기**
   - `수리 기록 관리` 대신 `전·중·후를 모두 보니 다시 설명할 필요가 없어요.`
3. **실제 제품 화면으로 증명하기**
   - 허구 대시보드가 아니라 실제 집 타임라인·채팅·사진·권한 화면을 보여준다.
4. **신뢰 재료를 누락하지 않기**
   - 개인정보 원칙, 권한 종료, 기록 보관 원칙, 회사 정보, 고객지원을 보여준다.
5. **개별 서비스 설명 페이지 만들기**
   - `집 기록`, `집 채팅`, `초대와 권한`, `사무소 협업`을 각각 실제 사용 장면으로 설명한다.

### 절대 복제하지 않을 것

- 홈노크의 문구·이미지·3D 그래픽·색상·배치·애니메이션
- 홈노크의 자산 자동 발견 경험을 집신에서 구현했다고 표현하는 것
- 공개된 수치를 집신의 성과처럼 사용하는 것
- 수납·세금·시세를 집신의 핵심으로 넣어 정체성을 흐리는 것
- 실제 동작하지 않는 기능을 이미 쓸 수 있는 것처럼 표현하는 것

## 7. 집신의 경쟁 자리

### 홈노크가 먼저 차지한 자리

> 내 부동산 자산을 한눈에 보고 임대료·시세·세금을 관리한다.

### 집신이 차지할 자리

> 집에서 일어난 일을 한번 남기고, 필요한 사람들이 같은 기록으로 이어서 처리한다.

## 8. 토스·문토·홈노크를 결합한 집신 홈 방향

| 참고 | 배울 요소 | 집신 적용 |
|---|---|---|
| 토스 | 한 화면 한 결과, 실사+실제 UI, 안전성의 구체적 증명 | 긴 글을 줄이고 사용 장면으로 보여줌 |
| 문토 | 따뜻한 생활 사진과 친근한 감정 | 한국의 실제 집과 사람이 있는 장면 |
| 홈노크 | 부동산 산업 신뢰, 이득 중심 제목, 수치·약관·회사 정보 | 집 기록의 실제 제품성과 운영 신뢰를 보강 |

최종 톤은 **홈노크의 부동산 신뢰 + 토스의 제품 설명 + 문토의 생활 온기**다. 화면과 문구는 집신의 자산으로 새로 만든다.

## 9. 권장 홈화면 6장면

1. **집의 살아 있는 순간**
   - `집에서 있었던 일, 이제 집에 남겨두세요.`
   - 따뜻한 실사 + 집 타임라인 UI
2. **흘어진 기록의 합류**
   - 사진첩·카카오톡·서류첩·달력이 집 하나의 실제 타임라인으로 정리
3. **한 번의 기록, 세 사람의 같은 확인**
   - 임차인의 요청 → 공인중개사의 확인 → 임대인의 진행 확인
4. **전·중·후가 남는 수리**
   - 수리 매칭이 아니라 과정·영수증·대화를 같은 사건으로 표현
5. **집의 기록과 사람의 권한 분리**
   - 주소만으로 열람 불가, 초대·관계·기간으로 접근
6. **실제 시작**
   - `내 집 기록 시작하기` / `사무소로 시작하기`
   - 사전가입이 아니라 실제 회원가입과 로그인으로 연결

## 10. 제품 우선순위에 주는 결론

### 지금 반드시 잘 만들 것

1. 실제 회원가입·로그인
2. 집 등록과 사무소 집 추가
3. 집 타임라인에 사진·문서·메모 업로드
4. 집 기준 채팅과 첨부
5. 사무소 구성원·임대인·임차인 초대
6. 역할·관계·기간에 따른 권한 종료
7. 다음 할 일과 일정

### 지금 따라가지 말 것

- 시세 예측
- 자산 자동 불러오기
- 세금계산기
- 임대료 자동수납
- 등기부등본 열람
- 부동산 투자 콘텐츠

## 11. 아직 확인해야 하는 것

- 홈노크 앱 안의 최신 실제 업로드·공유·권한 기능
- 공인중개사무소용 계정과 조직 기능 유무
- 임대인 인증과 자산 확인의 최신 실제 절차
- 무료 서비스 외 제휴·유료 상품의 최신 수익 구조
- 앱에 집 기준 다자간 채팅이 있는지

이 항목은 공개 웹페이지만으로 확인했다고 단정하지 않는다.

## 13. 현재 결정

- **확정:** 홈노크를 직접 경쟁사이자 산업 신뢰 레퍼런스로 관리한다.
- **확정:** 문구·화면·그래픽은 복제하지 않고 정보 순서·신뢰 구조·이득 표현법만 배운다.
- **확정:** 집신은 자산관리가 아니라 `집 기준 기록·업무·채팅·권한`으로 차별화한다.
- **추천:** 다음 시안은 토스·문토·홈노크의 장점을 합친 6장면 스토리보드로 먼저 제작한다.

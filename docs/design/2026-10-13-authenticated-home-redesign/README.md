# 로그인 홈 재설계 참고자료 분석

- 상태: 사용자 승인 대기
- 원본 제공: 사용자 직접 제작 시안 2장

## 파일

- `reference-01-my-home.png`: 로그인 후 My Home 구상
- `reference-02-checklist.png`: 계약 전 체크리스트 구상

## 살릴 구조

- 데스크톱에서 여러 집을 관리하기 쉬운 좌측 탐색
- 상단의 현재 집 선택
- 집 추가, 채팅, 알림, 프로필의 명확한 위치
- 집을 등록한 뒤 기록을 하나씩 준비하는 체크 방식
- 최근 집, 최근 기록, 일정의 업무 중심 배치

## 그대로 복제하지 않는 구조

- 7개 이상의 최상위 메뉴
- 좌측 메뉴와 집 목록이 동시에 차지하는 이중 사이드바
- 첫 로그인부터 여러 빈 카드가 동시에 보이는 화면
- 실제 데이터가 없는 0/24 진행률
- 현재 존재하지 않는 집신 AI
- 집 찾기·관리비 계산 등 현재 집신 범위를 벗어나는 기능

## 권장 전환

하나의 공통 앱 틀을 유지하되 실제 상태에 따라 복잡도를 공개한다.

1. 집 없음: 교육 이미지 1장 + 행동 1개
2. 집 있음·기록 적음: 선택한 집 + 실제 기록 6개 체크리스트
3. 기록 쌓임: 오늘 할 일 + 최근 집 + 최근 기록 + 채팅 + 일정

교육용 이미지는 첫 이용자의 이해를 돕는 예시로만 사용한다. 실제 집 카드에는 권한 확인된 실제 업로드 사진 또는 중립적인 `사진 없음` 표지만 사용한다.

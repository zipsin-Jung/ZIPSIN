# Figma 참고 시안 검토

- 일자: 2026-10-13
- 참고 파일: 사용자가 공유한 `제목 없음` Figma 파일
- 적용 원칙: 그대로 복제하지 않고 정보 구조와 화면 원칙만 참고

## 확인한 화면 범위

- 랜딩페이지
- 로그인·회원가입
- My Home·체크리스트
- 계약·입주, 거주 관리, 만기·퇴거
- 기능 소개, 공지사항, 고객센터, 회사소개
- 이용약관, 개인정보처리방침, 채팅

## 참고할 디자인 원칙

1. 화면 하나에 목적 하나를 둔다.
2. 넓은 여백과 짧은 문장으로 정보 우선순위를 분명히 한다.
3. 선 아이콘과 얇은 경계로 기능 묶음을 구분한다.
4. 최근 기록은 사진·계약서·영수증·메모·수리처럼 사용자가 바로 이해할 수 있는 항목으로 보여준다.
5. 안전한 기록 저장과 집 추가 행동을 홈에서 분명하게 보여준다.
6. 서비스 소개와 실제 로그인·회원가입·업무 화면을 구분한다.

## 집신 메인 반영 판단

- 유지: 큰 핵심 문장, 넓은 여백, 단순한 선 아이콘, 기록 종류별 카드, 로그인과 시작하기의 분리
- 집신에 맞게 변경: 주소 공개가 아니라 초대·관계 권한 강조, 집별 대화와 관계 종료 시 권한 종료 설명
- 사용하지 않음: 흑백 와이어프레임 자체의 색상, 화면 배치의 그대로 복제, 사실로 확인되지 않은 수치

## 후속 기준

Figma는 전체 서비스 화면 지도로 활용한다. 구현 우선순위와 문구는 승인된 집신 PRD와 실제 동작 기능을 기준으로 한다.

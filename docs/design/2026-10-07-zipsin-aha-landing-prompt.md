# 집신 메인 홈페이지 제작 프롬프트

아래 내용을 그대로 복사해 사용한다.

```text
집신(ZIPSIN) 메인 홈페이지를 기획하고 고품질 시각 시안으로 제작해줘.

[서비스 정의]
집신은 계약 전부터 입주, 거주, 수리, 관리, 퇴거까지 흩어진 사진·문서·대화·일정을 '집 한 채'를 기준으로 연결하는 주거 기록 관리 서비스야.
수리 중개 플랫폼이 아니고, 공인중개사 전용 서비스도 아니야.
임대인·임차인·공인중개사가 같은 집에서 필요한 기록을 함께 확인하고, 사람이나 담당자가 바뀌어도 집의 기록은 이어지는 구조야.

[이 페이지의 목표]
방문자가 스크롤할 때마다 반드시 다음 반응을 하게 해줘.
1. “맞아, 나도 그런 적 있어.”
2. “아, 그래서 집신이 필요하구나.”
3. “이건 정말 쓰겠다.”
4. “이러면 돈을 낼 이유가 있다.”

각 섹션은 반드시 ‘공감할 상황 → 문제 → 집신의 전환 → 눈에 보이는 결과’ 구조를 가져야 해.
모호한 소개 문구나 예쁜 장식만 있는 섹션은 만들지 마.

[전체 연출]
- 토스 홈페이지의 정돈된 여백, 대담한 타이포그래피, 스크롤에 따른 장면 전환, 실사 장면과 실제 제품 UI의 결합 원칙만 참고해.
- 토스의 로고, 문구, 색상, 이미지, 레이아웃을 복제하지 마.
- 한 화면에는 핵심 문장 1개와 시각적 증거 1개만 강하게 보여줘.
- 실제 한국의 아파트·빌라·원룸에서 생길 법한 순간을 자연스러운 실사 사진으로 보여줘.
- 실사 사진 위에 글자를 무리하게 올리지 말고, 필요하면 배경·여백·반투명 영역으로 가독성을 확보해.
- 휴대폰에는 실제로 사용할 수 있는 집신 제품 UI를 보여줘. 데코레이션용 가상 그래프나 의미 없는 카드는 금지해.
- 데스크톱과 모바일이 같은 스토리로 연결되게 설계해.

[비주얼 톤]
- 성숙한 2026년형 한국 프롭테크·SaaS 스타트업
- 고급스럽고 차분하지만 냉정하거나 기관 홈페이지처럼 보이지 않게
- 연한 흰색·뉴트럴 배경, 짙은 잉크 색의 글자, 집신의 녹색은 CTA와 제품 UI에만 절제해 사용
- 금색은 로고 안의 작은 포인트 외에는 사용하지 마
- 둥근 카드, 진한 그림자, 지나친 그라데이션을 남발하지 마
- 타이포그래피는 크고 단단하게, 설명은 짧고 쉽게

[절대 금지]
- 캐릭터가 화면을 차지하는 디자인
- 유치원·초등학교 포스터처럼 보이는 일러스트
- 집, 나무, 보호막, 무한대 등을 큰 3D 아이콘으로 배치
- 금색 그라데이션 제목
- 빈 대시보드와 의미 없는 통계 카드
- 모든 내용을 하나의 큰 흰색 카드 안에 넣는 구성
- 공인중개사 전용처럼 보이는 문구
- 수리 매칭 플랫폼처럼 보이는 문구
- 주소만 알면 다른 사람의 기록을 볼 수 있다는 표현
- 근거 없는 수치, 고객 수, 절감률, 성과 수치를 사실처럼 표시

[페이지 구성]

1. 히어로 — 집은 그대로인데 기록만 사라진다
핵심 문장:
“입주할 때 찍었던 사진,
2년 뒤에도 바로 찾을 수 있을까요?”
시각 장면:
이사·입주 순간의 실사 장면과 수천 장의 사진 속에서 과거 입주 사진을 찾지 못하는 휴대폰 화면.
아하 모먼트:
“사진첩이 아니라 그 집에 저장해야 하는구나.”

2. 반복 연락 — 집 문제 하나, 설명은 세 번
핵심 문장:
“임차인이 중개사에게,
중개사가 임대인에게,
임대인이 다시 수리기사에게.”
시각 장면:
같은 누수 사진과 설명이 세 개의 대화방에 반복되는 모습에서, 집신의 하나의 집 기록을 세 사람이 함께 확인하는 화면으로 전환.
아하 모먼트:
“한 번 기록하면 세 사람이 같은 내용을 보는구나.”

3. 담당자 변경 — 사람이 나가면 업무도 사라진다
핵심 문장:
“담당자가 바뀌어도,
이 집의 다음 일은 그대로 이어져야 하니까.”
시각 장면:
이전 담당자의 휴대폰에 남은 사진·연락·일정과, 집신에서 완료한 일·답변 대기·다음 행동이 그대로 전달되는 화면을 대비.
아하 모먼트:
“기록이 직원 휴대폰이 아니라 집과 사무소에 남는구나.”

4. 핵심 제품 — 주소 하나가 집의 기록함이 된다
핵심 문장:
“계약서도, 사진도, 일정도, 대화도
이제 이 집 하나에.”
시각 장면:
권한이 확인된 사용자의 휴대폰에서 특정 주소의 집 공간을 열고, 계약·입주·사진·수리·일정이 하나의 타임라인으로 이어지는 실제 제품 UI.
안전 원칙:
주소만으로 기존 기록을 볼 수 없고, 초대받은 권한 있는 사람만 확인할 수 있게 표현해.
아하 모먼트:
“이게 집신이구나. 집마다 하나의 기록 공간이 생기는 거구나.”

5. 과정 기록 — 사진이 이어지면 증거가 된다
핵심 문장:
“사진 한 장으로는 알 수 없지만,
전·중·후가 이어지면 과정이 보입니다.”
시각 장면:
수리 전 → 수리 중 → 수리 후 → 영수증이 타임라인으로 정리되고, 임대인·임차인·공인중개사가 같은 상태를 보는 제품 UI.
아하 모먼트:
“현장에 다시 가지 않아도 세 사람이 과정을 알 수 있구나.”

6. 필요한 순간 — 다시 찾지 않고 바로 꺼낸다
핵심 문장:
“퇴거할 때, 담당자가 바뀌 때,
문제가 생겼을 때 다시 찾지 마세요.”
시각 장면:
사용자가 필요한 사진·문서·처리 내역을 선택하고, 개인정보를 기본 제외한 깔끔한 PDF 기록으로 정리하는 제품 흐름.
법적 효력을 보장한다는 표현은 금지해.
아하 모먼트:
“평소에 남겨두면 필요한 순간 바로 꺼낼 수 있구나.”

7. 사용자별 가치 — 같은 기록이 서로 다른 문제를 해결한다
세 사람을 단순한 포즈 사진이 아니라 실제 행동으로 보여줘.
- 임차인: 입주 상태와 요청을 남겨 자신의 기록을 보호
- 임대인: 직접 방문하지 않고 집의 변화와 비용을 확인
- 공인중개사: 반복 연락과 현장 확인을 줄이고 담당자가 바뀌어도 업무를 연결
핵심 문장:
“필요한 이유는 달라도,
확인하는 집의 기록은 하나니까.”
아하 모먼트:
“세 사람 모두 필요한 이유가 있구나.”

8. 최종 CTA — 한 집부터 시작
핵심 문장:
“지금 사는 집도,
관리하는 집도,
기록은 한 채부터 시작됩니다.”
기본 버튼:
“내 집 기록 시작하기”
보조 버튼:
“집신 사용 방법 보기”

[헤더]
- 왼쪽: ZIPSIN 로고
- 메뉴: 집신이 필요한 이유 / 어떻게 쓰나요 / 사용자별 혜택 / 요금 / 도움말
- 오른쪽: 로그인 / 내 집 기록 시작하기
- 모바일은 로고·로그인·메뉴 버튼으로 단순화

[출력 방식]
1. 먼저 8개 섹션의 스토리보드를 데스크톱·모바일로 제안해.
2. 각 섹션마다 핵심 문장, 실사 장면, 제품 UI, 아하 모먼트를 표로 정리해.
3. 사용자의 승인 전에는 개발 코드를 작성하지 마.
4. 승인된 섹션부터 한 장면씩 고품질 이미지 시안을 제작해.
5. 각 장면은 이전·다음 장면과 색상, 타이포그래피, 실사 톤, 휴대폰 UI가 완전히 이어져야 해.
6. 최종 시안 승인 후에만 Next.js App Router로 구현해.
```

# 공개 홈 생활 장면 이미지 자산

- 일자: 2026-10-14
- 용도: 공개 홈페이지의 서비스 이해를 돕는 생활 장면 예시
- 제작 방식: Codex 이미지 생성 도구로 새로 제작
- 개인정보: 실제 고객 사진·주소·계약정보 사용 안 함

## 공통 제작 기준

- 한국의 평범한 아파트·사무 공간에서 실제로 일어날 법한 장면
- 사람 얼굴보다 손, 물건, 생활 흔적 중심
- 과장된 고급 주택 광고, 캐릭터, 화면 속 가짜 문서 글자 제외
- 따뜻한 뉴트럴 조명과 차분한 청록 계열로 네 장의 톤을 통일
- 이미지 자체는 문제를 보여주고 해결 내용은 실제 React UI로 분리

## 파일과 사용 위치

| 파일 | 보여주는 문제 | 사용 위치 |
|---|---|---|
| `public/images/public-home/scattered-records.png` | 휴대전화와 컴퓨터 폴더에 흩어진 집 사진 | 공개 홈 히어로, 첫 생활 장면 |
| `public/images/public-home/paper-contract.png` | 외출 중 필요한 계약서가 집의 종이 파일에만 있는 상황 | 계약서 생활 장면 |
| `public/images/public-home/ceiling-aircon.png` | 천장형 에어컨의 설치·수리 이력을 알기 어려운 상황 | 설비 이력 생활 장면 |
| `public/images/public-home/condition-before-after.png` | 도배·장판 상태를 입주 전후로 확인해야 하는 상황 | 상태 비교 생활 장면 |

## 사용 제한

- 이 이미지를 로그인 사용자의 실제 집 대표 사진으로 사용하지 않는다.
- 고객 자료, 수리 결과, 계약 증거처럼 표현하지 않는다.
- 이미지에 없는 기능을 자동화된 것처럼 설명하지 않는다.
- 삭제·교체 시에는 공개 홈 시나리오와 접근성 대체 설명을 함께 갱신한다.

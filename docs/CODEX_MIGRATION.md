## 사용자의 작업 방식

- 한국어 존댓말로 짧고 쉽게 설명합니다.
- 사용자는 개발 초보자이므로 사소한 기술 선택은 직접 판단합니다.
- 계획만 설명하지 말고 가능한 구현·검수·저장을 실제로 진행합니다.
- 기존 프로젝트와 정상 기능을 유지하고, 매번 새 프로젝트나 새 버전을 만들지 않습니다.
- 계정 로그인·권한 승인처럼 사용자가 직접 해야 하는 일만 마지막에 안내합니다.
- 검사하지 않은 항목을 완료했다고 표현하지 않습니다.

## 최신 디자인 방향

- 단색 배경과 텍스트 중심의 일반적인 SaaS 랜딩페이지로 단순화하지 않습니다.
- 최신 시안의 집·정원 배경, 큰 휴대폰, 집신이 캐릭터, 사진 중심 카드, 딥그린·골드 색상과 높은 이미지 비중을 실제 웹에 반영합니다.
- 전체 시안을 한 장의 배경 이미지로 붙이지 않습니다. 제목, 설명, 버튼, 메뉴, 카드, 폼은 실제 HTML/React로 구현합니다.
- 휴대폰 데모는 클릭 가능한 상태를 유지합니다.
- 로고는 초록 지붕, 금색 창문, 금색 무한대 모양의 실제 집신 로고를 사용하며 일반 집 아이콘으로 대체하지 않습니다.
- 캐릭터와 장식은 버튼이나 휴대폰 탭의 클릭을 막지 않아야 합니다.

## 확정 문구와 기능

- 서비스: 집신 / ZIPSIN
- 슬로건: `집을 계획하는 순간부터.`
- 핵심 메시지: `사람이 바뀌어도, 집의 기록은 남습니다.`
- 설명: 계약부터 입주, 수리, 관리, 퇴거까지 집 한 채의 모든 기록을 한곳에 정리합니다.
- 사용자: 공인중개사, 임대인, 임차인/거주자, 수리기사
- 흐름: 서비스 이해 → 휴대폰 데모 → 역할별 화면 → 요금제 → 사전가입 영역
- `사전 가입자 1,000명`은 목표이며 실적이나 현재 가입자 수로 표현하지 않습니다.

### 휴대폰 데모

- 홈, 우리집, 수리관리, 기록, 마이 화면을 유지합니다.
- 하단 홈, 상단 홈 버튼, 휴대폰 로고는 어느 화면에서든 홈으로 돌아갑니다.
- 화면 전환 시 휴대폰 내부 스크롤을 위로 초기화합니다.
- 수리 상태는 접수 → 처리중 → 완료로 바꿀 수 있습니다.
- 역할 선택 후 `해당 역할 화면 체험하기`는 Hero 휴대폰을 그 역할로 바꾸고 Hero로 이동합니다.
- 실제 기능이 아닌 항목은 예시 또는 준비 중임을 표시합니다.

### 요금제

- FREE: 0원 / 거주 중인 집 1채
- BASIC: 월 4,900원 / 임대인 2~9채
- PRO: 월 9,900원 / 임대인 10채 이상
- BUSINESS: 월 99,000원 / 공인중개사 최대 50채
- 요금제 버튼은 사전가입 영역으로 이동하고 희망 요금제를 자동 선택합니다.
- `출시 전 예상 요금제이며 변경될 수 있습니다`를 표시합니다.
- 연간 할인, 무료 개월 수, 무제한 등록, PDF 제공, 우선 지원 등 확정되지 않은 혜택을 만들지 않습니다.

### 사전가입 폼

- 이름, 전화번호, 사용자 유형, 현재 거주 상태, 개인정보 동의는 필수입니다.
- 지역과 희망 요금제를 포함하고 정확한 집 주소는 받지 않습니다.
- 전화번호 형식 오류를 포함해 항목 가까이에 오류를 표시하고 첫 오류로 이동합니다.
- 현재는 프론트엔드 체험이며 개인정보를 저장·전송하지 않습니다.
- 완료 화면에서도 실제 접수가 이루어지지 않았음을 명확히 표시합니다.

### 이번 단계에서 제외

- 실제 결제, 로그인, 관리자, 실제 채팅, 실제 AI, 복잡한 DB, 지도, 기사 매칭, PDF 생성
- 실제 가입 접수와 DB 연결은 미션6 범위입니다.

## 기존 오류와 유지할 수정

- `scripts/preview.mjs`의 HTTP 403 문제는 `path.resolve`를 이용한 루트 경로 정규화로 고쳤습니다. 경로 보호를 제거하지 않습니다.
- 초록 버튼의 글자는 링크 색상 상속으로 어두워지지 않도록 흰색 대비를 유지합니다.
- 페이지 헤더의 홈/로고와 휴대폰 내부 홈 동작을 구분합니다.
- 새로 다운로드한 `실행.command`는 macOS 경고가 생길 수 있습니다. 이미 허용한 실행 파일을 불필요하게 교체하거나 보안 기능 전체를 끄라고 안내하지 않습니다.

## 대화의 마지막 이미지 수정 요청

사용자는 스크린샷에서 동그라미로 표시한 영역의 다음 요소만 자연스럽게 제거해 달라고 요청했습니다.

- 말풍선/안내 문구
- 화살표와 텍스트
- 떠 있는 카드

해당 영역은 깨끗한 흰색 배경으로 자연스럽게 메우고, 원래 배경·휴대폰·나머지 디자인은 바꾸지 않는 요청입니다. 공유 대화에는 `remove-bubbles.cjs`가 생성되었다고 기록되어 있으나, 내려받은 ZIP에는 이 스크립트와 수정 결과 이미지가 없습니다. 따라서 이 수정이 현재 프로젝트에 실제 반영되었다고 간주하지 않습니다.

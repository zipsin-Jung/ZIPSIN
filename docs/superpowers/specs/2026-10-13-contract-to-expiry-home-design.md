# 집신 계약 후부터 만기까지 집 홈 설계

- 작성일: 2026-10-13
- 상태: DRAFT — 사용자 검토·승인 대기
- 구현 승인: 아님

## 1. 의도

사용자가 부동산 계약을 마친 뒤 계약서, 입주 사진, 수리 대화, 일정과 만기 준비를 각각 다른 장소에서 찾지 않도록 한다. 로그인 홈은 기능 목록이 아니라 현재 집의 계약 단계, 만기와 다음 행동을 보여준다.

제품 한 문장:

> 계약 후부터 만기·연장·퇴거까지, 그 집에 필요한 기록과 다음 일을 순서대로 알려주는 집 홈

## 3. 요구사항

### ZH-LIFE-001 사용 목적 선택

- 역할: 모든 가입 사용자
- 트리거: 휴대전화 인증 완료
- 흐름: 임차인 / 임대인 / 공인중개사 / 관리·기타 선택 → 안내 화면 개인화
- 권한: 선택만으로 집 접근을 허용하지 않음
- 수용기준:
  - 화면 안내용 선택과 실제 권한 역할을 구분한다.
  - 공인중개사와 관리·기타는 다음 단계에서 세부 역할을 확인한다.

### ZH-LIFE-002 집 연결

- 역할: 모든 사용자
- 트리거: 첫 집 시작
- 흐름: 집 만들기 또는 보안 초대 수락 → 집별 관계 확인
- 개인정보: 주소만으로 기존 기록을 검색하거나 연결하지 않음
- 수용기준:
  - 동일 주소의 다른 기록이 노출되지 않는다.
  - 관리·기타는 유효기간이 있는 초대가 필요하다.
  - 개인 시작 공간과 공유 집 공간은 자동 병합되지 않는다.

### ZH-LIFE-003 계약 요약과 만기 계획

- 역할: 임대인, 임차인, 허용된 사무소 구성원
- 트리거: 계약 시작·만기일 확인
- 흐름: 집 홈 → D-day 확인 → 아직 결정 전/연장 생각 중/퇴거 준비 선택
- 수용기준:
  - 만기일이 없으면 D-day를 만들지 않는다.
  - 만기가 지나면 D+숫자를 표시한다.
  - 계획 상태는 법적 통지가 아님을 표시한다.
  - 임대인과 임차인의 상태를 각각 보존한다.
  - 대리 입력은 행위자와 위임 대상을 기록한다.

### ZH-LIFE-004 다음 행동 안내

- 역할: 권한 있는 집 사용자
- 트리거: 집 홈 진입
- 흐름: 계약·입주·거주관리·만기퇴거 상태 확인 → 다음 행동 실행
- 수용기준:
  - 추천 행동은 최대 3개다.
  - 기능 목록보다 다음 행동이 먼저 보인다.
  - 완료는 실제 데이터로만 계산한다.

### ZH-LIFE-005 문서·사진 보관

- 역할: 권한 있는 사용자
- 트리거: 카메라 촬영 또는 파일 선택
- 흐름: 현재 집·작성자·시간 자동 입력 → 종류·범위 확인 → 업로드 → 시간선 반영
- 수용기준:
  - 사진·PDF는 직접 업로드한다.
  - `채팅에만 보내기`와 `집 기록에도 남기기`를 구분한다.
  - 비공개 파일은 public URL로 노출하지 않는다.
  - PDF 업로드와 PDF 자동 생성은 구분한다.

### ZH-LIFE-006 집 시간선·캘린더

- 역할: 권한 있는 사용자
- 트리거: 날짜가 있는 기록 또는 일정 저장
- 흐름: 기록은 시간선, 행동·기한은 캘린더에 표시
- 수용기준:
  - 사진 촬영일은 시간선에 표시할 수 있다.
  - 모든 사진을 캘린더 일정으로 만들지 않는다.
  - 사용자가 확인한 계약·만기·수리 일정만 캘린더에 표시한다.

### ZH-LIFE-007 집 채팅·알림

- 역할: 현재 관계자
- 트리거: 집·계약·수리 사건 대화 참여
- 수용기준:
  - 관계 종료 후 신규 메시지를 보낼 수 없다.
  - 이전 계약 대화는 다음 임차인에게 보이지 않는다.
  - 알림 수와 읽지 않은 채팅 수를 구분한다.
  - 법적 증거력을 보장한다고 표현하지 않는다.

### ZH-LIFE-008 이 집 사람들

- 역할: 권한 있는 현재 관계자
- 트리거: 집 사람들 화면 진입
- 수용기준:
  - 유효한 집·계약·사무소·사건 관계만 표시한다.
  - 개인 전화번호·이메일을 기본 노출하지 않는다.
  - 휴대전화 주소록을 자동 수집하지 않는다.
  - 관계 종료 후 새 연락을 차단한다.

## 5. 중요한 정책 미결정

다음은 구현 전에 사용자·개인정보·법률 검토가 필요하다.

- 개인 시작 공간을 공유 집과 연결하는 승인 절차
- 채팅 사진을 기록으로 남길 때 파일 복사 또는 원본 참조
- 채팅과 기록의 보관기간
- 메시지 수정·철회 정책
- 탈퇴·관계 종료 후 다운로드와 열람 기간
- 만기 계획을 상대에게 공유하는 알림 채널

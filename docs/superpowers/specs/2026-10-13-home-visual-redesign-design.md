# 집신 로그인 홈 시각 재설계 명세

## 1. 의도

### 사용자에게 들려야 하는 생각

1. `맞아, 집 사진과 서류가 여기저기 흩어져 있어.`
2. `아, 사진첩이 아니라 그 집에 기록하는 거구나.`
3. `내가 미처 생각하지 못한 기록도 하나씩 준비할 수 있겠네.`

### 디자인 목표

따뜻한 주거 서비스와 신뢰할 수 있는 업무 도구의 인상을 함께 만든다. 로그인 홈은 다시 읽는 광고가 아니라 문제를 인식하고 기록을 시작하는 제품 화면이어야 한다.

## 2. 디자인 시스템

- 방향: 에디토리얼 워크스페이스
- 글꼴: 로컬 Pretendard Variable 우선, 안전한 한글 시스템 글꼴 대체
- 배경: `#F7F7F3`
- 표면: `#FFFFFF`
- 주요 글자: `#16211E`
- 보조 글자: `#5D6A65`
- 브랜드 초록: `#0E5A4D`
- 진한 초록: `#083E37`
- 옅은 초록: `#EAF2EF`
- 금색: `#C98A2E`, 작은 상태 표시만 사용
- 본문: 모바일·데스크톱 모두 기본 16px 이상
- 핵심 제목: 모바일 30~32px, 데스크톱 44~48px, 굵기 700
- 카드: 반지름 16~20px, 1px 테두리, 약한 그림자
- 금지: 청록·파랑 대형 그라데이션, 유리 효과, 과도한 `font-black`, 작은 회색 문구, 동일 강도의 카드 반복

## 3. 교육용 사진

### 사진 A: 흩어진 사진과 파일

- 기본 첫 장면
- 컴퓨터 폴더에는 여러 집 사진, 휴대전화에는 개인 사진과 집 사진이 섞여 있다.
- 문구: `이 사진, 어느 집에서 찍었는지 기억나세요?`
- 해결: `사진첩이 아니라 그 집에 기록하세요.`
- 구현 예정 경로: `public/images/home-pain-scattered-records-v1.png`

### 사진 B: 외출 중 필요한 종이 계약서

- 길에서 휴대전화를 확인하는 사람과 집 서랍의 종이 서류를 분할 장면으로 보여준다.
- 문구: `지금 계약 만기일이 필요한데, 계약서는 집 어디에 있나요?`
- 해결: `밖에서도 권한 있는 계약 기록을 바로 확인합니다.`
- 구현 예정 경로: `public/images/home-pain-paper-contract-v1.png`

### 사진 C: 확인하기 어려운 천장형 에어컨

- 천장형 설비의 모델·설치·수리 정보를 휴대전화로 확인하려는 장면이다.
- 문구: `이 에어컨, 누가 설치하고 언제 수리했는지 기억나세요?`
- 해결: `제품·설치·수리·영수증을 이 집의 설비 기록에 남깁니다.`
- 구현 예정 경로: `public/images/home-pain-ceiling-aircon-v1.png`

AI 생성 사진은 `이런 순간에 집신` 교육 영역에만 사용한다. 사용자의 실제 기록이나 실제 고객 사례로 표현하지 않는다.

## 4. 요구사항

### ZH-UX-001 문제 인식 장면

- 역할: 모든 가입 사용자
- 선행조건: 로그인과 역할 선택 완료
- 흐름: 장면 확인 → 다른 장면 선택 → 연결된 해결 UI 확인 → 첫 기록 행동
- 상태: 로딩, 정상, 이미지 실패, 키보드 선택, 모바일 스와이프
- 수용기준:
  - 기본 장면은 흩어진 사진·파일이다.
  - 한 화면에서 질문 1개와 해결 1개만 강조한다.
  - 장면 선택 시 관련 체크리스트 항목과 실제 경로가 함께 바뀐다.
  - 이미지 실패 시에도 문구와 CTA를 사용할 수 있다.

### ZH-UX-002 집별 기록 체크리스트

- 역할: 대표·소속공인중개사·중개보조원·임대인·임차인
- 선행조건: 사용자가 볼 수 있는 집이 있거나 새 집 등록 권한이 있다.
- 흐름: 집 선택 → 필요한 기록 확인 → 항목 펼치기 → 기록 남기기 → 실제 데이터로 완료 표시
- 기본 항목:
  1. 집 등록 또는 초대 연결
  2. 입주·현재 상태 사진
  3. 계약서와 중요한 날짜
  4. 주요 설비 정보
  5. 수리·변경 기록
  6. 함께 확인할 사람 초대
- 권한 규칙:
  - 역할만으로 완료 권한이 생기지 않는다.
  - 중개보조원에게 계약 작성·승인 행동을 제공하지 않는다.
  - 임대인·임차인은 현재 관계와 허용된 기록 공간만 본다.
- 수용기준:
  - 완료 수는 실제 저장 데이터로만 계산하고 `3/6 완료`처럼 표시한다.
  - 각 항목에 네이티브 `details/summary` 또는 동등한 접근 가능한 `왜 필요한가요?`가 있다.
  - 상세 설명은 필요 이유, 남길 자료, 개인정보 주의, 다음 행동을 짧게 포함한다.
  - 완료하지 않은 항목을 실패나 경고처럼 표현하지 않는다.
  - 사용 권한이 없는 행동은 숨기거나 안전한 안내로 대체한다.

### ZH-UX-003 실제 업무 홈

- 역할: 기록이 있는 사용자
- 흐름: 홈 → 오늘 할 일 → 최근 집 → 기록·채팅
- 수용기준:
  - 홍보형 3단계 배너를 제거한다.
  - 데스크톱 첫 700px 안에 오늘 할 일과 주요 행동이 보인다.
  - 실제 업로드 사진이 있으면 권한 확인된 썸네일을 최대 3장만 표시한다.
  - 사진이 없으면 `사진 없음` 표지를 쓰고 가짜 사진을 실제 집에 붙이지 않는다.
  - 정상 빈 상태와 데이터 조회 오류를 구분한다.

### ZH-UX-004 반응형·접근성

- 모바일 순서: 문제 장면 → 체크리스트 → 최근 집 → 할 일·대화
- 데스크톱: 8:4 또는 7:5 두 열 구성
- 수용기준:
  - 320·390·768·1440px 가로 넘침 0건
  - 본문 16px 이상, 주요 버튼 48px 이상
  - 키보드만으로 장면·상세·CTA 사용 가능
  - WCAG AA 대비 충족
  - 이미지 대체텍스트는 장면의 의미를 설명하며 개인정보를 포함하지 않는다.

## 5. 화면 구조

### 새 사용자·집 없음

1. 실제 집신 로고와 간결한 헤더
2. 문제 인식 사진과 질문
3. 해결되는 집신 화면의 작은 실제 UI
4. 집 등록 또는 받은 초대 확인 CTA 한 개
5. 다음에 준비할 기록 체크리스트 미리보기

### 집은 있으나 기록이 적음

1. 선택한 집과 대표 사진 또는 표지
2. `이 집의 기록을 준비해 보세요` 체크리스트
3. 선택한 문제 장면과 바로 연결되는 미완료 항목
4. 최근 실제 기록

### 기록이 쌓임

1. 오늘 이어서 할 실제 일
2. 최근 변경된 집과 권한 있는 실제 사진
3. 읽지 않은 대화와 다음 일정
4. 체크리스트는 축약된 완료 상태로 유지

## 6. 상세 설명 예시

### 계약서와 중요한 날짜 — 왜 필요한가요?

`외출 중에도 계약 기간과 특약을 확인하고, 만기 전에 필요한 일을 놓치지 않기 위해 남깁니다. 주민등록번호와 계좌정보는 가린 사본을 권장합니다.`

### 주요 설비 정보 — 왜 필요한가요?

`천장형 에어컨처럼 제품 정보를 바로 보기 어려운 설비는 모델명, 설치일, 설치업체와 이전 수리를 함께 남기면 문제가 생겼을 때 다시 찾지 않아도 됩니다.`

### 입주·현재 상태 사진 — 왜 필요한가요?

`도배·장판·가구의 상태가 언제부터 있었는지 기억에 의존하지 않도록 같은 집의 시간선에 남깁니다.`

## 7. 개인정보·성능

- 주소나 집 ID만으로 사진을 열 수 없다.
- 비공개 첨부는 로그인 세션과 RLS를 통과한 뒤 짧은 signed URL로만 표시한다.
- JPEG·PNG만 홈 썸네일로 사용하며 HEIC·PDF는 썸네일에서 제외한다.
- 원본 사진은 최대 3장, 지연 로딩과 고정 비율을 사용한다.
- 계약서 원본·연락처·사람 얼굴·계좌정보가 있는 이미지는 자동 대표사진으로 선택하지 않는다.

## 8. MVP와 이후

### 이번 범위

- `/home`과 앱 헤더
- 세 교육용 사진 장면
- 집별 기록 체크리스트와 상세 이유
- 실제 최근 집·할 일·대화 연결
- 사진 없음·오류·권한 없음 상태

### 이후

- 승인된 디자인 토큰을 집 상세·기록·채팅에 확장
- 안전한 썸네일 변환 파이프라인
- 사용자가 체크리스트 항목을 추가·숨기는 기능

### 제외

- 가짜 완성도·성과 수치
- 자동 법적 효력 판단
- 모든 기록의 AI 자동 분류
- Production 배포

## 9. 검증

- 단위: 장면 전환, 실제 완료 계산, 상세 열기, 역할별 CTA, 빈 상태, 오류 상태
- 통합: 권한 없는 집·종료된 관계의 첨부 미노출
- E2E: 가입 사용자 390px·1440px에서 홈 → 체크 항목 → 기록 작성 → 홈 완료 반영
- 시각: 타이포·사진 비율·가로 넘침·이미지 실패 폴백
- 최종: Preview에서 사용자 승인

## 10. 열린 결정

기능·개인정보·비용을 바꾸는 미결정은 없다. 체크리스트의 문구와 순서는 Preview 사용자 검토 후 조정 가능하며 되돌릴 수 있다.

# 회원가입 휴대전화 인증·PC 업무 제품 명세

## 요구사항

### ZSD-AUTH-001 가입 단계 가시화

- 역할: 모든 가입자
- 흐름: 계정 만들기 → 이메일 확인 → 휴대전화 번호 인증 → 역할 선택
- 상태: 초기, 이메일 대기, 번호 입력, 발송 중, 재발송 제한, 불일치, 만료, 공급자 장애, 성공
- AC-1: `/signup`에서 휴대전화 인증이 필수 후속 단계임을 즉시 읽을 수 있다.
- AC-2: 인증 성공 전 역할과 앱에 진입할 수 없다.
- AC-3: SMS 공급자 미연결을 성공처럼 표시하지 않는다.
- AC-4: 휴대전화 번호 인증을 자격·소유권 인증으로 표현하지 않는다.

### ZSD-WEB-001 여러 집 PC 업무

- 역할: 공인중개사, 여러 집 임대인, 사무소 구성원
- 흐름: PC 로그인 → 집 목록 → 이름·주소 검색 → 정렬 → 집 기록 또는 새 기록
- 상태: 정상, 빈 목록, 검색 결과 없음, 오류, 권한 종료
- AC-1: 1280·1440px에서 메뉴·검색·목록·빠른 행동을 접힘과 가로 넘침 없이 사용한다.
- AC-2: 검색은 권한 있는 집 목록 안에서만 동작한다.
- AC-3: 키보드로 검색, 집 열기, 새 기록 진입이 가능하다.
- AC-4: 모바일은 같은 데이터와 권한을 카드형으로 보여준다.

### ZSD-SESSION-001 로그아웃

- 역할: 모든 로그인 사용자
- 흐름: 마이 → 로그아웃 → 서버 세션 종료 → 공개 홈
- AC-1: 눈에 보이는 로그아웃이 있다.
- AC-2: 로그아웃 뒤 보호 경로 직접 접근은 로그인으로 이동한다.

## 개인정보·권한

- 전화번호 원문·인증번호를 URL, 로그, Git에 남기지 않는다.
- 주소만으로 집 기록을 검색하거나 연결하지 않는다.
- PC에서도 대표 계정을 공유하지 않고 개인 계정을 사용한다.
- 공급자 오류와 요청 제한은 안전한 한국어 안내만 표시한다.

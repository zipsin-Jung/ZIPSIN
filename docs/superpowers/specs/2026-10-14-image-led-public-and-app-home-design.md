# 이미지 중심 공개 홈·앱 홈 설계

## 제품 목표

방문자는 10초 안에 집신을 `집에 흩어진 사진·문서·대화·일정을 집 한 채에 이어서 기록하는 서비스`라고 이해한다. 로그인 사용자는 첫 화면에서 어느 집인지, 만기가 언제인지, 다음 행동과 새 대화가 무엇인지 확인한다.

## 요구사항과 수용 기준

### RC-PUB-IMG-001 공개 홈 생활 장면

- AC-PUB-IMG-01: 흩어진 집 사진, 외부에서 필요한 계약서, 천장형 에어컨, 입주 전후 상태의 네 이미지가 실제 자산으로 표시된다.
- AC-PUB-IMG-02: 장면을 선택하면 이미지, 질문, 설명과 해결 UI가 같은 사례로 함께 바뀐다.
- AC-PUB-IMG-03: 이미지 실패 시에도 질문, 설명, 제품 UI와 CTA를 사용할 수 있다.
- AC-PUB-IMG-04: 이미지는 예시 장면임을 명확히 표시하며 실제 고객 기록처럼 표현하지 않는다.

### RC-PUB-EVIDENCE-001 실제 제품 UI 증거

- AC-PUB-EV-01: 해결 화면은 스크린샷이 아닌 접근 가능한 React 컴포넌트다.
- AC-PUB-EV-02: 예시 주소·날짜·건수에는 `제품 화면 예시`가 표시된다.
- AC-PUB-EV-03: OCR, 자동 비교와 PDF 생성처럼 구현되지 않은 기능은 작동하는 것처럼 보이지 않는다.

### ZH-HOME-MEDIA-001 로그인 홈 이미지 원칙

- AC-HOME-MEDIA-01: 교육 이미지나 임의 주거 사진을 실제 집 카드에 사용하지 않는다.
- AC-HOME-MEDIA-02: 실제 사진을 안전하게 조회하지 못하는 상태에서는 `아직 등록된 사진이 없습니다` 표지를 사용한다.
- AC-HOME-MEDIA-03: 계약서·영수증·PDF·채팅 첨부를 대표사진으로 자동 선택하지 않는다.
- AC-HOME-MEDIA-04: 향후 실제 사진은 해당 집의 준비 완료 photo 기록과 현재 접근 권한이 모두 확인된 경우에만 짧은 signed URL로 표시한다.

### ZH-HOME-SUMMARY-001 로그인 후 첫 화면

- AC-HOME-SUM-01: 한 집 화면은 집명, 보호 주소, 계약 D-day, 다음 행동, 사진 상태와 집 대화를 첫 화면에 표시한다.
- AC-HOME-SUM-02: 여러 집 화면은 만기와 열린 일을 우선하며 작은 사진 상태만 보조한다.
- AC-HOME-SUM-03: 자료가 없을 때 가짜 수치 대신 등록 또는 확인 행동을 보여준다.

### ZH-VIS-A11Y-001 반응형·접근성

- AC-VIS-01: 320·390·768·1440px에서 가로 넘침이 없다.
- AC-VIS-02: 장면 탭은 클릭과 좌우 화살표 키로 전환된다.
- AC-VIS-03: 이미지에는 개인정보가 없는 대체 설명이 있고 이미지 위에 긴 본문을 올리지 않는다.
- AC-VIS-04: 첫 장면만 우선 로드하고 나머지는 지연 로드하며 고정 비율로 레이아웃 이동을 줄인다.

## 화면·상태

### 공개 홈

- 기본: 흩어진 사진 선택
- 선택·키보드: 선택한 이미지와 제품 UI 동시 변경
- 이미지 실패: 중립 배경과 `이미지를 불러오지 못했습니다` 폴백
- 모바일: 질문 → 이미지 → 해결 UI → CTA 한 열

### 로그인 홈

- 집 없음: 역할에 맞는 하나의 시작 행동
- 한 집: D-day·다음 행동 우선, 사진 없음 표지, 집 기록·대화 CTA
- 여러 집: 우선순위 카드와 작은 사진 없음 상태
- 계약 날짜 없음·채팅 없음·조회 오류·권한 종료는 기존 안전 상태 유지

## 이미지 출처와 사용 범위

- 생성 이미지 네 장은 공개 교육용이며 실제 고객 자료가 아니다.
- 이미지 안에는 주소, 계약 내용, 고객 정보와 집신 UI 문구를 넣지 않는다.
- 실제 제품 UI는 HTML·React로 별도 표시한다.
- 이전 합성 시안과 사용자 참고 스크린샷은 분위기 참고용으로만 보존한다.

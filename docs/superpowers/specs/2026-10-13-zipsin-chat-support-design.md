# 집신 챗·공식 고객지원 제품 명세

- 작성일: 2026-10-13
- 상태: 사용자 승인, 구현계획 작성
- 기준 결정: `DEC-015 집신 챗과 공식 고객지원`
- 적용 대상: 유료 파일럿과 이후 정식 제품

## 1. 목적

집신 안에서 중개사·임대인·임차인·수리기사가 개인 전화번호나 카카오톡을 공개하지 않고 대화하게 한다. 대화는 개인 휴대전화가 아니라 집신 계정과 허용된 방에 남는다. 모든 사용자는 `집신 고객지원` 공식계정으로 문의할 수 있고, 초기에는 집신 대표가 직접 답한다.

## 2. 확정 원칙

1. 채팅 권한에 별도의 `담당자` 개념을 사용하지 않는다.
2. 사무소 소속, 현재 계약 관계, 방 초대·참여, 수리방 초대만 접근 근거로 사용한다.
3. 전화번호·이메일·비공개 로그인 아이디·휴대전화 주소록은 상대에게 공개하지 않는다.
4. 모르는 사용자를 전화번호나 이름으로 전체 검색해 연락할 수 없다.
5. 초기 사진은 사용자가 채팅방에 직접 선택해 올린다.
6. 채팅 사진은 집 기록에 자동 저장되지 않는다.
7. 집신 고객지원은 일반 사용자가 만들거나 흉내 낼 수 없는 공식계정이다.
8. 초기 고객지원 답변자는 집신 대표이며, 별도 상담 담당자 배정 기능을 만들지 않는다.
9. 대표는 고객지원방만 볼 수 있고 사용자의 다른 개인·단체·집 대화를 임의로 볼 수 없다.
10. 향후 AI 응답은 `AI 답변`으로 표시하고 사용자가 사람에게 연결할 수 있게 한다.
11. 관계 종료나 방 제외 뒤에는 다음 조회·전송·파일 열기부터 차단한다.
12. 메시지 원문 수정·물리 삭제는 첫 출시에서 제공하지 않는다.

## 4. 방 종류와 권한

| ROOM-TYPE | 방 | 누가 만들거나 여는가 | 접근 기준 | 종료 기준 |
|---|---|---|---|---|
| `direct` | 개인 대화 | 이미 연결된 사용자 중 한 명 | 두 사용자의 활성 참여 | 차단·나가기 |
| `group` | 단체 대화 | 사용자가 허용된 관계자를 초대 | 초대를 수락한 활성 참여자 | 나가기·내보내기 |
| `home_shared` | 집 대화 | 집 공간에서 생성 | 현재 계약 관계자 또는 방에 명시적으로 초대된 사무소 구성원 | 계약 종료·방 제외 |
| `office_internal` | 사무소 대화 | 사무소 생성 시 기본 생성 | 활성 사무소 구성원 | 사무소 소속 종료 |
| `repair_event` | 수리 대화 | 수리 기록에서 생성 | 해당 수리방에 초대된 관계자·수리기사 | 완료·철회·만료·방 제외 |
| `support` | 집신 고객지원 | 사용자 최초 진입 시 사용자별 생성 | 해당 사용자와 집신 대표의 공식 지원 권한 | 계정 종료 또는 운영상 종료 |

주소, 집 ID, 방 ID를 안다는 사실은 접근 권한이 아니다. 집 대화에 들어왔다고 집의 계약서·전체 기록·다른 대화가 자동으로 열리지 않는다.

## 5. 역할별 가치

| 역할 | 얻는 가치 |
|---|---|
| 대표 공인중개사 | 직원 개인 카카오톡이 아니라 사무소와 집신에 업무 대화를 남김 |
| 소속공인중개사·중개보조원 | 개인 전화번호 공개 없이 필요한 사람과 대화하고 인수인계 단절을 줄임 |
| 임대인 | 집·계약·수리 맥락 안에서 중개사·임차인·수리기사와 확인 |
| 임차인 | 요청과 사진을 현재 관계 안에 남기고 반복 설명을 줄임 |
| 수리기사 | 초대된 수리방의 필요한 정보만 확인하고 다른 집 정보는 보지 않음 |
| 집신 대표 | 공식 고객지원방에서 사용자 문의를 직접 확인하고 답변 |

## 6. 요구사항과 수락 기준

### REQ-CHAT-CORE-001 공통 메시지

- 역할: 활성 방 참여자
- 트리거: 채팅방에서 메시지 작성
- 사전조건: 현재 방 읽기·쓰기 권한
- 흐름: 내용 입력 → 선택적으로 파일 추가 → 전송 → 저장 확인 → 실시간 전달 또는 재조회 복구
- 상태: 빈 상태, 불러오는 중, 전송 중, 성공, 실패·재시도, 네트워크 끊김, 권한 없음, 종료됨

수락 기준:

- **AC-CHAT-CORE-001** 참여자가 아닌 사용자는 방 ID를 알아도 방·참여자·메시지를 볼 수 없다.
- **AC-CHAT-CORE-002** 발신자와 방 관계는 서버에서 결정하고 클라이언트 입력을 신뢰하지 않는다.
- **AC-CHAT-CORE-003** 같은 전송 키를 반복 요청해도 메시지는 한 건만 만들어진다.
- **AC-CHAT-CORE-004** 전송 실패 뒤 작성한 글과 선택한 파일을 유지한다.
- **AC-CHAT-CORE-005** 실시간 연결이 끊겨도 DB 저장과 재조회로 누락 메시지를 복구한다.

### REQ-CHAT-ROOM-001 여섯 종류의 방

- 역할: 중개사·임대인·임차인·수리기사·일반 가입자
- 트리거: 새 대화 또는 관계 화면의 대화 시작
- 사전조건: 방 종류별 소속·계약·초대·참여 관계
- 개인정보 범위: 해당 방에 필요한 사람과 정보만 표시

수락 기준:

- **AC-CHAT-ROOM-001** 개인 대화는 이미 연결된 관계 또는 초대 수락 없이 시작할 수 없다.
- **AC-CHAT-ROOM-002** 사무소 대화는 활성 사무소 구성원만 접근한다.
- **AC-CHAT-ROOM-003** 이전 계약자의 메시지·파일·알림은 다음 계약자에게 보이지 않는다.
- **AC-CHAT-ROOM-004** 수리기사는 초대된 수리방과 공유된 파일만 볼 수 있다.
- **AC-CHAT-ROOM-005** 집 대화는 별도 담당자 배정 없이 계약 관계와 방 초대로 접근을 판단한다.
- **AC-CHAT-ROOM-006** 소속·계약·수리 초대·방 참여가 끝나면 다음 요청부터 차단한다.

### REQ-CHAT-FILE-001 직접 첨부

- 역할: 현재 방의 전송 권한자
- 흐름: 사진·PDF 선택 → 형식·크기 확인 → 비공개 업로드 → 메시지 연결
- 제한: JPEG·PNG·HEIC·PDF, 파일당 20MB, 메시지당 최대 10개

수락 기준:

- **AC-CHAT-FILE-001** 파일 경로를 알아도 현재 방 권한 없이는 열 수 없다.
- **AC-CHAT-FILE-002** 접근할 때마다 현재 권한을 확인하고 5분 접근 주소만 발급한다.
- **AC-CHAT-FILE-003** 일부 실패 시 성공·실패 파일을 구분하고 실패 파일만 다시 시도한다.
- **AC-CHAT-FILE-004** 화면에 `채팅 사진은 집 기록에 자동 저장되지 않아요`를 표시한다.
- **AC-CHAT-FILE-005** 자동 기록 저장·OCR·자동 분류를 실행하지 않는다.

### REQ-CHAT-SUPPORT-001 집신 고객지원

- 역할: 모든 가입자, 집신 대표
- 트리거: 채팅 목록의 고정된 공식계정 선택
- 흐름: 사용자 문의 → 답변 대기 → 집신 대표가 공식계정으로 답변 → 해결 표시
- 개인정보 범위: 사용자는 자기 지원방만, 대표는 지원방만 확인

수락 기준:

- **AC-CHAT-SUPPORT-001** 일반 사용자는 공식 표시·공식계정 이름·지원 권한을 만들 수 없다.
- **AC-CHAT-SUPPORT-002** 대표 개인 이름·전화번호·개인 계정은 사용자에게 노출되지 않는다.
- **AC-CHAT-SUPPORT-003** 별도 담당자 배정 없이 집신 대표만 초기 문의를 확인하고 답한다.
- **AC-CHAT-SUPPORT-004** 사람이 답하는 동안 AI 또는 자동응답이라고 표시하지 않는다.
- **AC-CHAT-SUPPORT-005** 대표가 사용자의 다른 채팅을 고객지원 권한으로 열람할 수 없다.
- **AC-CHAT-SUPPORT-006** 주민등록번호·계좌 비밀번호·계약서 전체 원본을 보내지 말라는 안내를 표시한다.
- **AC-CHAT-SUPPORT-007** 향후 AI 답변에는 `AI 답변` 표시와 `사람에게 연결` 행동을 제공한다.

### REQ-CHAT-SAFETY-001 차단·신고·보호

- 역할: 채팅 사용자, 신고 검토 권한자
- 트리거: 원하지 않는 개인 메시지 또는 부적절한 내용

수락 기준:

- **AC-CHAT-SAFETY-001** 개인 대화 상대를 차단하면 새 개인 메시지를 받지 않는다.
- **AC-CHAT-SAFETY-002** 모든 메시지와 방을 신고할 수 있다.
- **AC-CHAT-SAFETY-003** 신고 열람·처리 권한과 수행 이력을 별도로 기록한다.
- **AC-CHAT-SAFETY-004** 업무 관계방에서는 개인 차단으로 기록을 없애지 않고 알림 끄기·신고·관계 종료를 사용한다.
- **AC-CHAT-SAFETY-005** 사용자 화면의 숨김과 서버의 물리 삭제를 구분한다.

## 7. 사용자 흐름

### FLOW-CHAT-001 개인·단체 대화

`연결된 사람 선택 → 개인 또는 단체 대화 생성 → 상대가 초대 확인 → 글·사진 전송 → 읽음 확인 → 필요 시 차단·신고·나가기`

### FLOW-CHAT-002 집·사무소 대화

`집 또는 사무소 화면 → 대화 열기 → 참여 범위 확인 → 직접 사진·메시지 전송 → 앱 안 알림 → 관계 종료 시 접근 차단`

### FLOW-CHAT-003 수리 대화

`수리 기록 → 수리방 생성 → 관계자·수리기사 초대 → 필요한 사진·내용 공유 → 완료 → 수리기사 접근 종료`

### FLOW-CHAT-004 집신 고객지원

`채팅 목록의 집신 고객지원 → 문의 작성 → 집신 대표 확인 → 공식계정으로 답변 → 해결 표시`

## 9. 핵심 문구

- 집 대화: `이 방에 초대된 사람들과 이야기합니다. 집 기록은 자동으로 공유되지 않아요.`
- 사무소 대화: `현재 사무소 구성원만 볼 수 있어요.`
- 수리 대화: `이 수리에 필요한 내용만 초대된 사람들과 공유합니다.`
- 사진: `이 사진은 채팅에만 올라갑니다. 집 기록에는 자동으로 저장되지 않아요.`
- 고객지원: `집신 사용 중 궁금한 점을 남겨주세요. 현재는 집신 대표가 직접 확인하고 답변합니다.`
- 권한 종료: `이 대화를 볼 수 있는 관계가 끝났습니다.`

- `support_authorizations`: 집신 대표의 지원 권한
- `notifications`: 본문·주소·전화번호가 없는 앱 안 알림

일반 개인·단체방은 활성 멤버십을 권한 원본으로 사용한다. 집·사무소·수리방은 멤버십과 함께 현재 소속·계약·초대 상태를 매 요청마다 다시 확인한다. 고객지원 권한은 다른 방 접근 권한으로 확장되지 않는다.

## 11. 품질과 출시 차단 조건

다음 중 하나라도 발생하면 출시하지 않는다.

- 다른 방·사무소·집·계약의 메시지나 참여자 노출
- 이전 계약자 또는 종료된 수리기사의 접근 성공
- 고객지원 공식계정 사칭
- 집신 대표가 고객지원 권한으로 일반 채팅 열람
- 전화번호·비공개 로그인 아이디가 화면·알림·로그에 노출
- 중복 전송으로 같은 메시지 여러 건 생성
- 권한 종료 뒤 실시간 구독·파일 접근 지속
- 신고 원본이나 처리 이력 유실

테스트는 단위, DB/RLS 통합, 두 계정 실시간 브라우저, 320px·390px·1440px, 키보드, 재연결, 중복 전송, 사무소·계약·수리 권한 교차, 80% 이상 네 커버리지 지표를 포함한다.

## 12. 미확정 정책

다음은 첫 개발을 막지 않지만 운영 전 확정해야 한다.

- 메시지·파일 최종 보존 기간
- 방을 나간 사용자의 과거 대화 열람 기간
- 신고 처리 기준과 이의 제기 절차
- 실제 고객지원 운영시간과 응답 목표

확정 전에는 보존 기간이나 응답시간을 사용자에게 약속하지 않는다.

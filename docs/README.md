## 보관 원칙

- 새로운 요구사항과 기획 변경은 관련 제품 문서에 반영합니다.
- 중요한 선택은 `decisions/`에 기록합니다.
- 한 페이지 이상 길어진 제품 대화는 `conversations/`에 저장합니다.
- 매 작업의 순서와 결과는 `worklogs/`에 저장합니다.
- 같은 문서는 바탕화면의 `코덱스랑/집신` 문서함에도 함께 반영합니다.
- 개인정보, 실제 연락처, 계좌번호와 원본 계약서는 저장하지 않습니다.

# 공개형 서비스 V1 대화 요약

- 날짜: 2026-10-02
- 주제: 누구나 가입하고 유료 진행이 가능한 집신 구축

## 사용자 결정

- 최종 서비스는 특정 사무소에 한정하지 않고 누구나 가입할 수 있게 만든다.
- 카카오·네이버·Google 간편가입과 별도 휴대전화 인증을 사용한다.
- 사업자는 1월에 준비할 예정이므로 현재는 실제 금전을 받지 않는다.
- 실제 결제 대신 테스트 결제를 먼저 구현한다.
- 첫 구현은 가입부터 집·기록·캘린더·테스트 결제까지 하나씩 진행한다.

## 합의된 첫 흐름

`간편가입 → 휴대전화 인증 → 역할 선택 → 첫 집 등록 → 기록·사진 → 캘린더 → 테스트 결제`

## 중요한 구분

- 테스트 결제는 실제 승인·청구·정산이 발생하지 않는다.
- 실결제는 사업자 등록, 결제대행사 계약·심사와 사용자 별도 승인 후 활성화한다.
- 역할 선택만으로 타인의 집·사무소·계약 기록 접근 권한을 주지 않는다.
- 화면 데모, 실제 계정 생성, 공개 출시와 실결제 활성화는 각각 다른 완료 상태다.

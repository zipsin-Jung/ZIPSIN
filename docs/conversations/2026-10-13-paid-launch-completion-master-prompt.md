# 유료 출시 완성 프롬프트 대화 기록

날짜: 2026-10-13

## 사용자 요구

- 집신은 이 작업을 기준으로 개발 완료되어야 한다.
- 반복적인 재디자인과 원점 회귀가 더 이상 일어나면 안 된다.
- 돈을 받고 판매하는 플랫폼이므로 유료 결제 전환이 필요하다.
- 개발자·디자이너·사업가·PM 관점에서 사용자가 미처 찾지 못한 영역까지 찾아야 한다.
- 설득력 있고 빈틈없는 복사·붙여넣기용 프롬프트가 필요하다.

## 확인된 핵심 사실

- 집·기록·권한·채팅의 핵심 기반은 이미 구현되어 있다.
- 로그인 후 홈의 승인된 시각 재설계는 아직 계획 단계다.
- 실 SMS/OAuth, 계약 생성, 첨부와 권한 종료의 실제 E2E는 보완이 필요하다.
- 결제·구독·환불·영수증·운영자 관리·법정 고지·관측은 구현되지 않았다.
- 현재 Production 출시 게이트는 FAIL이다.

## 결론

프롬프트는 화면을 더 만드는 요구가 아니라 다음 완결 흐름을 실행하도록 작성했다.

`가입 → 첫 집·첫 기록 → 가치 경험 → 결제 → 권한 활성화 → 반복 사용 → 이용 종료·자료 처리`

반복을 막기 위해 디자인 동결, 요구사항 추적, P0/P1 게이트, 독립 검수, 외부 사용자 행동의 일괄 요청, Production 승인 조건을 포함했다.

## 후속 요구: 초대 링크로 즉시 합류

사용자는 로그인한 뒤 공인중개사 사무소 구성원, 임대인, 임차인을 바로 초대하고 초대 링크도 함께 전달해야 한다고 강조했다. 이에 다음을 통합 프롬프트와 제품 문서에 추가했다.

- 사무소 초대와 현재 계약 관계자 초대를 분리
- 완전한 HTTPS 초대 링크 생성
- 데스크톱 링크 복사와 모바일 기기 공유
- 미가입자의 가입·휴대전화 인증 뒤 원래 초대 복귀
- 수락과 관계 생성을 한 작업으로 처리
- 수락 직후 허용된 집과 대화를 홈에 표시
- 만료·철회·일회성·토큰 비노출·관계 종료 즉시 차단

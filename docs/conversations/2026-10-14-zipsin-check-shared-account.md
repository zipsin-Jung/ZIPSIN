# 2026-10-14 집신체크 공용 계정 대화 기록

사용자는 집신체크의 목적이 사회초년생 임차인을 먼저 모아 집신 회원으로 전환하는 것임을 분명히 했다. 따라서 “연동 준비 중” 문구나 별도 체크 계정은 제품 목적과 충돌한다.

확정된 방향은 `zipsin.net`과 `ck.zipsin.net`이 하나의 회원가입·아이디 로그인·간편 로그인·사용자 ID·세션을 쓰는 것이다. 집신체크에서 만든 로컬 기록은 로그인 전에 사라지지 않아야 하며, 로그인 또는 가입 뒤 사용자가 떠난 체크 화면으로 돌아와 계정에 저장할 수 있어야 한다.

구현은 같은 Next.js 앱과 같은 Supabase를 기준으로 통합했다. 실제 운영 연결은 관리자 설정과 Preview 왕복 검수 뒤 사용자 최종 승인을 받아 진행한다.

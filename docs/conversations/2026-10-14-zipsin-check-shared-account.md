# 2026-10-14 집신체크 공용 계정 대화 기록

사용자는 집신체크의 목적이 사회초년생 임차인을 먼저 모아 집신 회원으로 전환하는 것임을 분명히 했다. 따라서 “연동 준비 중” 문구나 별도 체크 계정은 제품 목적과 충돌한다.

확정된 방향은 `zipsin.net`과 `ck.zipsin.net`이 하나의 회원가입·아이디 로그인·간편 로그인·사용자 ID·세션을 쓰는 것이다. 집신체크에서 만든 로컬 기록은 로그인 전에 사라지지 않아야 하며, 로그인 또는 가입 뒤 사용자가 떠난 체크 화면으로 돌아와 계정에 저장할 수 있어야 한다.

구현은 같은 Next.js 앱과 같은 Supabase를 기준으로 통합했다. 실제 운영 연결은 관리자 설정과 Preview 왕복 검수 뒤 사용자 최종 승인을 받아 진행한다.

후속 회원가입 점검에서 사용자는 비밀번호 규칙·보기 기능·필수 동의 전체선택을 요청했고, 가입 진행 뒤 검은 서버 오류 화면을 제보했다. 첫 화면의 중복 연령 체크는 제거했다. 다만 현재 문자 OTP는 전화번호 소유만 확인하고 생년월일을 확인하지 않으므로, 휴대전화 인증을 나이 확인으로 간주하지 않는다는 제한을 기록한다. 만 14세 미만 가입을 실제 허용하려면 법정대리인 동의 확인 절차가 별도로 필요하다.

사용자가 실제 회원가입 가능 여부 검수를 요청해 운영 주소와 최신 GitHub/Vercel 배포를 대조했다. 최신 통합 코드는 GitHub Preview에 배포되어 있으나 Vercel 로그인 보호가 적용되어 있고, 운영 `zipsin.net/signup`은 404였다. 따라서 현재는 일반 사용자가 운영 주소에서 가입할 수 없으며, 실제 Supabase 회원 생성도 아직 확인하지 못했다. GitHub 연결 유무와 회원 데이터 저장은 별개이고, 최종 확인은 접근 가능한 Preview에서 테스트 가입 후 Supabase Auth Users와 관련 테이블을 함께 확인해야 한다.

이후 관리자 세션에서 Preview 회원가입을 실제 제출했으나 `service_unavailable`로 실패했다. Vercel 환경값 부재, 집신체크 계정 연결 migration 누락, Supabase Site URL의 localhost 설정과 빈 Redirect URL 목록을 확인했다. 이메일은 활성화됐지만 이메일 확인은 꺼져 있고 Phone·Google·Kakao도 비활성이다. 사용자가 오늘 배포를 원하더라도, 외부 인증 공급자 없이 가능한 이메일·아이디 범위와 모든 인증을 갖춘 정식 범위 중 하나를 먼저 확정해야 한다.

사용자는 무료 범위의 이메일·아이디 가입부터 연결하고, Vercel로 Supabase 서버 비밀값을 안전하게 전달하는 작업을 승인했다. 이에 기존 비밀값을 대화·Git·문서에 노출하지 않고 새 통합 브랜치 Preview에 연결했다. Supabase에는 가입 유입 기록과 온보딩 RPC를 적용했다. Google·Kakao·Naver와 문자 인증은 개발자 키나 공급자 없이 사용할 수 없으므로 화면에서 비활성 상태를 유지한다. Supabase 장애 공지 중 Site URL 저장은 반영되지 않아 이메일 링크·OAuth를 열기 전 재시도가 필요하다.

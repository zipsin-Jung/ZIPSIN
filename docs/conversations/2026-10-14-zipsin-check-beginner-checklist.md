# 집신체크 초보자 체크리스트 대화 기록

## 사용자 문제 제기

- `괜찮음`, `다시 확인`, `미확인`은 결과가 모호하다.
- 사회초년생은 `바닥 모서리`, `배관 주변`만으로 정확한 위치와 이상 신호를 알 수 없다.
- 현장에서 모든 항목을 길게 확인하기 어려우므로 가장 중요한 세 항목을 먼저 보여야 한다.
- 관리비·수리 약속·주차처럼 사람에게 물어볼 내용은 현장 관찰과 분리하고 순서를 정해야 한다.

## 확정 결과

- 상태를 `문제없음 / 문제 있음 / 못 봤음`으로 변경한다.
- 우선 3개는 물·배수, 곰팡이·누수, 온수·난방이다.
- 나머지 항목도 삭제하지 않고 아래에 제공한다.
- 상세 체크에는 정확한 위치, 사용자가 할 행동, 발견할 이상 신호, 다음 행동을 적는다.
- 물어볼 것 8개는 별도 화면에서 비용과 수리 약속부터 기록한다.
- 사용자가 승인한 이미지 시안의 정보 구조를 실제 웹 화면에 반영한다.

## 후속 확정

- 상세 체크 버튼은 처음 보는 사용자가 놓치지 않도록 빨간 테두리와 `꼭 눌러보세요` 문구로 강조한다.
- 사용자가 한 번 상세 체크를 열면 강조를 해제하고 일반 초록 상태로 돌린다.
- 옵션 상태를 우선 3개 다음의 첫 항목으로 올린다.
- 좋음·나쁨을 다시 정리하는 방문 요약 페이지는 현장 흐름에 도움이 되지 않으므로 완전히 제거한다.
- 체크 완료 버튼은 `저장하고 내가 본 집으로`로 바꾸고 전체 집 목록으로 바로 이동한다.

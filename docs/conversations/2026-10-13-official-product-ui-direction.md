# 정식 출시 제품 UI 방향 보정

## 사용자 피드백

- 집신은 가상 데모가 아니라 실제 사람이 사용할 정식 출품 수준으로 만든다.
- 제품 화면에 `데모입니다`, `테스트`, `준비 중`을 광고하듯 노출하지 않는다.
- 작은 글자, 낮은 대비, 평면적인 흰 카드 나열을 피한다.
- 짙은 잉크·네이비와 청록을 중심으로 신뢰감 있는 고대비 문자와 절제된 그라데이션을 사용한다.
- 이탈은 기능이 없어서 생기게 하지 말고, 지금 실제로 작동하는 동선만 보여준다.

## 반영 결정

1. 랜딩페이지와 앱 화면을 구분하되 로고와 브랜드 신뢰감은 이어간다.
2. 앱 헤더는 홈과 집 기록의 작동하는 메뉴만 제공한다.
3. 업무 홈은 핵심 문장과 현재 공간을 큰 면으로 보여주고, 집 등록과 집 목록을 즉시 시작할 수 있게 한다.
4. 공개 검색과 주소 기반 자동 병합은 하지 않는다. 권한 있는 사람만 정확한 주소를 본다.

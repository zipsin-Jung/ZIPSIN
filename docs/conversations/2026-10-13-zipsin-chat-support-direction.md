# 집신 챗과 대표 직속 고객지원 방향

사용자는 집신 안에서 중개사·임대인·임차인·수리기사가 카카오톡처럼 대화하기를 원한다. 개인 휴대전화 연락처와 카카오톡을 업무에 사용할 필요를 줄이는 것이 목적이다.

모든 사용자에게 `집신 고객지원` 공식계정을 보여주고, 초기에는 집신 대표가 직접 답한다. 대표의 개인 신원은 노출하지 않지만 사람이 답하고 있다는 사실은 숨기지 않는다. 향후 AI를 붙일 때에는 AI임을 표시하고 사람 연결을 제공한다.

사용자는 별도 담당자 개념이 없음을 명확히 했다. 채팅 접근은 사무소 소속, 계약 관계, 방 초대와 참여, 수리방 초대로 결정한다.

현재 최소 기능에서는 사용자가 사진을 직접 채팅에 올린다. 채팅 사진을 집 기록에 자동 업데이트하는 기능은 후속으로 남긴다.

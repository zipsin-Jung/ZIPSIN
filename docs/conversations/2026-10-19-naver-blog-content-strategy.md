# 2026-10-19 네이버 블로그 콘텐츠 전략 대화 정리

## 사용자 요청

- 기존 글을 삭제하지 않고 집신 블로그를 다시 활성화한다.
- 고딕체, 가운데 정렬과 문단 흐름에 맞는 이미지를 사용한다.
- 부동산 정보와 이슈는 사실 근거만 담는다.
- 제품의 핵심 해결 방식을 지나치게 공개하지 않는다.
- 단순 홍보 글이 아니라 검색 유입이 생기는 정보 글을 작성한다.
- 집 보기 글에서 `https://ck.zipsin.net/`으로 자연스럽게 연결한다.
- 임대관리와 집신 소개 글에서는 `https://zipsin.net/`으로 연결한다.

## 비판적 회고

- 초기에 작성한 글은 문제 제기에 집중해 검색자가 원하는 구체적인 답이 부족했다.
- 추상적인 제목, 반복되는 출시 준비 안내와 일반적인 생성 이미지만으로는 검색 클릭과 신뢰를 만들기 어렵다.
- 이후 운영은 부동산 실무·집 보기 정보 80%, 브랜드 이야기 20%로 전환한다.
- 한 글에는 하나의 검색 질문만 다루고 공식 출처, 즉시 실행할 체크리스트와 분명한 아하 포인트를 포함한다.

## 결정

- 집 보기·체크리스트 글의 행동 유도는 집신체크를 사용해 후보 집을 같은 기준으로 비교하는 경험에 연결한다.
- 집신체크는 로그인 없이 사용 가능하며 체크·메모·사진이 현재 브라우저에만 저장되고 외부로 전송되지 않는다는 실제 안내를 함께 표시한다.
- 일반 집신 홈페이지는 출시 준비 중이며 실제 가입·결제가 진행되지 않는다는 현재 상태를 정확히 표시한다.
- 기존 글의 삭제, 비공개 글 공개 전환과 미공개 제품 구조 공개는 금지한다.

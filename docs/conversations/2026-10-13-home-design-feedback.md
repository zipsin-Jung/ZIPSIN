# 로그인 홈 디자인 피드백 대화 기록

## 사용자 피드백

- 현재 홈에는 사진과 디자인적 요소가 없고 글꼴·글자 크기·가시성이 부족하다.
- 집신을 써야 하는 페인 포인트와 첫 아하 모먼트가 전달되지 않는다.
- 쉽게 알아볼 수 있는 벽걸이 에어컨보다 정보를 확인하기 어려운 천장형 에어컨이 실제 사례에 가깝다.
- 길에서 급히 부동산 계약서가 필요하지만 종이가 집에 있어 한 장씩 찾아야 하는 번거로움을 보여줘야 한다.
- 컴퓨터 폴더의 여러 집 사진과 휴대전화 개인 사진이 뒤섞여 어느 집인지 기억하기 어려운 문제를 보여줘야 한다.
- 가입 후 고객이 필요한 기록을 스스로 인지하지 못하므로 체크하듯 하나씩 등록하게 해야 한다.
- 각 기록이 왜 필요한지 작게 펼쳐 보는 상세 설명이 필요하다.
- 수정된 이미지 방향을 승인하고 이대로 진행하도록 요청했다.

## 반영 결정

- 첫 장면은 `흩어진 사진과 파일`로 고정한다.
- 종이 계약서와 천장형 설비 장면을 다음 사례로 배치한다.
- 교육용 이미지는 실제 사용자 기록으로 가장하지 않는다.
- 집별 기록 시작 체크리스트와 `왜 필요한가요?` 상세 설명을 홈의 핵심 상호작용으로 만든다.
- 완료 표시는 실제 저장 데이터만 사용한다.
- 가입 초기 홈과 기록이 쌓인 업무 홈을 구분한다.

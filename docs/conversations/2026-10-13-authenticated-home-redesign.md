# 로그인 홈·체크리스트 재설계 대화 기록

- 날짜: 2026-10-13
- 범위: 로그인 후 홈의 복잡도, 시각 전달력, 이미지와 체크리스트

## 사용자 문제 제기

사용자는 직접 그린 My Home과 체크리스트 화면을 제공했다. 현재 개발된 집신은 글자가 과도하게 크고 글 중심이며, 사진과 디자인 요소가 없어 읽고 싶지 않고 신뢰와 사용 의지가 생기지 않는다고 평가했다. 동시에 직접 그린 화면도 기능이 너무 많아 복잡해질 수 있어, 개발 전에 대화로 구조를 풀고 싶다고 요청했다.

## 사용자가 원하는 장면

- 노트북·컴퓨터에서도 여러 집을 관리할 수 있는 화면
- 현재 집을 고르고 집별 기록을 이어가는 구조
- 집신 가입 후 필요한 기록을 체크하듯 하나씩 등록하는 흐름
- 사용자가 필요성을 모를 때 `왜 필요한가요?`를 짧게 열어보는 설명
- 흩어진 컴퓨터 파일과 휴대전화 사진
- 외출 중 급히 필요한 계약서와 집에 있는 종이 서류
- 모델명·설치·수리 이력을 확인하기 어려운 천장형 에어컨
- 실제 사진과 기록이 들어가 전달력이 생기는 화면

## 조사·회의 결론

직접 시안에서 좌측 탐색, 현재 집 선택, 체크 진행, 최근 기록의 원리를 채택한다. 다만 첫 화면에 모든 메뉴와 빈 카드가 보이면 제품이 더 복잡해진다. 따라서 하나의 공통 앱 셸 안에서 사용자의 실제 데이터 상태에 따라 필요한 내용을 단계적으로 공개한다.

1. 집 없음: 예시 이미지 한 장과 다음 행동 한 개
2. 집 있음·기록 적음: 실제 집과 기록 6개 체크리스트
3. 기록 쌓임: 오늘 할 일, 최근 집, 최근 기록, 채팅, 일정

체크리스트는 계약 전 24개 검사 기능을 새로 만드는 것이 아니다. 집 연결, 상태 사진, 계약·날짜, 설비, 수리·변경, 사람 초대의 여섯 실제 기록을 준비하는 안내로 한정한다.

교육용 이미지는 실제 고객 기록이 아님을 표시하고, 활동 사용자의 집 카드에는 권한 있는 실제 업로드 사진만 사용한다. 집신 AI와 실제 데이터가 없는 완료율은 노출하지 않는다.

## 현재 승인 상태

개발 프롬프트와 방향은 사용자 검토 대기다. 제품 코드는 이번 작업에서 변경하지 않는다. 사용자가 방향을 승인하면 1440px과 390px의 첫 사용자·활동 사용자 시안을 한 번에 제출한 뒤 구현 단계로 넘어간다.

# 2026-10-18 집신클린 기획 대화 요약

## 흐름
1. 인수인계 문서(집신 클린 피그마 9화면) 확인 → 피그마 9개 화면 실제 존재 확인. 중복(P02·P05), 절차 불일치(P03·P04), C01 PC 크기, 견적 카드 같은 문구, 옛 로고를 지적.
2. 대표 결정: 집신 본체와 겹치는 화면 먼저, 클린 거래는 시안 유지. 도메인 `cl.zipsin.net`.
3. 경쟁 분석(클린벨·짐싸): 둘 다 거래가 끝나면 정보도 끝남. 집신 자리 = 계약 시점 접점 + 집 기록.
4. 대표 경험: 구옥·통베란다 견적 20만 원 → 반쯤 청소 후 이삿짐 시간을 무기로 17만 원 추가(총 37만 원). 이 장면을 막는 것이 핵심.
5. 결론(킥): 고객은 판단하지 않는다. 판단 근거는 집신 사진에 있다. 가격은 예약 시 확정, 현장 변경 없음 → DEC-031.

## 대표가 직접 한 판단
- 업체를 집신이 직접 영업, 처음엔 과하게라도 대표님을 직접 만나 검증
- 기준은 금액이 아니라 실력
- 동네 이모님은 판가름하지 않음, 업체가 아니어도 됨(개인·이모님 트랙)
- 세차처럼 메뉴를 나누고 시간도 기준에 포함
- 고객 말장난도 막아야 함(양쪽 공정)
- "등급에 모든 게 들어 있어야 한다", "집신에 사진이 있으면 된다"

# 이미지 중심 공개 홈·로그인 홈 승인 대화

- 일자: 2026-10-14
- 사용자 승인: 이미지 중심 개편안에 맞게 진행

## 사용자 요구 요약

- 기존 화면에서 무엇이 바뀌었는지 알기 어렵고 승인한 이미지가 보이지 않았다.
- 글만 크게 늘어놓지 말고 실제 생활 문제를 이미지로 먼저 이해하게 해야 한다.
- 집 사진 분산, 종이 계약서, 천장형 에어컨 이력, 도배·장판 입주 전후 상태를 보여줘야 한다.
- 로그인 후 화면은 기능이 많고 어렵게 보이지 않으면서도 D-day와 다음 행동을 바로 이해해야 한다.

## 확정한 방향

- 공개 홈에는 네 생활 장면 이미지를 실제 파일로 넣는다.
- 장면 선택 시 이미지와 해당 집신 제품 UI가 함께 바뀐다.
- 사무소 인수인계와 퇴거 가치는 삭제하지 않고 하단 핵심 가치로 유지한다.
- 로그인 홈에서는 D-day, 다음 행동, 사진·문서·집 대화 순으로 보여준다.
- 안전한 실제 사진 연결이 준비되기 전에는 교육용 이미지를 실제 집 카드에 넣지 않고 `사진 없음` 상태를 사용한다.
- 기존 권한 구조와 데이터베이스는 이번 시각 개선에서 바꾸지 않는다.
- Production 배포는 사용자 최종 승인 전까지 진행하지 않는다.

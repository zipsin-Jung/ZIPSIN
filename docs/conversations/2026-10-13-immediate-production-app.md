# 사전가입이 아닌 즉시 사용형 집신

- 일자: 2026-10-13
- 사용자 결정: 현재 서비스는 사전 회원가입이나 데모를 광고하는 페이지가 아니라, 설명을 이해한 뒤 바로 가입·로그인하고 사용하는 정식 웹앱이어야 한다.
- 진입 기준: 비로그인 사용자는 실제 로그인·회원가입으로, 로그인 사용자는 업무 홈으로 이동한다.
- 앱 홈 기준: 집신의 핵심 흐름을 짧게 설명하되 실제 최근 집·새 메시지·다음 행동만 표시한다.
- 금지: 가상 고객 수, 가상 업무 수치, 체험·데모·사전가입 문구, 담당자 중심 구조.
- 현재 제한: 최신 로컬 코드는 Preview에 반영되지 않았고 DB migration도 미적용이므로, 사용자 승인 전에는 원격 배포 상태를 최신 제품으로 표현하지 않는다.

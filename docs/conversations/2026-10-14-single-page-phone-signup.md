# 2026-10-14 회원가입 휴대폰 인증 배치 대화

## 사용자 문제 제기

사용자는 회원가입을 눌렀을 때 휴대폰 인증이 별도 단계로 보이는 이유를 물었고, 이메일 바로 아래에 휴대폰 번호와 인증번호 입력을 함께 배치해 한 화면에서 끝내길 요청했다.

## 확인된 원인

- 현재 비밀번호 가입은 Supabase 계정을 먼저 만든 뒤 `/signup/verify`로 이동한다.
- 현재 문자 API는 로그인 사용자를 전제로 하므로 입력칸만 첫 화면으로 옮겨서는 동작하지 않는다.
- Preview의 붉은 설정 오류는 Supabase migration 또는 서버 환경값 미적용 가능성이 있으며 구현과 외부 설정을 나눠 확인해야 한다.

## 승인된 방향

- 신규 비밀번호 가입은 `/signup` 한 화면으로 합친다.
- 휴대폰 OTP를 먼저 완료하고 그 전에는 계정을 만들지 않는다.
- 인증 증거를 서버에서 한 번만 소비한 뒤 최종 계정을 만든다.
- OAuth와 기존 미완료 계정 흐름은 보존한다.

상세 수락기준은 `docs/superpowers/specs/2026-10-14-single-page-phone-signup-design.md`에 기록했다.

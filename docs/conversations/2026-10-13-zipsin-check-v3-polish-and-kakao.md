# 2026-10-13 집신체크 V3 디테일·카카오 문의 대화 기록

## 사용자 요구

- 홈에 집신 로고와 이미지 요소를 넣고 사회초년생에게 어울리는 밝은 인상을 만든다.
- 홈에서 카드형 사용법, 미리 읽기, 급할 때 사진·메모 사용, 빨간 별의 의미를 바로 이해하게 한다.
- 필수 5개는 한눈에 보이게 유지하고, 상세 체크는 전체 목록이 아니라 각 필수 항목의 `상세보기` 안에 둔다.
- 상세 체크 뒤에는 전구 모양과 함께 확인 이유를 설명한다.
- 문의는 집신체크 전용이 아니라 집신 전체 문의가 사용자에게 바로 오도록 한다.
- 공개 카카오톡 채널 주소 `http://pf.kakao.com/_xhcxkFX`를 제품에 넣고 마무리한다.

## 반영 결정

- 필수 5개 카드를 기본 화면으로 유지하고 상세 19개를 5개 카드에 분배한다.
- 메모와 사진은 같은 진입점 `메모·사진`으로 유지한다.
- 홈에 로고, 핵심 가치, 4단계 사용법, 현장 팁, 필수 항목 미리보기를 추가한다.
- 모든 주요 화면에 `카카오로 문의` 고정 링크를 제공한다.
- 검색 노출과 무관하게 공개 채널 링크로 바로 이동할 수 있게 한다.

## 별도 후속

- 카카오톡 검색 노출은 채널 공개·검색 허용 후 카카오 반영 시간이 필요할 수 있다.
- 간편가입, 서버 저장과 여러 기기 동기화는 이번 로컬 V3 화면 개선에 포함하지 않는다.

## 홈 화면 2차 피드백

- 상단 메뉴의 문자형 이모티콘을 더 정돈된 아이콘으로 변경한다.
- 정사각형 히어로 옆 빈 공간에 최근 등록한 집 3채를 카드로 미리 보여준다.
- 등록한 집이 부족하면 `보러 갈 집 1·2·3` 빈 카드를 보여 바로 등록할 수 있게 한다.
- 중요 안내를 4개 사용법 카드보다 위로 올린다.
- 안내 문구는 `집 보러 가기 전에 체크리스트를 읽어봐 주세요`, `모든 체크를 다 할 필요는 없어요`로 정리한다.

## 체크 행동 안내·문의 캐릭터 피드백

- 사용법의 `미리 읽기` 설명은 `집 보러 가기 전에 읽어 보고 가면 좋아요`로 변경한다.
- `네모만 체크` 설명은 `전부 다 체크하진 않아도 돼요`로 변경한다.
- 사용자가 놓치지 않도록 체크 화면 상단과 각 필수 카드에 상세 체크·메모·사진을 눌러보라는 포인트를 제공한다.
- 고정 문의 버튼의 `집신이`는 글자가 아니라 집신이 캐릭터를 뜻한다. 캐릭터와 `문의`를 표시하고 누르면 집신 통합 카카오톡 채널로 이동한다.

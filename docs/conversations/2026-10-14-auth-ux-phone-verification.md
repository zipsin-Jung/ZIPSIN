# 2026-10-14 로그인 이미지·아이디 중복·휴대폰 인증 대화 정리

사용자는 로그인 화면 왼쪽의 기존 설명·카드·캐릭터 대신 제공한 집/기록 시각화 이미지를 넣고, 미연결 소셜 로그인 아래 반복되는 `연결 설정 후 사용할 수 있습니다` 문구를 제거해 달라고 요청했다.

회원가입에서는 아이디를 제출한 뒤에야 중복을 아는 것이 아니라 입력 단계에서 `중복 확인`을 수행해야 한다고 지적했다. 진행 단계는 `1 집신과 함께 해요`, `2 휴대폰 인증`으로 간단히 보여주고, 실제 휴대폰 인증이 빠져 있는 현재 상태를 보완하길 요청했다. 계정 찾기도 이메일만이 아니라 이메일 또는 휴대폰으로 확인할 수 있어야 한다고 정리했다.

코드 확인 결과 DB의 아이디 고유 제약, 가입용 휴대폰 상태 테이블과 화면은 존재하지만 실제 SMS 공급자는 비활성이고 `/ck` 가입은 이전 결정에 따라 휴대폰 인증을 건너뛰고 있었다. 계정 복구도 이메일 링크만 지원했다.

여섯 역할은 집신체크의 익명 사용은 유지하되 집신 계정 생성과 서버 저장을 선택한 시점에는 실제 휴대폰 인증을 요구하는 방향을 권고했다. 사용자도 `인증까지 연결`을 승인했다. 실제 문자 공급자는 월 기본료 없이 건당 과금되고 국내 발신번호 등록을 지원하는 SOLAPI 직접 연동안을 제안한다. 실제 업체 계정·발신번호·비밀키·소액 충전은 사용자 명의와 비용이 필요한 외부 단계이므로 서면 명세 승인 뒤 진행한다.

# 2026-10-08 미션 5 CRUD 요청 정리

사용자는 부트캠프 IT 창업가 미션으로 기존 랜딩페이지에 Next.js·Supabase 기반 CRUD 1개를 연결해야 한다고 설명했다. 필수 항목은 데이터 명세, 등록·목록·상세·수정·삭제, 동적 라우팅, 페이지네이션, 입력·로딩·오류·빈 상태, Storage 업로드, Vercel 배포, QA, README, GitHub PR이다.

사용자는 GitHub 학습 전이며 작업에 시간을 허비하고 싶지 않다고 밝혀고, 중간 승인 요청 없이 완성 가능한 범위를 끝까지 진행하라고 지시했다.

이에 따라 개인정보 없는 `가상 수리 기록`을 선정했다. 사전가입 데이터를 CRUD로 사용하지 않은 이유는, 인증과 RLS를 제외하는 이번 미션에서 실제 이름·전화번호가 노출될 수 있기 때문이다. 기존 랜딩·영업 데모는 보존하고 `/records`를 별도 교육용 흐름으로 설계했다.

외부 계정 비밀값이 작업공간에 없는 경우, 코드·SQL·문서·자동검사와 로컬 브라우저 검수는 완성하되 실제 DB·Storage·Vercel 전체 순환은 미검증으로 명확히 남기기로 했다.

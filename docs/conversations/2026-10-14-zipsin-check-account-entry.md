# 2026-10-14 집신체크 계정 진입·서비스 왕복 대화 기록

## 사용자 요구

- 집신체크 오른쪽 위에 `집신 구경가기`와 `간편 로그인·회원가입`을 나란히 둔다.
- 집신에서도 집신체크로 다시 이동할 수 있게 한다.
- 체크 중 저장하기를 누르면 로그인 페이지로 이동한다.
- 실제 계정 연동 전에는 집신체크에 기록을 보존하고 `연동 준비 중`이라고 솔직하게 안내한다.
- 후보 집을 확정했다고 주소만으로 기존 집·계약에 자동 연결하지 않는다.

## 반영 결정

- 비회원 기록은 기존 localStorage·IndexedDB에 계속 보존한다.
- `집신에 저장`은 현재 후보 ID가 포함된 허용된 내부 복귀 경로를 로그인 화면에 전달한다.
- 운영 OAuth가 꺼져 있으면 Google·Kakao·Naver를 `준비 중`으로 표시한다.
- 실제 집신 계정 저장과 `내 집 등록`은 운영 인증·권한 설정 후 별도 활성화한다.
- 집 확정 뒤 내 집 등록은 주소, 계약 관계와 공개 범위를 확인하는 사용자 행동으로 유지한다.

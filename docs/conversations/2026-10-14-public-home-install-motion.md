# 공개 홈 설치·애니메이션 대화 기록

- 날짜: 2026-10-14
- 주제: 메인 화면 품질, 앱 다운로드와 이미지 애니메이션

## 사용자 피드백

- 오른쪽 위에 `앱으로 다운로드`가 필요하다.
- 전체 이미지에 센스 있는 애니메이션이 필요하다.
- 첫 홈 이미지의 애니메이션과 이미지 자체가 잘 보이지 않는다.
- 현재 메인 홈페이지가 유료 제품답게 보이지 않는다.

## 합의한 방향

- 가짜 앱스토어 링크 대신 실제 웹앱 설치를 제공한다.
- 지원 브라우저는 설치 프롬프트, iPhone은 홈 화면 추가 안내를 사용한다.
- 첫 세로 이미지는 확장 배경과 선명한 전경으로 가시성을 높인다.
- 네 장은 각각 모임·연속성·연결·관리 이력을 설명하는 서로 다른 1회 모션을 사용한다.
- 큰 외곽 카드와 중첩 테두리를 줄이고 이미지가 화면의 주인공이 되게 한다.
- 기존 한 화면·가로 캐러셀·가입·로그인·카카오 문의는 유지한다.
- 오프라인·푸시·네이티브 앱·Production 배포는 이번 범위에서 제외한다.

## 현재 상태

사용자가 채팅 설계를 승인했다. 서면 설계 문서를 작성했으며 문서 검토 뒤 구현계획과 개발로 넘어간다.

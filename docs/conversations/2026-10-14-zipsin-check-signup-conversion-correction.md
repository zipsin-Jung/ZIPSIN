# 2026-10-14 집신체크 회원가입 전환 수정

## 사용자 의도

- 집신 본 서비스가 자리 잡기 전, 지금 집을 구하는 사회초년생·임차인을 집신체크로 먼저 모은다.
- 회원가입이 핵심 성과이므로 가입 버튼을 `준비 중`으로 막지 않는다.
- 집신 본 서비스와 확정된 집 자동 등록만 후속 준비 범위로 남긴다.

## 반영 결론

- Google·Kakao 간편가입은 기본 활성화한다.
- 준비되지 않은 Naver는 비활성 버튼으로 노출하지 않는다.
- 일반 가입은 후보 이전 동의 없이 진행하고, 이전을 선택한 경우에만 동의를 받는다.

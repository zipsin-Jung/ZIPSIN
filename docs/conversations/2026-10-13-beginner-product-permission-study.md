# 집신 웹앱 준비와 초보자 학습 요청 정리

- 일자: 2026-10-13
- 상태: 학습자료 작성 완료, 기존 권한 권고안 승인 대기

## 사용자 요청

- 웹앱까지 무엇이 더 필요한지 알고 싶다.
- 집신 정의, 다섯 역할, 혼합 권한 모델, 초대와 종료, 현재 업무, 경쟁 대체재, 고객·가격 검증과 AWS IAM 원리를 쉬운 말로 공부하고 싶다.
- 사실·가설·추천·미결정을 나누고 최신 법령·공식 가격 출처를 확인한다.
- 20개 항목, 7일 공부 계획, 자가시험과 대상별 30초 설명문으로 만든다.

## 정리 결과

- 실제 웹앱의 최소 흐름을 `대표 가입→사무소 확인→직원 초대→집 5채→기록·할 일→담당 변경→인수인계→결제`로 정리했다.
- 공인중개사법과 AWS 공식 문서에서 역할 구분, 기본 거부, 최소 권한, 인증·권한 분리와 명시적 거부 우선을 확인했다.
- 경쟁 범위를 광고·메신저·문자·클라우드·업무관리·전자계약·대행·수첩·직원 휴대전화까지 넓혔다.
- 공식 가격은 현재 공개된 예시만 기록하고 광고·문자·매물관리처럼 계약별로 달라지는 비용은 실제 청구서로 확인하도록 구분했다.
- 가격 검증은 칭찬이 아니라 실제 집 5채, 직원 초대, 반복 사용, 결제와 8주 유지로 판단한다.

# 2026-10-15 Claude 협업 인수인계 대화 기록

## 사용자 요청

사용자는 지금까지 Codex와 진행한 집신 코드·문서·테스트·결정을 Claude에게 전체 인계해 두 에이전트와 다음 작업을 함께 이어가고자 했다.

특히 다음을 반드시 포함하도록 요청했다.

- 기획과 설계의 분리
- 기능 정의, 스펙, 테스트 케이스와 단위·스트레스·시나리오 검수
- 커버리지 네 지표 80% 이상과 대표 소스코드·테스트코드 대응
- PRD·유저플로우·UI/UX·구현·테스트 추적
- 순서 사전 보고와 사후 문서화
- 긴 대화, 결정, 작업로그, 모든 디렉토리와 문서의 GitHub 보존
- 에이전트별 SOC·SOP, 전체 최초 회의, 비판·시간선 에이전트
- 삭제 금지, 최종 결과물 보고와 사용자 승인
- 반복 가능한 운영 절차의 스킬 파일화

## 확인한 기존 체계

저장소에는 이미 총괄비서, 제품기획, UX·UI, 설계·개발, 검수·비판, 시간선·대안 분석의 여섯 역할이 각각 SOC와 SOP로 정의돼 있다. 공통 규칙은 새 기능의 전체 회의, G1~G6 게이트, TDD, 독립 검수, 기록과 Git 동기화를 이미 요구한다.

따라서 동일한 에이전트 파일을 다시 만들지 않고, Claude가 정본을 반드시 읽고 정확한 현재 상태에서 시작하도록 외부 에이전트 인계 계층을 추가하기로 했다.

## 결론

- 최상위 진입점 `CLAUDE_HANDOFF.md`를 둔다.
- 복사·붙여넣기 가능한 종합 프롬프트에 코드·문서·테스트·외부 연동·남은 일을 구분해 적는다.
- 실제 worktree, 브랜치, HEAD와 미커밋 변경을 명시하고 인계 요약보다 Git·파일 상태를 우선한다.
- 비밀키, OTP, 전체 전화번호와 외부 계정 ID는 인계물에 저장하지 않는다.
- 외부 협업 인계 절차를 `zipsin-memory-sync` 스킬과 템플릿에 추가한다.

현재 산출물은 사용자 최종 승인 전이므로 `승인 대기`로 보존한다.

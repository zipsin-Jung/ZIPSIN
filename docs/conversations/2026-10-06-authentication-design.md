# 2026-10-06 로그인·회원가입 설계 대화 기록

## 사용자 요구 변화

1. 기존 로그인 화면을 밝고 신뢰감 있는 고급 디자인으로 개선
2. 일반 로그인은 이메일이 아니라 아이디·비밀번호 사용
3. 이메일은 회원가입에서 수집
4. Google·카카오·네이버 간편 로그인도 유지
5. 버튼 문구는 `이메일로 회원가입`이 아니라 정확히 `회원가입`
6. 왼쪽 영역에서 집신이 집·계약·수리·사진·일정·비용 기록을 관리하는 플랫폼임을 한눈에 설명
7. 승인 시안을 실제 클릭·가입·로그인이 가능한 화면으로 개발

## 승인된 화면 방향

- 왼쪽: 집의 모든 기록을 한곳에서 관리한다는 설명과 `계약·입주 기록`, `수리·사진 보관`, `일정·비용 관리`
- 오른쪽: 간편 로그인 3종, 아이디·비밀번호, 로그인, 계정 복구, 회원가입
- 모바일: 인증 영역을 먼저 표시하고 플랫폼 설명은 아래에 배치

## 결정

- 별도 아이디와 비공개 매핑을 사용하고 Supabase Auth는 실제 이메일·비밀번호·세션을 담당한다.
- 가입 순서는 아이디·비밀번호·이메일, 이메일 확인, 전화 인증·이름, 필수 동의, 역할 선택이다.
- 이메일 일치만으로 소셜 계정과 일반 계정을 자동 병합하지 않는다.
- 구현 전 네 역할 회의를 거쳐 사용자에게 구조와 계획을 보고했고 사용자가 개발을 승인했다.

## 아직 사용자 확인이 필요한 항목

- 실제 Preview에서 DB migration과 이메일 왕복
- Google·카카오·네이버 실제 제공자 설정과 왕복
- 운영용 분산 로그인 요청 제한 공급자
- Production 공개

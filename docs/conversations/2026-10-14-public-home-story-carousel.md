# 공개 메인 4장 이야기 대화 기록

- 날짜: 2026-10-14
- 참여: 사용자, Codex

## 배경

사용자는 가로 시안보다 `위에서 흩어진 정보가 집신으로 쏟아져 모이는` 세로 구성이 집신의 의미를 더 잘 전달한다고 판단했다. 가로 이미지는 정보가 동시에 펼쳐져 정신없고 제목과 시선 경쟁이 생긴다고 평가했다.

## 이미지에서 확정한 의미

- 서류 더미: 계약서와 집 관련 문서의 분산
- 노트북: 수많은 집 사진을 찾기 어려운 상태
- 휴대전화: 임대인·공인중개사·201호와 반복한 통화
- 노란 대화 흐름: 반복된 집 관련 메신저 대화
- 달력·수리 사진: 일정과 설치·수리 이력
- 집 모양 ZIPSIN 화면: 흩어진 모든 정보가 집 한 채의 기록으로 정리되는 결과

## 메인 방향

- 승인 이미지를 첫 장으로 사용한다.
- 최종 네 장은 `모인다 → 이어진다 → 연결된다 → 가치가 된다`로 구성한다.
- 2장은 같은 집을 봄·가을·겨울로 나눠 사람은 바뀌어도 집의 안전한 관리 기록은 이어진다는 의미를 담는다.
- 3장은 개인 휴대전화의 구두 전달·통화·문자·개인 메신저·주소록이 뒤섞인 현재 문제를 보여주되, 외부 기록을 집신으로 가져오는 것처럼 보이면 안 된다. 외부 흐름은 중앙 집신 앞에서 끝나고, 오른쪽에는 사용자가 직접 초대한 사람·집별 연락처·집신 전용 채팅의 새 기록만 보인다.
- 4장은 자동차 비교를 쓰지 않고 `위치와 서류만 보고 계신가요?`라는 질문에서 출발한다. 에어컨·배관·난방·벽지·바닥의 관리 기록도 함께 확인해야 한다는 메시지와 `잘 관리한 시간은 집의 신뢰가 된다`는 브랜드 결론을 담는다.
- 장면은 한 페이지 안에서 옆으로 부드럽게 넘어간다.
- 점에 마우스를 올리면 해당 장을 볼 수 있고 좌우 화살표로도 이동한다.
- 자동재생은 한 번만 실행하고 마지막 장에서 멈춘다.

## 사용자 피드백

- 점을 사용한 장면 이동과 자동 전환을 긍정적으로 평가했다.
- 마우스를 점에 올려 장면을 바꾸고, 그렇지 않을 때는 옆 화살표를 클릭하는 방식을 요청했다.
- 네 장이 같은 시각 은유를 반복하면 안 되며 각 장은 전혀 다른 생활 문제를 보여야 한다고 수정했다.
- 1장과 2장 이미지를 확정했고, 3장은 전화·개인 채팅·주소록의 혼란과 집별 연락처·집신 채팅의 결과가 분리되도록 확정했다.
- 건물도 사람처럼 나이를 먹기 때문에 관리 이력이 필요하며, 이력이 흠이 아니라 잘 관리한 자산을 설명하는 근거가 되길 원한다고 밝혔다.
- 중고차 비교는 뜬금없을 수 있다고 판단해 제외하고, 집 내부에서 위치·서류와 관리 이력을 함께 확인하는 4번 이미지를 최종 선택했다.

## 실행과 검수 결과

- 사용자가 구현계획과 네 장 이미지 적용을 승인했다.
- 네 장을 영구 자산화하고 공개 홈에 실제 React 캐러셀로 적용했다.
- 모바일에서 같은 높이를 강제로 유지했을 때 짧은 장면 아래 큰 공백이 생긴 것을 시각 검수로 발견했다.
- 활성 장면의 높이를 측정해 부드럽게 조절하도록 바꿨고, 390px과 1440px 결과를 다시 확인했다.
- 외부 대화 자동 연동이 아니라 직접 초대·집별 연락처·집신 채팅부터 새 기록이 시작된다는 경계를 유지했다.

# 전역 카카오톡 문의 대화 기록

날짜: 2026-10-13

## 사용자 요청

- 공식 카카오 채널과 채팅 주소를 제공했다.
- 챗봇처럼 화면 오른쪽 아래에 항상 보이는 문의 진입점을 원했다.
- 현재는 AI가 아니라 집신 대표에게 바로 연결되어야 한다.
- 설계 설명 뒤 사용자가 구현을 승인했다.

## 확정한 내용

- 모든 공개·인증·앱 화면에 하나의 고정 문의 버튼을 둔다.
- 버튼은 공식 카카오 채널 채팅을 새 창으로 연다.
- 모바일에서는 앱 하단 메뉴 위에 놓고, 데스크톱에서는 오른쪽 아래에 둔다.
- 내부 고객지원은 삭제하지 않으며 장기 기록이 필요한 상담의 원본으로 유지한다.
- 외부 카카오 문의가 집신 기록에 자동 저장되지 않는다는 사실과 민감정보 전송 금지를 안내한다.
- 대표 직접 답변을 챗봇·AI·24시간 상담으로 과장하지 않는다.

## 후속 범위

AI 자동 응답, 카카오 상담내역 자동 동기화와 카카오 SDK 연동은 이번 범위에 포함하지 않는다. 별도 요구사항과 승인 뒤 검토한다.

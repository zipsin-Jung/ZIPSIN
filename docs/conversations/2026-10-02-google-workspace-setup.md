# Google Workspace 회사 이메일 설정 대화 요약

- 날짜: 2026-10-02
- 주제: `zipsin.net` 회사 이메일 개설과 DNS 연결

## 사용자 결정

- 회사 이메일 서비스는 Google Workspace Starter를 사용한다.
- 가입 화면의 회사·세금 정보는 개인 사업자 미등록 상태에 맞춰 진행한다.
- 관리자용 첫 계정을 만들고 도메인 소유권 확인과 Gmail 연결을 진행한다.
- 브라우저와 가비아 DNS 조작은 에이전트가 이어서 수행한다.

## 진행 결과

- Google Workspace 가입 및 관리자 계정 생성 완료
- 도메인 소유권 확인 완료
- Gmail MX 연결 및 활성화 완료
- SPF 발신 인증 레코드 등록 완료
- Google 관리자 계정으로 관리자 콘솔에 접속해 DKIM 키 확인
- 가비아에 DKIM TXT 등록 및 공개 DNS 조회 확인
- Google 관리자 콘솔에서 DKIM 인증 시작 완료
- 사용자 승인 후 회사 계정에서 외부 개인 Gmail로 시험 메일 발송
- Google 관리자 이메일 로그에서 `1/1 전송됨`과 내부 서버 전달 완료 확인
- 수신 계정 검색 색인 지연으로 SPF·DKIM `PASS` 원본 검증은 남음

## 다음 대화에서 이어갈 지점

수신 계정에서 시험 메일이 검색되면 원본을 열어 SPF와 DKIM `PASS` 여부를 확인한다. 이어서 외부 계정에서 회사 계정으로 답장을 보내 수신 방향을 확인한다. 이후 충분히 안정화되면 DMARC 관찰 모드를 검토한다.

실제 이메일 주소, 비밀번호, 결제정보, 인증 토큰은 이 기록에 저장하지 않는다.

# 유료 파일럿 Task 4 중간 기록

## 완료한 부분

- 사무소 내부 메모·수리·할 일 기록 생성 RPC와 서버 액션
- 권한 종료·공간·종류·중복 요청을 DB에서 재검증
- 집 상세의 최신순 타임라인과 빈 상태
- 기록 작성 화면과 저장 후 집 상세 복귀
- 할 일 목록과 `할 일 / 진행 중 / 완료` 상태 변경
- 작성·상태 변경 감사 기록

## 아직 남은 Task 4 범위

- 기존 기록의 허용 필드 수정 흐름
- 할 일 담당자·기한 입력과 오늘·지연·답변 대기 분류
- 현재 계약 공유 공간은 Task 6의 계약·관계자 초대와 함께 완성
- 사진·문서는 Task 5의 비공개 저장소 완성 전에 가짜 업로드 UI를 노출하지 않음

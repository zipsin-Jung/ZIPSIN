# 네이버 블로그 5편 발행 준비 작업 기록

- 작업일: 2026-10-20
- 상태: 로그인 대기, 미발행

## 수행 순서

1. 기존 블로그 운영 원칙과 발행 대기 원고 확인
2. 국토교통부·정부24·주택도시보증공사·국가법령정보센터 자료 확인
3. 검색 의도가 겹치지 않는 주제 5개로 원고 구성
4. 독자 관점·검색 의도·과장·개인정보·기능 설명을 비판 검수
5. 대표 이미지 5장과 본문 이미지 10장 생성·검수
6. 네이버 블로그 접속 상태 확인

## 준비한 글

1. 전·월세 집 보러 갈 때 체크리스트, 물부터 소음까지 9가지
2. 전입신고·확정일자·임대차 신고, 무엇이 다른가요?
3. 2026 주택 임대차 신고, 대상·기한·과태료 한 번에 정리
4. 세입자 퇴거 전 체크리스트, 보증금 반환 전에 남길 기록 8가지
5. 누수·보일러·도어록 수리비, 임대인과 임차인 중 누가 부담할까요?

## 변경 내용

- 전체 원고와 발행 순서, 태그, 이미지 배치, 출처, 비판 검수를 `docs/blog/2026-10-20-five-post-publication-package.md`에 기록했다.
- `public/images/blog/2026-10-20-five-posts/`에 16:9 이미지 15장을 저장했다.
- 이미지는 실제 주소·계약정보·상호·연락처를 포함하지 않도록 생성했다.
- 집신체크는 로그인 없이 브라우저에 저장되는 비교 도구로만 설명했다.
- 집신은 가상 3분 데모와 현장 문제 확인 단계이며 실제 수리 접수·결제·상담이 구현되지 않았음을 수리비 글에 명시했다.

## 검증 결과

- 이미지 15장 모두 1672×941 PNG로 확인했다.
- 각 글의 검색 질문이 겹치지 않도록 역할을 분리했다.
- 주택 임대차 신고 금액·기한·지역·과태료는 2026-10-20 현재 국토교통부 공식 안내를 기준으로 확인했다.
- 민법 제623조와 대법원 판례의 수선 의무 판단 기준을 확인했다.
- 네이버 블로그 접속 시 로그인 화면으로 이동해 편집과 예약 발행은 진행하지 않았다.
- 기존 게시물은 삭제·수정·공개 전환하지 않았다.

## 남은 일

1. 사용자가 네이버 로그인을 완료하면 원고 5편을 편집기에 입력한다.
2. 나눔고딕·가운데 정렬을 적용하고 글마다 이미지 3장을 문단 사이에 배치한다.
3. 공개 발행 직전 제목, 공개 범위와 예약 시각을 사용자에게 보여주고 확인받는다.
4. 확인 후 전체공개 예약 발행하고 실제 공개 화면을 검증한다.

- 세부 프롬프트는 각 글의 대표 장면과 본문 `아하 포인트`에 맞춰 수도·배수, 절차 구분, 신고 판단 요소, 입주·퇴거 비교, 수리비 판단 흐름으로 구성했다.

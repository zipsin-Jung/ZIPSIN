# 2026-10-08 집 키·홈 화면 방향 정리 작업보고

## 요청

오늘 논의한 홈페이지, 로그인 후 홈, 중요 일정, 과금 사례와 집 키 방향을 한 문서로 정리한다.

## 수행 순서

1. 기존 제품 명세와 권한 결정을 확인했다.
2. 네 역할의 제품·설계·비판 관점을 취합했다.
3. 확정 내용, 가설, 폐기 시안, 미결정 사항을 분리했다.
4. 장기 대화를 `docs/conversations/`에 저장했다.
5. 작업 결과와 다음 승인 지점을 기록했다.

## 작성 결과

- 대화 기록: `docs/conversations/2026-10-08-home-key-and-dashboard-direction.md`
- 공개 홈페이지와 로그인 후 홈의 목적을 분리했다.
- 로그인 후 홈의 첫 아하 모먼트를 `우리 집의 다음 중요 일정과 행동`으로 정리했다.
- 집 키를 영구 비밀번호나 소유권 증명이 아닌 역할·범위·기간 제한 초대권으로 정의하는 권장안을 기록했다.
- 상충하는 계약 상태를 한 집에 섞은 일정 시안은 폐기 대상으로 기록했다.

## 검증

- 개인정보, 연락처, 계좌번호, 인증정보와 실제 계약 자료를 문서에 포함하지 않았다.
- 기존 원칙인 `주소만으로 비공개 기록 접근 금지`와 충돌하지 않도록 확인했다.
- 제품 방향은 기록했지만 확정되지 않은 정책을 결정으로 표현하지 않았다.

## 남은 일

- 집 키가 없는 주소 검색자의 공개 범위 결정
- 최초 집 관리자 확인 방법 결정
- 로그인 후 한 집 홈 시안 제작과 사용자 승인
- 공개 홈페이지 시안과 로그인 후 홈 시안 분리

## 승인 상태

**기획 정리 완료 · 정책과 화면 사용자 승인 대기 · 구현 및 배포 미실행**

사용자가 배포 전 별도 승인을 요구했으므로 문서는 로컬 커밋까지만 저장하고 원격 푸시는 보류한다.

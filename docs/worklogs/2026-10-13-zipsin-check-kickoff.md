# 2026-10-13 집신체크 킥오프 작업 보고

## 수행 순서

1. 필수 시작 문서, 작업 규칙, 제품 문서와 현재 저장소 상태 확인
2. Google Drive의 과거 체크리스트 논의 조사
3. HUG, 국토교통·법령 관련 공공 근거 조사
4. 총괄·기획·설계·검수 네 역할의 최초 회의
5. 범위, 위험, 승인 게이트와 사용자 입력정보 통합
6. 킥오프·결정 제안·대화·작업 로그 작성 및 문서함 동기화

## 변경 내용

- 집신체크를 집신 단일 계정 안의 서브서비스로 권고했다.
- 첫 MVP를 `집 보기 → 현장 체크 → 후보 비교 → 선택적 가입`으로 제한했다.
- 단일 안전점수 대신 상태와 근거 중심의 비교를 권고했다.
- 후보집 개인 기록과 집신 장기 집 이력을 분리하고 명시적 전환 원칙을 세웠다.
- 구현 전에 필요한 개인정보·권한·법적 오인 방지 승인 게이트를 정의했다.

## 검증 결과

- 기존 집신 방향, 단일 계정, 주소만으로 접근 금지와 이전 계약자 개인정보 분리 원칙에 부합한다.
- Google Drive 과거 논의의 ‘체크리스트를 기록의 입구로 사용’하는 방향을 이어간다.
- HUG의 계약 전·중·후 셀프 체크리스트와 현행 주택임대차 관련 공식 자료를 근거로 조사했다.
- 코드는 변경하지 않았고 빌드나 브라우저 검수 대상이 아니다.

## 남은 일

- 사용자의 방향 승인
- 공식 출처가 연결된 세부 체크 항목과 요구사항 ID 작성
- 주소·사진·보존·삭제·공유 정책 결정
- 모바일 프로토타입과 현장 사용자 검증
- 승인 후 구현계획 작성

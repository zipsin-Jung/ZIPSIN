# 2026-09-30 에이전트 지침 설계

## 요청

집신의 네 에이전트에게 부여할 적절한 공통 지침과 역할별 지침을 정한다.

## 작업 순서

1. 공통 지침 정의
2. 역할별 책임·권한·금지사항 정의
3. 역할별 SOP 정의
4. 에이전트 간 인계 형식과 사용자 승인 단계 정의
5. 제품 문서 저장
6. 바탕화면 문서함과 GitHub 동기화

## 결과

- 공통 작업 절차, 기록, 안전과 집신 제품 원칙을 정의했다.
- 총괄비서, 기획·디자인, 설계·개발, 검수·비판 에이전트의 목적과 업무 경계를 정의했다.
- 각 에이전트가 해서는 안 되는 행동을 명시했다.
- 기획과 설계, 구현과 독립 검수를 분리했다.
- 표준 인계 형식과 사용자 승인 지점을 정의했다.

## 다음 단계

- 사용자의 검토와 수정 의견 반영
- 승인 후 실제 에이전트 지침 파일 생성
- 공통으로 사용할 스킬 파일 설계와 생성

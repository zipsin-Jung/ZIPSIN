## 요청

## 확인

- Google Drive에서 `집신 로고`, `집신이 캐릭터`를 검색했으나 검색된 세 파일은 다른 주제의 일반 이미지여서 사용하지 않았다.
- GitHub 기본 브랜치의 코드 검색에서는 로고·마스코트 원본이 별도로 검색되지 않았다.
- 프로젝트의 `public/images/zipsin-company-logo.jpg`와 `public/images/03_zipsin_mascot_9set(1).png`를 공식 시각 기준으로 사용했다.

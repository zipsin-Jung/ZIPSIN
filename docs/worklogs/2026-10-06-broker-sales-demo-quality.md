# 공인중개사 영업용 3분 데모 품질 검수

- 날짜: 2026-10-06
- 결과: 조건부 통과에서 수정 후 승인 대기

## 수행 순서

1. 승인 명세와 구현 추적표 대조
2. 대표·보조원 권한과 개인정보·비저장 고지 확인
3. 타입·테스트·커버리지·빌드 검사
4. 운영 미리보기 HTTP·경로 이탈 방어 검사
5. Safari 화면 확인과 Headless Chrome 반응형 캡처 한계 확인
6. 발견 결함 수정과 재검사

## 발견 및 수정

- 보조원에게 노출되던 담당 변경 동작을 제거하고 상태 함수와 UI 양쪽에서 차단했다.
- `처음부터`가 안내 화면이 아닌 대시보드로 가던 동작을 최초 안내 화면 복귀로 수정했다.
- 상태 로직만 계측하던 커버리지 범위를 핵심 UI까지 넓히고 대표 전체 여정과 역할별 권한 테스트를 추가했다.
- 화면 전환 뒤 본문 포커스가 이동하도록 보완했다.
- 모바일 시작 화면의 긴 한글 문장과 카드가 컨테이너 안에서 줄바꿈되도록 보완했다.
- 전이 의존성 `source-map-js`를 보안 패치 버전으로 갱신했다.

## 남은 확인

- Headless Chrome은 macOS 최소 렌더링 폭 때문에 320px·390px 실제 CSS 뷰포트 증거로 채택하지 않았다. 실제 휴대전화에서 가로 넘침과 손가락 3분 전체 흐름을 확인해야 한다.
- 실제 영업 대상 5명 중 4명 이상이 3분 안에 완주하고 제품을 `집별 기록과 사무소 업무 인계 서비스`로 설명하는지 측정해야 한다.
- 운영 배포와 실제 상담 접수는 이번 승인 범위가 아니다.

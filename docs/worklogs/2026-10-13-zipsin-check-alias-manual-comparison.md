## 수행 순서

1. 기존 등록·비교 코드와 승인된 설계를 확인했습니다.
2. 별명 입력, 중복 안내, 비교 자동 선택 제거와 비교 실행 버튼의 실패 테스트를 먼저 작성했습니다.
3. 모바일 하단 시트 형태의 별명 입력과 수동 비교 선택 흐름을 구현했습니다.

## 변경 내용

- `바로 체크`를 누르면 `이 집 별명 정하기` 시트를 먼저 엽니다.
- 빈 별명은 체크 시작을 막고, 중복 별명은 구분 안내만 표시합니다.
- 새 후보 생성 시 `compareCandidateIds`에 자동 추가하지 않습니다.
- 비교 화면은 2~3채 선택 후 `선택한 집 비교하기`를 눌러야 표와 집신 저장 연결을 표시합니다.
- 기존 후보·체크·메모·사진과 자동 별명 데이터는 삭제하거나 변환하지 않습니다.

# 2026-10-13 집신체크 비교 중심 V2 구현

## 수행 순서

1. V1 원본을 보존하는 V2 저장·이전
2. 여러 집 보관·비교 선택·사진 일괄 삭제
3. 간단·상세 등록과 수정
4. 현장 필수 5개와 메모 안 사진
5. 2~3채 선택과 동일 행 비교표
6. 안전한 전화·매물 링크·영구 삭제
7. 자동검사·실제 브라우저·독립 검수·GitHub 저장

## 변경 내용

- `zipsin-check:v2`를 추가하고 v1 후보 ID와 원본을 보존했다. 이전 항목 답·메모는 새 5개 항목에 대응해 보여주고, 이전 사진 키도 새 메모 시트와 비교표에서 읽는다.
- 별명을 비워도 `오늘 본 집 N`으로 바로 시작하며, 상세 등록에서 위치·금액·관리비·출퇴근·담당자·링크를 선택 입력한다.
- 현장 항목을 `물·배수`, `곰팡이·누수`, `채광·소음`, `창문·문`, `옵션·파손` 5개로 줄였다.
- 큰 결과는 `괜찮음 / 다시 확인 / 미확인`, 상세 네모 체크는 실제 행동 수행 여부로 분리했다.
- 사진은 메모 하단 시트에서만 추가·교체·삭제한다. 취소하면 그 시트를 열기 전 사진으로 복원하고, Escape·Tab 포커스를 지원한다.
- 저장된 집 중 2~3채를 선택하고 대표 사진·전체 사진 펼침·사진 수·메모·위치·금액·관리비·월고정비·출퇴근·현장 5개·담당자를 같은 행으로 비교한다.
- 전화는 유효한 번호만 `tel:`로, 매물 링크는 `http/https`만 연다.
- 영구 삭제는 텍스트 저장 가능 여부를 먼저 검증하고 사진 IndexedDB 삭제가 성공한 뒤 화면에서 기록을 지운다. 마지막 한 채도 목록에서 삭제할 수 있고, 어느 단계든 실패하면 기록을 유지한다.
- 손상된 V2 원본은 새 체크를 시작해도 덮어쓰지 않으며, 저장 실패한 상세 수정은 입력 화면을 유지한다.

- 개발 서버 새 세션의 실제 브라우저 콘솔 warning/error: 0건

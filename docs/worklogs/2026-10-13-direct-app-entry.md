# 랜딩 없는 실제 서비스 진입 변경

- 일자: 2026-10-13
- 상태: 구현·로컬 브라우저 확인 완료

## 요청

서비스 주소에서 긴 랜딩페이지를 스크롤하게 하지 말고 실제 사용할 로그인과 업무 화면으로 바로 진입하게 한다.

## 수행 순서

기존 진입점 확인 → 실패 테스트 작성 → 루트 진입 변경 → 랜딩 보존 경로 분리 → 전체 테스트·타입 검사·빌드 → 실제 브라우저 확인 → 문서·Git 저장

## 변경

- `/`는 비로그인 사용자를 `/login`, 로그인 사용자를 `/home`으로 보낸다.
- 기존 랜딩은 삭제하지 않고 `/about`에 보존했다.
- 로그인 화면의 소개 링크는 `/about`으로 연결했다.
- 체험용 랜딩이 실제 서비스의 첫 진입을 가로막지 않게 했다.

## 검증

- 새 진입 규칙 테스트를 먼저 실패시키고 최소 구현 뒤 통과시켰다.
- 타입 검사 통과
- 전체 41개 테스트 파일, 223개 테스트 통과
- Production build 통과
- 로컬 브라우저에서 `/`가 `/login`으로 이동하고 로그인 화면이 표시되는 것을 확인했다.
- 로컬 시각 확인에는 실제 인증정보가 아닌 개발용 빈 연결값을 사용했으므로 로그인 왕복은 검증하지 않았다.

## 남은 일

- 승인된 집신 챗 구현
- 사용자 최종 승인 뒤 원격 push·migration·배포

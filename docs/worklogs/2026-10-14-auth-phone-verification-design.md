# 로그인·회원가입·휴대폰 인증 설계 작업 기록

- 날짜: 2026-10-14
- 단계: 구현 전 서면 설계
- 브랜치: `codex/zipsin-shared-auth-integration`

## 수행 순서

1. 기존 로그인·회원가입·휴대폰 인증·계정 복구 코드를 확인했다.
2. 제품기획, UX·UI, 설계·개발, 검수, 시간선 관점으로 요구사항을 검토했다.
3. 실제 문자 공급자와 운영 비용을 공식 자료로 비교했다.
4. SOLAPI 문자 전송과 기존 Supabase 계정 구조를 결합하는 설계를 작성했다.
5. 제품 결정, 회의 기록, 대화 기록과 통합 설계서를 갱신했다.

## 정리한 변경 범위

- 로그인 왼쪽 영역을 사용자 제공 집신 기록 이미지로 교체
- 활성화된 간편 로그인만 표시
- 회원가입 아이디 중복확인 추가
- 회원가입을 `집신과 함께 해요`와 `휴대폰 인증` 두 단계로 정리
- SOLAPI 실제 문자 인증 연결
- 이메일 또는 인증된 휴대폰을 이용한 계정 찾기·비밀번호 재설정
- 집신체크에서 가입한 뒤 원래 화면으로 안전하게 복귀

## 검증 결과

- 문서 공백·충돌 검사: 통과
- 제품 코드 변경: 없음
- 빌드·브라우저 검수: 구현 전 단계이므로 미실행
- 운영 배포: 미실행

# 2026-10-08 코칭 조언·권한 모델 검토

## 수행 순서

1. 필수 인수인계·제품·작업 규칙 확인
2. 기존 집 키 재기획 회의와 역할·권한 명세 확인
3. AWS IAM, Verified Permissions, Cedar와 NIST 공식 자료 확인
4. RBAC·ABAC·ReBAC·혼합 모델 비교와 사전 부검
5. 조언 정리, 권고안, 결정 초안과 대화 기록 작성
6. 문서 링크·Git 변경·바탕화면 동기화 확인

## 변경 내용

- 코치님·강사님 조언을 제품, 사업 검증, 창업자 태도와 용어로 나눠 정리했다.
- AWS IAM의 기본 거부, 명시적 거부 우선, 요청자·자원·조건 평가 원리를 확인했다.
- 집신에는 RBAC + ReBAC + 제한적 ABAC 혼합 모델을 권고했다.
- MVP는 별도 외부 권한 엔진 대신 Supabase 관계 테이블·RLS와 Next.js 서버 판정으로 시작하도록 제안했다.
- `집 키`보다 `집 연결 초대`, `공유 승인`, `접근 종료`를 권장 용어로 정리했다.

## 검증 결과

- 기존 `DEC-002`, 공개형 V1 명세, 집 키 재기획 회의와 충돌하지 않음을 확인했다.
- 외부 사실은 AWS, Cedar와 NIST 공식 문서에 한정해 확인했다.

# 유료 파일럿 Task 3 — 직원 초대와 담당 배정

## 수행 순서

1. 토큰 원문 비저장, 48시간 만료, 철회, 일회 수락과 동시 수락 잠금을 테스트로 고정했다.
2. 대표만 소속공인중개사·중개보조원 초대를 만들고 철회하도록 RPC를 구현했다.
3. 초대받은 사람이 자기 계정으로 사무소명·예정 역할·접근 범위를 확인한 뒤 수락하게 했다.
4. 대표가 동일 사무소의 활성 직원만 활성 집에 배정·해제하도록 구현했다.
5. 집 등록 후 404가 나지 않도록 권한 기반 집 상세 입구와 빈 타임라인을 연결했다.

## 검증

- 집중 테스트: 8개 통과
- 전체 회귀: 36개 파일, 209개 통과
- 타입 검사: 통과
- 프로덕션 빌드: 통과
- Preview DB에서의 실제 동시 수락·RLS 실행은 Task 8까지 미검증이다.

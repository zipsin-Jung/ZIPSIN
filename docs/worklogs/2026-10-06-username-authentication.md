# 2026-10-06 아이디 인증·회원가입 구현 작업 기록

## 수행 순서

1. 네 역할 킥오프와 사용자 설계 승인
2. 상세 구현계획과 사용자 개발 승인
3. 아이디 정책·비공개 매핑 DB
4. 아이디·비밀번호·이메일 회원가입
5. 서버 전용 아이디 로그인
6. 승인 시안·간편 로그인 3종
7. 아이디 확인·비밀번호 재설정
8. 타입·단위·통합·커버리지·빌드·브라우저 검수

## 변경 내용

- `account_usernames`와 원자 아이디 예약 구조 추가
- 아이디 4~20자 정규화·예약어·중복 차단
- `/signup`, `/account-recovery`, `/reset-password` 추가
- `/login`을 간편 로그인 + 아이디·비밀번호 화면으로 교체
- 모바일에서 인증 영역을 먼저 표시
- 이메일 확인 뒤 기존 전화 인증·동의·역할 선택 흐름 연결
- 계정 존재 여부를 노출하지 않는 공통 로그인·복구 응답

## 남은 일과 제한

- 신규 migration은 아직 Supabase Preview에 적용하지 않았다.
- 실제 이메일 확인·복구 메일 왕복은 미검증이다.
- Google·카카오·네이버 실제 로그인 왕복은 제공자 키 설정 뒤 검증해야 한다.
- Production 분산 요청 제한 설정 전 아이디 로그인 기능을 공개하지 않는다.
- Production 공개는 사용자 별도 승인 대상이다.

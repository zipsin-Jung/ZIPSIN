# 유료 파일럿 Task 2 — 첫 집 등록과 집 목록

## 수행 순서

1. Task 1 권한 경계와 승인된 `REQ-PILOT-HOME-001`을 재확인했다.
2. 입력 검증, 재시도, 중복 제출, 사무소 경계, 자동 병합 금지 테스트를 먼저 실행했다.
3. 집·생성자 담당·감사 기록을 한 트랜잭션으로 만드는 RPC를 추가했다.
4. Next.js 서버 액션, 집 등록 폼, 집 목록과 업무 홈 연결을 구현했다.
5. 정식 서비스 품질을 기준으로 앱 셀, 업무 홈, 등록 폼과 목록을 고대비 네이비·청록 디자인으로 통일했다.
6. 집중 테스트, 전체 회귀, 타입 검사와 프로덕션 빌드를 분리해 확인했다.

## 변경 내용

- `create_home_for_office`: 활성 대표만 사무소 집을 만들고 담당·감사 기록을 원자적으로 생성한다.
- 멱등성 키로 중복 클릭과 재시도의 중복 집 생성을 막았다.
- 주소는 비공개 사무소 공간에 저장하고 다른 사무소의 동일 주소와 자동으로 합치지 않는다.
- 새 집 등록·집 목록·업무 홈을 연결했다.
- 화면에서 `데모·테스트·준비 중` 문구를 사용하지 않고, 작동하는 기능만 노출했다.

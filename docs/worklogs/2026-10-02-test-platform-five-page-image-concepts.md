# 테스트 플랫폼 5페이지 이미지 시안 작업 기록

- 날짜: 2026-10-02
- 단계: 화면 방향 검토용 이미지 시안
- 기준: 공식 집신 로고, 공식 집신이 캐릭터, 밝고 신뢰감 있는 고급 색상

## 수행 순서

1. 기존 빈 화면 시안과 공식 로고·캐릭터 자료 확인
2. 핵심 사용자 흐름을 5개 화면으로 정리
3. 같은 디자인 체계로 화면별 이미지 생성
4. 결과물을 프로젝트와 바탕화면 문서함에 보관
5. Git 변경사항 검토 후 시안 파일만 커밋·푸시

## 생성한 화면

1. `test-platform-flow-01-empty.png`: 첫 방문 및 집 등록 시작
2. `test-platform-flow-02-my-homes.png`: 등록한 집 목록
3. `test-platform-flow-03-home-records.png`: 선택한 집의 기록 타임라인
4. `test-platform-flow-04-new-record.png`: 새 기록 작성
5. `test-platform-flow-05-record-progress.png`: 기록 상세와 진행 상태

## 공통 설계 기준

- 고령 사용자도 바로 이해할 수 있도록 큰 글자와 큰 선택 영역을 사용했습니다.
- 담당자 배정 중심이 아니라 집과 기록 중심으로 구성했습니다.
- 흰색 바탕, 청록색 중심, 옅은 하늘색·민트색 보조, 금색 최소 사용 원칙을 적용했습니다.
- 공식 로고와 집신이 캐릭터의 형태를 공통 기준으로 사용했습니다.

## 검증 결과와 남은 일

- 이미지 5장의 화면 목적과 이동 순서가 구분되는지 확인했습니다.
- 실제 Next.js 페이지, 버튼 동작, 데이터 저장, 접수 기능은 아직 구현하지 않았습니다.
- 사용자 선택 후 확정된 시안을 기준으로 기능 정의, 사용자 흐름, 화면 상태와 테스트 케이스를 갱신해야 합니다.

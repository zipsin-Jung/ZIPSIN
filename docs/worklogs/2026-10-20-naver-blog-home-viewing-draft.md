# 2026-10-20 네이버 블로그 집 보기 체크리스트 원고

## 수행 내용

1. 최근 글과 겹치지 않는 `집 보러 갈 때 체크리스트` 주제를 선택했다.
2. 주택도시보증공사와 국토교통부의 공식 안내를 확인했다.
3. 제목, 본문, 대표 이미지, 본문 이미지 위치와 태그를 작성했다.
4. 독자 관점, 검색 의도, 과장 가능성, 행동 유도와 중복 여부를 비판적으로 검토해 원고를 개선했다.

## 결과

- 원고: `docs/blog/2026-10-20-home-viewing-checklist.md`
- 상태: 사용자 승인 전, 공개 발행 보류
- 예정 카테고리: 집 구하기·집신체크
- 예정 공개 범위: 전체공개

## 남은 일

- 사용자에게 최종 원고와 공개 범위를 보여주고 발행 승인을 받는다.
- 승인 후 대표·본문 이미지를 제작해 네이버 편집기에 나눔고딕·가운데 정렬로 배치한다.
- 공개 발행 뒤 URL, 모바일 가독성, 링크와 공개 설정을 확인한다.

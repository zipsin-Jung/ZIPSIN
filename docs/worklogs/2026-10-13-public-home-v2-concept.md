# 집신 공개 홈 V2 킥오프·시안 작업기록

- 작업일: 2026-10-13

## 수행 순서

1. 현재 `PublicHome`과 제품·기능·결정 문서 확인
2. 총괄비서·제품기획·UX·UI·설계개발·검수비판·시간선분석 여섯 역할 킥오프
3. 공개 홈 6장면과 표현·제외·승인 기준 정리
4. 집신 로고를 참조한 고충실도 데스크톱 전체 홈 시안 생성
5. 시안의 장면 연결·제품 설명·금지요소 자체 검수

## 결과

- 시안: `docs/design/assets/zipsin-public-home-v2-concept.png`
- 킥오프: `docs/meetings/2026-10-13-public-home-v2-kickoff.md`
- 시안은 홈노크의 비주얼을 복제하지 않고, 따뜻한 실사와 집신의 실제 제품 장면을 중신으로 구성했다.
- 생성 시안 안의 작은 한글은 일부 오타가 있으며 승인 후 실제 HTML·React UI에서 정확히 작성할 예정이다.

## 검증과 남은 일

- 시안에 6장면, 실제 가입·로그인 CTA, 세 사용자, 수리 과정, 권한 분리가 표현됨을 확인했다.
- 사전가입·데모·시세·세금·수납·등기부·허구 실적은 넣지 않았다.
- 사용자 승인 전이므로 제품 코드는 변경하지 않았다.
- 다음 단계는 G2 시안 수정 또는 승인이다.

## 앱 서비스 홈 방향으로 2차 수정

- 사용자는 1차 시안이 너무 랜딩페이지 같고 `앱 다운로드 하기`가 필요하다고 정정했다.
- 상단 주 행동을 `앱 다운로드`로 바꾸고, `집신 소개 · 주요 서비스 · 이용 방법 · 고객지원`을 탐색하는 정식 서비스 홈으로 재구성했다.
- 긴 6개 설득 섹션 대신 앱 다운로드 Hero, 4개 서비스 진입, 2개 핵신 제품 설명, 기능 허브, 이용·정책·고객지원으로 압축했다.
- 2차 시안: `docs/design/assets/zipsin-service-home-v3-concept.png`
- 시안의 QR과 앱스토어 배지는 배치 검토용이다. 실제 스토어 주소가 생기기 전에 가짜 다운로드 링크를 배포하지 않는다.

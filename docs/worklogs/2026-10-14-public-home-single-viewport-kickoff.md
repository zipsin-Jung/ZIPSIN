# 공개 홈 단일 화면 전환 최초 회의

- 날짜: 2026-10-14
- 상태: G1 제품·G2 UX 사용자 승인, 구현 시작

## 요청

공개 홈 아래 내용을 모두 제거하고 한 화면에서 네 장을 좌우로만 이동한다. 첫 장은 승인 이미지가 확대된 상태에서 집 쪽으로 모이는 느낌을 주고, 오른쪽에 핵심 메시지를 글 쓰듯 보여준다.

## 역할별 결론

- 총괄비서: 공개 홈만 변경하고 Production·로그인 후 제품은 보존한다.
- 제품기획: `흩어진 정보 → 집의 기록 → 가치`를 첫 장 한 문장으로 설명한다.
- UX·UI: 데스크톱 이미지 왼쪽·문구 오른쪽, 모바일 이미지 위·문구 아래로 구성한다.
- 설계·개발: 네 장을 실제 flex track으로 만들고 transform 기반으로 이동한다.
- 검수·비판: viewport overflow, 숨은 장 포커스, 감소된 모션, 큰 이미지 성능을 필수 검사한다.
- 시간선 분석: 지금은 합성 PNG의 카메라 이동을 사용하고, 레이어 자산이 생기면 개별 흡입 모션을 후속 검토한다.

## 작업 순서

요구사항·테스트 연결 → 실패 테스트 → 최소 구현 → 반응형·접근성 보완 → 전체 자동검증 → 실제 브라우저 → 문서·바탕화면·GitHub → Preview → 사용자 승인

## 제외

외부 메신저 연동, 로그인 후 기능, 데이터·권한·결제, Production 배포는 변경하지 않는다.

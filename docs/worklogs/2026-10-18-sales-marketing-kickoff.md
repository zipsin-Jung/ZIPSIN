# 집신 영업·마케팅 킥오프 작업일지

- 일자: 2026-10-18
- 상태: 기획 문서 작성, 사용자 승인 대기

## 수행 순서

1. 작업 현황, 인계, 제품 기준, 운영 규칙과 마이그레이션 문서를 확인했다.
2. 사업계획, 3분 데모, 2027 연간 계획, 고객검증 교과서와 관련 결정을 확인했다.
3. 여섯 역할 최초회의를 진행했다.
4. 영업 채널, 메시지, 퍼널, 4주 실험, 개인정보 최소화와 중단 기준을 통합했다.
5. 계획, 회의, 대화와 작업 기록을 문서화했다.

## 변경 내용

- `docs/25-sales-marketing-validation-plan.md`를 작성했다.
- 대표 직접영업 → 소규모 소개 → 콘텐츠 → 검증 후 유료광고 순서를 권고했다.
- 현재 단계 목표를 E3 현장증거와 E4 비용 있는 약속으로 제한했다.
- 실제 제품 준비 전 체험·결제·반복 사용을 완료로 표현하지 않도록 했다.

## 검증 결과

- 코드와 배포는 변경하지 않았다.
- 실제 접수·가입·저장·결제가 구현되지 않았다는 기존 기준을 유지했다.
- 집신을 수리 플랫폼으로 축소하지 않았고 공인중개사무소를 초기 결제 고객으로 유지했다.
- 개인정보, 실제 연락처, 정확 주소, 계약서와 계좌정보를 문서에 넣지 않았다.

# 공인중개사 영업용 3분 데모 구현

- 날짜: 2026-10-06
- 상태: 구현·자동검사 완료 · 사용자 승인 대기
- 요구사항: DEMO-001~006

## 수행 순서

1. 승인 명세와 기존 랜딩·PhoneDemo 확인
2. 비저장형 상태·가상 데이터 설계
3. `/demo`와 랜딩 Hero 진입 버튼 구현
4. 대표·보조원, 집·사건·담당변경·인수인계·기록 요약 연결
5. 단위·흐름 테스트와 80% 커버리지 기준 설정
6. 타입·테스트·빌드 검증
7. 추적표와 작업 기록 갱신

## 변경 내용

- 기존 `/`와 `PhoneDemo`는 보존하고 별도 `/demo` 정적 라우트를 추가했다.
- 실제 주소·연락처·계좌·계약서가 없는 가상 누수 사례만 사용한다.
- 상태는 React 메모리에만 있으며 API, 저장소, 외부 전송을 호출하지 않는다.
- 대표는 사무소 전체 우선순위와 담당자 변경을 체험한다.
- 보조원은 배정 업무와 이어진 완료·대기·다음 행동을 확인하며 담당자를 변경할 수 없다.
- 사건 상태에 따라 다음 행동과 완료 사진·영수증 예시가 바뀐다.
- 기록 요약은 다운로드가 아닌 PDF 미리보기이며 개인정보 기본 제외와 법적 효력 비보장을 표시한다.
- 모든 주요 화면에 비저장형 가상 자료 고지와 초기화 기능을 제공한다.
- 랜딩 Hero의 첫 CTA를 `공인중개사 3분 데모`로 연결했다.

## 데이터·권한·위협 검토

- 데이터 등급: 모두 공개 가능한 비식별 가상 데이터다.
- 권한: 담당자 변경은 대표 역할에만 허용하며 보조원 요청은 상태 함수에서 거부한다.
- 저장·API·인증·초대·다운로드가 없어 서버 인가 대상은 이번 범위에 없다.
- 새로고침 또는 초기화 시 최초 상태로 복귀한다.
- 위험은 실제 서비스로 오인하는 것이며 시작 화면, 상단 고정 고지와 각 결과 화면의 문구로 완화했다.

## 검증 결과

- `npm run typecheck`: 성공
- `npm run test:coverage`: 상태·권한·대표 전체 여정·초기화·보조원 화면, 총 9개 테스트 성공
- 전체 계측 커버리지: statements 91.8%, branches 97.01%, functions 86.84%, lines 92.85%
- `npm run build`: 성공, `/`와 `/demo` 정적 생성 확인
- `npm start` HTTP 검증: `/`, `/demo`, `/demo/`, `/demo.html` 200, 없는 경로 404, 인코딩된 상위 경로 접근 403
- Safari에서 운영 미리보기 시작 화면을 확인했다.
- Headless Chrome 캡처를 시도했으나 macOS 최소 렌더링 폭 때문에 320px·390px 결과를 실제 CSS 뷰포트 검증 증거로 채택하지 않았다.

## 독립 전 검수 수정

- 보조원 역할에서 인수인계 화면의 담당 변경 버튼이 노출되고 내부적으로 대표 역할로 강제 전환되던 권한 우회를 제거했다.
- 담당 변경 버튼은 대표에게만 표시되며 보조원에게는 대표만 변경할 수 있다는 안내를 표시한다.
- 역할별 버튼 노출을 확인하는 DOM 테스트를 추가했다.
- 정적 export가 `demo.html`과 `demo/` 보조 파일을 함께 만드는 구조에서 로컬 미리보기가 디렉터리를 먼저 선택하던 문제를 수정했다.
- `scripts/preview.mjs`는 디렉터리에 `index.html`이 없으면 같은 이름의 `.html` 파일을 찾는다. 기존 저장 루트 밖 경로 차단은 유지한다.
- `처음부터`는 안내 화면과 최초 가상 상태로 돌아가도록 수정했다.
- 화면 전환 뒤 본문으로 포커스를 옮겨 키보드·스크린리더가 새 문맥을 인지할 수 있게 했다.
- `SalesDemo.tsx`까지 커버리지 대상에 포함하고 대표 전체 여정·초기화·보조원 권한 통합 테스트를 추가했다.
- `source-map-js`를 보안 패치 버전으로 올려 `npm audit` 취약점 0건을 확인했다.

## 남은 일과 위험

- 자동 통합 테스트로 전체 클릭 흐름과 포커스 이동을 확인했지만 실제 320px·390px 모바일 뷰포트와 손가락 조작은 현장 전 최종 확인이 필요하다.
- 영업 대상 5명 중 4명이 3분 이내 완주하고 제품을 집별 기록·사무소 업무 인계 서비스로 설명하는지는 현장 검증이 필요하다.
- 운영 배포와 실제 상담 접수 연결은 이번 작업에 포함하지 않았다.

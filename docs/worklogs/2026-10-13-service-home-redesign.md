# 실제 서비스 메인 홈 개편

- 일자: 2026-10-13
- 상태: 구현·자동 검증 완료, 인증된 실제 브라우저 검수 대기

## 요청

긴 랜딩이나 로그인 화면만 보여주는 것이 아니라, 로그인 후 첫 홈페이지에서 집신이 어떤 플랫폼인지 바로 이해하고 실제 기능을 시작할 수 있게 한다.

## 수행 순서

기존 홈 확인 → 실패 테스트 작성 → 신규·기존 사용자 상태별 메인 홈 개편 → 담당자 문구 제거 → 집중 테스트 → 전체 테스트·타입 검사·빌드

## 변경

- 모든 홈 상태 상단에 `집의 모든 기록과 대화를 한곳에서 이어가세요`를 표시한다.
- 집신 사용 방식을 `집을 등록하고 / 기록을 남기고 / 함께 이야기합니다` 세 단계로 설명한다.
- 기존 사무소 사용자는 집 등록, 집 목록, 구성원 관리로 바로 이동한다.
- 신규 대표는 집신 설명과 사무소 생성 양식을 같은 첫 화면에서 본다.
- 다른 역할은 초대받은 공간이 아직 없다는 상태와 개인정보 보호 원칙을 본다.
- 실제로 작동하지 않는 채팅 버튼과 근거 없는 통계를 넣지 않았다.
- 채팅 접근이나 홈 문구에 별도 담당자 개념을 사용하지 않는다.

## 검증

- 변경 전 집중 테스트 3건이 예상한 문구·행동 차이로 실패하는 것을 확인했다.
- 구현 후 집중 테스트 3건 통과
- 타입 검사 통과
- 전체 41개 테스트 파일, 223개 테스트 통과
- Production build 통과
- 현재 로컬 환경에는 실제 Supabase 인증정보가 없어 로그인한 `/home` 브라우저 화면은 아직 검수하지 않았다.

- 집신 챗 구현 후 홈의 실제 대화 진입과 읽지 않은 수 연결

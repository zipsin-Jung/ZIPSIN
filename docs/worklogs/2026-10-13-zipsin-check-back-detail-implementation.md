# 집신체크 뒤로가기·상세 체크 보강 작업록

## 수행 순서

1. 브라우저 뒤로가기 재현과 원인 확인
2. 실패하는 회귀 테스트 작성
3. 화면 이동 기록·필수 표시·상세 24개 구현
4. 자동 검증과 실제 브라우저 검수
5. 문서·Git 반영

## 변경

- `ZipsinCheckApp`: History API와 `popstate`를 연결해 브라우저 뒤로가기를 내부 목록 복귀로 처리
- `CheckFlow`: 필수 5개에 `꼭 확인` 핀, 상세 19개 펼침/접기, 진행 개수 표시
- `catalog`: 7개 범주의 총 24개 항목과 현장 행동 체크 추가
- `storage`: 상세 항목 추가 후에도 v1 이전이 안전하도록 기존 매핑만 선택해 이전

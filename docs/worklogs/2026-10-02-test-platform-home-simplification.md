# 2026-10-02 테스트 홈 단순화

## 사용자 피드백

첫 화면의 담당자와 많은 정보가 어렵고, 나이 든 사람을 포함해 누구나 간단하게 사용할 수 있어야 한다.

## 변경

- 담당자, 역할 전환, 표, 통계와 복잡한 메뉴를 첫 화면에서 제거했다.
- `내 집 보기`, `새 기록 남기기`, `진행 중인 일` 세 행동만 크게 배치했다.
- 큰 글자, 넓은 누르기 영역, 도움말과 한 개의 최근 기록만 남겼다.
- 단순화 시안 `public/images/test-platform-home-concept-v2-simple.png`를 생성했다.
- 제품 방향을 `DEC-007`에 기록했다.

## 검증과 한계

- 생성 이미지를 직접 확인했다.
- 실제 웹페이지·접수·저장 기능은 구현하지 않았다.
- 담당자 기능은 삭제 확정이 아니라 첫 화면 제외와 후속 검토 상태다.

## 상태

단순화 방향 반영, 사용자 의견 대기

# 공개 메인 4장 스토리 캐러셀 기획 기록

- 날짜: 2026-10-14
- 상태: 기획·UX 설계 문서화 완료, 제품 코드 미변경

## 수행 순서

기존 작업 트리·문서·공개 홈 코드 확인 → 여섯 역할 최초회의 → 대안 비교 → 네 장 스토리와 전환 규칙 합의 → 설계·결정·대화 문서 작성 → 문서 링크 검증 → Git 저장

## 확정한 내용

- 공개 `/`의 Hero와 사례 탐색을 하나의 4장 이야기로 합친다.
- 1회 자동재생, 점 hover 선택, 이전·다음, 재생·일시정지, 키보드와 swipe를 제공한다.
- 과한 3D page curl과 무한재생을 사용하지 않는다.
- 네 장은 모인다→찾는다→이어진다→확인한다 순서다.
- 기존 제품 증거 UI를 재사용하고 실제 구현되지 않은 기능을 과장하지 않는다.

## 변경하지 않은 것

- 제품 코드와 이미지 자산
- 로그인 후 홈
- DB·권한·채팅·계약 동작
- Preview와 Production

## 검증

- 현재 최신 공개 홈 worktree와 기존 `ScenarioExplorer`, 시나리오 데이터, 제품 증거 UI를 확인했다.
- 새 설계에 비어 있는 요구사항이 없고, 네 장 순서와 전환 규칙이 결정문과 일치하는지 확인한다.

## 다음 작업

사용자가 서면 명세를 검토·승인하면 구현계획을 작성한다. 구현계획 승인 전에는 코드와 자산을 변경하지 않는다.

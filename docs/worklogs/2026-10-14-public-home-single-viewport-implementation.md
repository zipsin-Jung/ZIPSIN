# 공개 홈 단일 화면 구현 작업 기록

- 날짜: 2026-10-14
- 상태: Preview 실제 검수 완료, 사용자 승인 대기

## 요청

공개 홈을 긴 랜딩페이지가 아닌 한 화면으로 만들고, 승인 이미지 네 장을 좌우로만 이동하게 한다. 첫 이미지는 확대 상태에서 집으로 모이는 인상을 주고 오른쪽 핵심 문장은 글을 쓰듯 나타나게 한다.

## 수행 순서

기존 문서·코드 확인 → 여섯 역할 최초 회의 → 요구사항·결정 기록 → 테스트 실패 확인 → 최소 구현 → 반응형·접근성 수정 → 전체 검증 → 독립 검수·수정 → 문서·바탕화면·GitHub → Preview → 사용자 승인

## 변경 내용

- 공개 홈 아래 소개·기능·이용 방법·CTA·푸터를 제거했다.
- 헤더를 로고·로그인·`웹에서 시작하기`로 단순화했다.
- 네 장을 실제 flex 가로 트랙에 배치하고 100% 단위로 이동한다.
- 첫 장에 승인 이미지의 확대·축소 카메라 모션, 빛의 흐름과 핵심 문장 reveal을 적용했다.
- 모바일은 이미지 위·문구 아래, 데스크톱은 이미지 왼쪽·문구 오른쪽으로 구성했다.
- 비활성 장을 접근성 트리와 탭 순서에서 제외했다.
- 외부 연락 기록을 가져오지 않고 초대 후 집별 연락처·집신 채팅에서 새 기록을 시작한다는 경계를 명시했다.

## 테스트 중 수정

- 제거한 제품 카드의 예전 문구를 찾던 테스트를 현재 화면 계약에 맞췄다.
- 모바일에서 숨긴 자동재생 버튼 수를 화면 너비별 기대값에 맞췄다.
- 320·390px 핵심 문장 잘림과 1440px 오른쪽 문장 잘림을 수정했다.
- 문장 각 줄의 `scrollWidth`가 표시 너비를 넘지 않는 회귀 검사를 추가했다.
- 독립 검수에서 320px 다음 버튼이 viewport 아래로 밀리는 문제를 발견했다. 제어를 한 줄로 고정하고 320px에서 페이지 숫자만 숨겼다.
- 모든 보이는 제어의 우·하단이 viewport 안에 있는지 자동 검사한다.
- 768px에서 카카오 문의가 자동재생을 덮는 문제를 재현하고, 태블릿 너비에서 문의 버튼을 위로 올린 뒤 포인터 도달과 클릭 회귀 검사를 추가했다.

# 2026-10-18 네이버 블로그 초기 정비·첫 글 발행

## 수행 순서

1. 기존 글과 카테고리의 공개 상태를 확인했다.
2. 기존 글은 삭제하지 않고 기존 카테고리를 비공개로 전환했다.
3. 집신 브랜드 정보와 메뉴·카테고리를 정리했다.
4. 첫 글과 대표 이미지를 작성해 임시저장했다.
5. 사용자에게 제목·카테고리·공개 범위를 보고하고 발행 승인을 받았다.
6. 전체공개로 발행한 뒤 공개 화면과 기존 카테고리 잠금 표시를 확인했다.

## 변경 내용

- 블로그명: `집신 | 집 한 채의 기록과 업무`
- 닉네임: `집신지기`
- 소개: `계약부터 입주·수리·퇴거까지, 집 한 채의 기록과 다음 할 일을 연결합니다.`
- 프로필: 집신 회사 로고
- 상단 메뉴: 블로그와 집신 중심으로 단순화
- 새 분류: `집신 소개`, `공인중개사 실무`, `집 기록 이야기`, `창업·개발 기록`
- 첫 글: `공인중개사무소의 집 사진, 담당자가 바뀌면 어디에 남을까요?`
- 공개 주소: `https://blog.naver.com/2hiworld/224445649666`

## 검증 결과

- 공개 화면에서 첫 글 제목, 본문, 태그 9개와 `집신 소개` 분류를 확인했다.
- 공개 화면에서 블로그명, 닉네임과 소개문을 확인했다.
- 기존 카테고리에 잠금 표시가 유지되는 것을 확인했다.
- 기존 글은 삭제하지 않았다.
- 첫 글에는 현재 실제 가입·저장·접수가 아니라 가상 자료 기반 3분 데모와 현장 문제 확인 단계임을 명시했다.

## 남은 일

- 두 번째 글부터는 인터뷰에서 확인된 문제나 명시적인 가상 사례만 사용한다.
- 인스타그램은 계정 연결과 게시물 형식 합의 후 별도로 준비한다.
- 네이버 검색 노출과 유입은 발행 직후 수치가 아니라 주 단위로 확인한다.

## 반복 운영 자동화

- 화요일·금요일 오전 10시에 다음 글을 준비하고 비판적으로 검수하는 자동화를 활성화했다.
- 일요일 오후 6시에 최근 7일 성과를 회고하고 다음 주 주제 2개를 제안하는 자동화를 활성화했다.
- 기존 글 삭제·공개 전환은 자동화 범위에서 제외했다.
- 외부 공개 발행은 사용자 명의의 게시 행위이므로 최종 원고와 공개 범위를 보여드린 뒤 발행 직전 확인을 받도록 설정했다.

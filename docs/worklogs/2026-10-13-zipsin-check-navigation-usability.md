# 2026-10-13 집신체크 이동·가시성 개선

## 사용자 문제

- 작성 중 `뒤로가기`와 `목록`에 의존해 현재 위치와 다음 행동을 알기 어려웠습니다.
- 체크 중 홈으로 가려면 화면을 여러 번 벗어나야 했습니다.
- `취소`가 작성 내용 취소인지 전체 기록 취소인지 불명확했습니다.

## 변경

- 모든 `/ck` 주요 화면에 `홈 · 내가 본 집 · 체크 · 비교` 고정 메뉴를 추가했습니다.
- PC에서는 상단, 모바일에서는 하단에 고정했습니다.
- 현재 위치를 배경색과 `aria-current` 상태로 표시했습니다.
- 현재 후보가 없거나 비교할 집이 2채 미만일 때는 해당 메뉴를 비활성화합니다.
- `방문 끝내기`를 `체크 결과 보기`로, `취소`를 결과가 분명한 닫기 문구로 교체했습니다.
- 체크 상태에 `자동 저장됨`을 표시했습니다.

## 검증

- 실패 테스트로 홈 이동 후 체크 기록 유지와 주요 메뉴 상태를 먼저 재현했습니다.
- Vitest: 27파일 132개 통과
- TypeScript: 통과
- Next.js 16.4.0 Production build: 통과
- Chromium desktop·390px: 6개 통과
- Vercel Preview(`3e1c00c`): 실제 브라우저에서 체크 → 홈 → 현재 집 체크 재진입을 검수했고, `물·배수` 선택과 `1/5` 진행 상태가 유지됨을 확인했습니다.
- 실제 브라우저에서 홈·내가 본 집·체크·비교 메뉴의 상시 노출과 현재 화면 강조를 확인했습니다.

Production·DNS는 변경하지 않았습니다.

# 집신 챗·공식 고객지원 명세 작업기록

- 일자: 2026-10-13
- 상태: 정식 명세 사용자 검토 대기

## 요청

카카오톡처럼 집신 자체 채팅을 만들고, 모든 사용자에게 집신 대표와 연결되는 공식 고객지원 채팅을 제공한다. 담당자 개념은 사용하지 않는다. 사진은 현재 직접 업로드하고 자동 기록 업데이트는 후속으로 둔다.

## 수행 순서

기존 설계 확인 → 전체 역할 회의 → 세 가지 접근 비교 → 사용자 방향 승인 → 담당자 개념 제거 → 요구사항·흐름·화면·수락 기준 작성 → 자체 검토 → 문서함·Git 저장

## 결과

- 여섯 종류 방과 공통 메시지 기능을 정의했다.
- 집신 대표의 고객지원 권한이 일반 대화 열람으로 확장되지 않게 했다.
- 직접 첨부와 후속 자동 기록 기능을 분리했다.
- 차단·신고·종료·공식계정 사칭 방지와 출시 차단 조건을 정의했다.
- `DEC-014`를 삭제하지 않고 `DEC-015`가 확장 대체함을 기록했다.

## 검증

- 미작성 표시와 빈 수락 기준이 없는지 검사했다.
- 요구사항·흐름·화면·수락 기준 추적표를 확인했다.
- 제품 코드는 변경하지 않았으므로 코드 테스트는 실행하지 않았다.

## 다음

사용자가 정식 명세를 검토·승인하면 별도의 구현계획을 작성한다. 계획 승인 뒤 테스트 우선으로 개발한다.

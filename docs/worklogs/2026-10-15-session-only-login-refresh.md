## 수행 내용

- `로그인 유지` 해제 로그인 시 계정 정보가 없는 브라우저 세션 쿠키 `zipsin-session-only=1`을 남긴다.
- proxy·서버 Supabase client·브라우저 client가 표시를 보고 갱신 쿠키의 `maxAge`·`expires`를 제거한다. 삭제 쿠키(빈 값·`maxAge: 0`)는 그대로 둔다.
- 브라우저 client는 `@supabase/ssr` 기본 저장소가 400일 만료를 강제하므로 쿠키 읽기·쓰기를 직접 지정했다. 이를 위해 표시 쿠키는 HttpOnly를 쓰지 않는다.
- 로그아웃은 표시를 지우고, 간편 로그인 시작은 표시를 지워 기존처럼 유지되는 세션을 사용한다.

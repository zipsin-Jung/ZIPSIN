# 2026-10-13 집신체크 현장 모드 구현

## 수행 순서

전체 회의 → 요구사항·기술 설계 → 실패 테스트 → 최소 구현 → 전체 자동검사 → 실제 브라우저 검수 → 독립 품질검수 순서로 진행했다.

## 변경 내용

- 첫 화면 필수 입력을 제거하고 `바로 체크 시작` 한 번으로 `오늘 본 집 N`을 만든다.
- 핵심 9개 기본 행에는 `괜찮음 / 확인 필요`, 120자 메모, 사진 추가만 둔다.
- `꼼꼼히 보기`는 같은 답을 보존하면서 16개 항목과 이유·방법·근거를 제공한다.
- 사진은 JPG·PNG·WebP, 원본 10MB 이하만 받고 긴 변 1600px 이하 JPEG로 재인코딩한다.
- 항목당 1장·후보당 6장으로 제한하고 IndexedDB `zipsin-check-photos:v1`에 Blob을 저장한다.
- 사진 실패와 텍스트 저장을 분리하고, 계정·서버 전송이나 다른 기기 복구로 표현하지 않는다.
- 독립 검수에서 발견한 커밋 전 성공 표시, 6장 제한 경쟁 조건, 사진 삭제 부재, 중복 접근성 이름과 초고해상도 위험을 수정했다.
- 사용자는 확인 후 사진을 개별 삭제할 수 있고, 저장 성공은 IndexedDB 트랜잭션 커밋 뒤에만 표시한다.

# 집신체크 비교 중심 V2 명세 작업

## 수행 순서

현재 문서·코드 확인 → 여섯 역할 최초회의 → 제품·UX·기술·품질·시간선 의견 통합 → ZCC 요구사항과 화면·데이터·테스트 명세 작성 → 결정안과 대화 기록 갱신 → 사용자 서면 명세 검토 요청 순서로 진행했다.

## 결과

- 네이버 카드검색식 동일 행 비교표를 중심 경험으로 정의했다.
- 현장 필수 항목을 5개로 줄이고 메모 안에서 사진을 추가하도록 했다.
- 집 보관 수와 비교 선택 최대 3채를 분리했다.
- 간단·상세 등록, 구조화 연락처·가격, 안전한 전화·링크와 영구 삭제를 명세했다.
- 기존 v1 기록·사진을 보존하는 schema v2 비파괴 이전 조건을 작성했다.

## 현재 상태

제품·UX 서면 명세는 작성됐으며 사용자 검토 대기다. 제품 코드는 변경하지 않았다. 승인 후 별도 구현계획을 작성하며, 실제 로그인·서버 이전·운영 배포는 이번 범위가 아니다.

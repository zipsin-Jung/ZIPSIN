# 유료 파일럿 Task 5 중간 기록

## 이번에 완성한 부분

- 현재 개발 상태를 초보자도 한눈에 볼 수 있는 한 장 이미지로 제작했다.
- Supabase `home-records` 비공개 저장소 설계와 migration을 추가했다.
- JPG, PNG, HEIC, PDF만 허용하고 파일당 20MB, 기록당 10개를 제한했다.
- 권한 확인 후에만 서버가 저장 경로를 만들고, 클라이언트가 해당 경로로 업로드하게 했다.
- 저장된 파일은 권한을 다시 확인한 뒤 5분간만 유효한 열람 주소를 받도록 했다.
- 집 타임라인의 각 기록에서 사진·PDF를 추가하고 다시 열 수 있게 연결했다.

# 2026-10-13 집신체크 현장 모드 최초 회의

## 수행 순서

1. 최신 사용자 현장 요구와 기존 PRD·기술 설계·코드를 확인했다.
2. 총괄비서, 제품기획, UX/UI, 설계·개발, 품질·비판, 시간선 분석 여섯 역할이 최초 회의를 했다.
3. 현장 입력을 최소화하는 제품 요구사항 ZCF-001~007과 테스트 ZCF-T001~008을 확정했다.

## 통합 결론

- 기본은 한 번 눌러 시작하는 현장 모드다.
- 상태는 `괜찮음 / 확인 필요`, 미선택은 미확인이다.
- 메모와 사진은 항목에서 즉시 추가한다.
- 긴 설명과 추가 7개는 같은 기록의 꼼꼼히 보기에 둔다.
- 사진은 재인코딩 후 IndexedDB에 로컬 저장하며 서버로 전송하지 않는다.
- 사진 저장 실패가 텍스트 체크를 손상시키면 안 된다.

## 게이트

사용자의 구현 요청을 G1 제품·G2 UX 범위 승인으로 기록한다. 로컬 전용·비회원·서버 전송 없음이라는 기존 G3 경계 안에서 기술 설계와 테스트를 진행한다. 실제 계정 사진 저장과 운영 배포는 제외한다.

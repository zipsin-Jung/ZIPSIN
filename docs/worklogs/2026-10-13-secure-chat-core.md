# 공통 채팅 저장·읽음·알림 기반 작업기록

- 일자: 2026-10-13
- 범위: 채팅 공통 데이터, 메시지 전송, 읽음, 알림

## 수행 순서

1. 승인된 채팅 결정과 구현 계획을 확인했다.
2. 비참여자·종료 참여자·잘못된 본문·중복 전송·읽음 역행·알림 개인정보 테스트를 먼저 작성하고 실패를 확인했다.
3. RLS 테이블과 원자 RPC, 입력 스키마, 페이지네이션 서비스를 구현했다.
4. 전체 테스트·커버리지·Production build를 검증했다.
5. 기능 정의·기술 문서·출시 검수 문서를 갱신했다.

## 구현 결과

- 방·참여·메시지·읽음·알림의 공통 저장 구조
- 활성 참여자만 메시지를 읽고 전송하는 권한 함수
- 서버 세션에서 발신자를 결정하는 메시지 전송 RPC
- 같은 멱등성 키 20회 재시도를 한 메시지로 고정
- 사용자별 읽음 위치의 역행 방지
- 본문과 개인정보를 복사하지 않는 알림
- 최근 메시지 30개 단위 페이지네이션과 ID 중복 제거

## 검증 결과

- 집중 테스트: 3개 파일, 13개 통과
- 전체 테스트: 51개 파일, 265개 통과
- 커버리지: 문장 90.90%, 분기 83.75%, 함수 90.90%, 줄 91.63%
- TypeScript 검사와 Next.js Production build: 통과
- 실제 Preview DB·다계정·동시성 브라우저 검증: 미수행

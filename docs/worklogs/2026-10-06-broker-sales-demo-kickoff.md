# 공인중개사 영업용 데모 킥오프 작업일지

- 날짜: 2026-10-06
- 상태: 기획 완료 · 사용자 승인 대기

## 요청

공인중개사무소 영업 전에 보여 줄 수 있는 결과물을 먼저 만든다.

## 수행 순서

1. 사용자에게 작업 순서를 보고했다.
2. 기존 작업 현황, 제품 문서, 결정 기록과 현재 Next.js 코드를 확인했다.
3. 총괄비서·기획디자인·설계개발·검수비판 네 역할의 최초 회의를 진행했다.
4. 영업용 최소 흐름, 제외 범위, 수용 기준과 위험을 통합했다.
5. 데모 제품 명세, 회의록, 대화 기록과 작업일지를 작성했다.

## 결론

- 기존 랜딩페이지를 보존하고 별도 `/demo`를 만든다.
- 핵심 흐름은 `멈춘 업무 → 집 기록 → 사건 상태 → 담당 변경 → 보조원 인수인계 → 기록 요약`이다.
- 실제 저장·전송 없이 비식별 가상 데이터만 사용한다.
- 상세 요구사항은 `docs/13-broker-sales-demo-spec.md`를 따른다.

## 확인 결과

- 기존 `/test` 계획은 범위가 넓어 영업 시작이 늦어질 위험이 확인됐다.
- 세 전문 역할 모두 한 가지 공인중개사 인수인계 흐름에 집중할 것을 권고했다.
- 현재 코드는 랜딩페이지와 작은 PhoneDemo만 있으며 별도 `/demo`는 아직 구현되지 않았다.

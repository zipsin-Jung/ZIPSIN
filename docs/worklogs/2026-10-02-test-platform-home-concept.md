# 2026-10-02 테스트 플랫폼 예시 홈 화면

## 요청

테스트 플랫폼 제작·배포 계획을 토대로 예시 홈페이지 이미지를 만든다.

## 수행 순서

1. 기존 집신 랜딩·역할별 모바일 UI·마스코트 참고 이미지 확인
2. `/test` 기능정의와 T-01 사무소 인수인계 흐름 확인
3. 이미지 생성 스킬로 PC 대시보드 목업 제작
4. 결과 확인 후 프로젝트 참고 이미지로 저장
5. 바탕화면 문서함과 GitHub 동기화

## 결과

- 파일: `public/images/test-platform-home-concept-v1.png`
- 크기: 1672×941 PNG
- 주요 구성: 데모 안내, 네 역할 전환, 오늘의 업무 요약, 우선 확인 업무, 담당자 현황, 최근 집 기록
- 브랜드: 딥그린·아이보리·골드, 둥근 카드, 집신이 안내 캐릭터

## 검증과 한계

- 생성 이미지를 직접 확인했다.
- 실제 웹페이지나 클릭 가능한 UI가 아닌 방향 확인용 이미지다.
- 이미지 생성 특성상 세부 문구와 가상 주소는 구현 단계에서 제품 문서 기준으로 다시 작성해야 한다.
- 실제 접수·저장·전송 기능은 구현하지 않았다.

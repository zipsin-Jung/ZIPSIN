# 2026-09-30 바탕화면 문서함 구성

## 요청

작성한 문서를 바탕화면의 `코덱스랑` 폴더에 넣고 이후 모든 정리도 같은 위치에 저장한다.

## 계획한 순서

1. 대상 폴더와 기존 파일 확인
2. 충돌 없는 집신 전용 폴더 생성
3. 기존 기획·대화·결정·작업 문서 복사
4. 이후 동기화 규칙을 작업 지침과 운영 문서에 반영
5. 복사 결과와 문서 누락 검사
6. GitHub 커밋·푸시

## 수행 내용

- 비어 있던 `코덱스랑` 폴더 안에 `집신` 문서함을 만들었다.
- 저장소의 `docs/` 전체를 같은 구조로 복사했다.
- 사용자가 문서를 쉽게 찾을 수 있도록 문서함용 README를 만들었다.
- 이후 문서 변경 때 바탕화면 문서함도 함께 갱신하도록 AGENTS와 작업 운영 규칙을 수정했다.
- 바탕화면과 GitHub 이중 보관 방식을 결정 기록으로 남겼다.
- 저장소 문서와 바탕화면 문서함을 비교해 누락이나 내용 차이가 없음을 확인했다.

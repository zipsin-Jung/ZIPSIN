# 계약 후부터 만기까지 개발 프롬프트 작업 보고

- 날짜: 2026-10-13
- 상태: 문서 완료, 사용자 승인 대기

## 요청

사용자의 계약 후 만기까지 제품 구상을 넣을 것·뺄 것·나중으로 미룰 것으로 구분하고, 실제 개발에 사용할 통합 프롬프트를 작성한다.

## 수행 순서

1. 기존 역할·권한·업무 흐름과 홈 개발 프롬프트 확인
2. 실제 개발 작업트리의 역할, 계약, 관계, 채팅, 첨부, 알림 구조 확인
3. 제품기획·UX, 설계·검수, 총괄·시간선 여섯 역할 회의
4. 전자문서 표현과 개인정보 동의 공식 근거 확인
5. MVP·후속·제외, 사용자 흐름, 화면, 상태, 수용기준 정리
6. 제품 명세·결정 제안·개발 프롬프트 작성
7. 대화·회의·작업 기록 갱신
8. 바탕화면 문서함과 GitHub 동기화

## 핵심 결과

- 계약 후부터 만기까지의 네 단계 제품 정의를 만들었다.
- 네 사용자 분류와 실제 접근 권한을 분리했다.
- 만기 선택을 세 가지 준비 상태로 수정했다.
- 자동 업데이트를 사용자 확인 후 즉시 반영으로 정의했다.
- 이 집 사람들, 집 채팅, 일정과 문서의 개인정보 경계를 정의했다.
- OCR, AI 자동화, PDF 내보내기와 법적 증거 보장을 후속으로 분리했다.

## 검증

- 실제 코드·마이그레이션에서 현재 가능한 기능과 없는 기능을 구분했다.
- 기존 RLS 원칙과 역할 모델을 유지했다.
- 국가법령정보센터의 전자문서·개인정보 동의 자료를 확인했다.
- 제품 코드는 수정하지 않았다.

## 남은 일

- 사용자 G1 제품 의미 승인
- 단일 권장 데스크톱·모바일 시안
- 데이터·보존·개인정보 미결정 승인
- 구현 계획 작성과 테스트 우선 개발

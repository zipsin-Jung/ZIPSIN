# 2026-10-02 단순 구조 참고 시안 5종

## 요청

## 참고한 원칙

- 상단에서 바로 찾을 수 있다.
- 핵심 기능 입구가 많지 않다.
- 설명용 장식보다 실제 내용이 먼저 보인다.
- 각 입구의 이름만 보고도 다음 화면을 예상할 수 있다.
- 참고 화면의 브랜드·색상·문구·정확한 배치는 복제하지 않는다.

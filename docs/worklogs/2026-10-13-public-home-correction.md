# 정식 메인페이지 진입 수정 작업보고

## 요청

메인페이지가 로그인 화면으로 바로 열리는 잘못된 흐름을 수정하고, 집신을 이해한 뒤 실제 로그인·회원가입으로 들어가게 한다.

## 수행 순서

1. 루트 진입 코드와 기존 랜딩의 사전가입·데모 노출 확인
2. 비로그인 메인과 로그인 사용자 업무 홈 분리
3. 정식 메인페이지 제작
4. 단위검사·타입검사·Production build
5. 문서·바탕화면 문서함·GitHub 동기화
6. Vercel Preview 실제 브라우저 검수

## 변경 내용

- 비로그인 `/`은 `PublicHome`을 표시한다.
- 로그인 세션이 있는 경우에만 `/home`으로 이동한다.
- 메인페이지는 문제, 해결 구조, 기록 종류, 집신 채팅, 사용자별 가치와 실제 시작 행동으로 구성했다.
- CTA는 `/signup`과 `/login`에만 연결했다.
- 새 메인페이지에는 사전가입·데모·출시 준비·가짜 성과 수치를 넣지 않았다.
- 모바일과 데스크톱 반응형 스타일을 별도 CSS module로 구현했다.

## 검증

- 전체 단위·통합 검사: 63개 파일, 304개 통과
- `npm run typecheck`: 통과
- `npm run build`: 통과
- 실제 Preview 브라우저 검수: 배포 후 기록

# 홈노크 심층 경쟁 분석 작업기록

- 작업일: 2026-10-13

## 수행 순서

1. 홈노크 공식 홈페이지와 핵신 서비스 페이지 확인
2. 실제 모바일 화면에서 첫 인상·정보 순서·시각 방식 확인
3. 공식 약관과 하나은행 제휴 안내로 가입·본인인증·자동수납 범위 확인
4. 홈노크와 집신의 공통점·차이·위험·빈 자리 분석
5. 토스·문토·홈노크 참고 원칙을 집신 6장면으로 정리
6. 복제 금지 범위와 독자적 제품 자리를 결정문에 기록

## 결과와 검증

- 홈노크는 직접 경쟁사이자 산업 신뢰 레퍼런스로 관리한다.
- 집신은 자산·세금·수납이 아니라 집·사건·기록·채팅·권한으로 차별화한다.
- 실적 수치에 2023년 12월 기준이 표시되어 있음을 확인했다.
- 자동수납 0원, 호실별 전용 계좌, 미납 알림, 계약서 보관 안내를 확인했다.
- 앱 로그인 후 세부 권한·조직·채팅 기능은 미확인으로 구분했다.

# 집신·집신체크 통합 인증 재설계 기록

- 사용자는 `ck.zipsin.net`에서 집신 본체와 똑같은 로그인·회원가입·간편로그인을 사용하고, 가입자가 그대로 집신 회원이 되는 구조를 승인했다.
- 기존 집신체크 전용 로그인 구현은 같은 Supabase를 향하더라도 집신 본체의 아이디 로그인·회원가입과 분리되어 있어 요구를 충족하지 못한다고 판정했다.
- 독립 설계·품질 검토 결과, 두 도메인을 같은 Next.js 앱과 Supabase 프로젝트에 연결하고 인증 시작·callback을 `zipsin.net`으로 중앙화하는 구조를 채택했다.
- 기존 승인 명세를 보완하는 통합 인증 설계와 실행 계획을 작성했다. 제품 코드는 아직 변경하지 않았다.
- 실제 Google 오류 원인은 Supabase 공급자 비활성이고, Production 복귀 주소가 loopback 주소로 구성된 것도 확인했다.
- 다음 단계는 집신 본체 인증 브랜치를 기준으로 집신체크를 비파괴 병합하고 테스트 우선으로 공용 인증을 완성하는 것이다.

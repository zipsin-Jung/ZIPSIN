# 집별 채팅 범위 확정 작업기록

- 일자: 2026-10-13
- 상태: 기획·설계 승인 반영, 구현 전

## 요청

사용자는 유료 파일럿과 정식 제품에 채팅을 반드시 포함하도록 승인했다.

## 수행 순서

1. 기존 명세·계획·진행 상태 확인
2. 총괄·기획·UX/UI·설계개발·검수 관점 전체 회의
3. 권한·개인정보·화면·수락 기준 확정
4. 제품 명세와 구현계획 갱신
5. 진행도 이미지 갱신
6. 문서함 동기화와 Git 저장

## 변경

- `DEC-014`로 집별 채팅을 필수 범위로 결정했다.
- 사무소 내부 대화와 현재 계약 공유 대화를 분리했다.
- 메시지·사진·PDF·읽지 않은 수·앱 안 알림을 최소 범위로 정했다.
- 일대일·임의 단체방·통화·외부 알림·AI 기능을 제외했다.
- 이전 계약 차단, 종료 즉시 차단, 원문 삭제 금지, 중복 전송 방지를 수락 기준에 넣었다.
- 구현계획에 채팅 Task를 추가하고 후속 Task를 재배치했다.

## 확인

- 명세의 포함·제외 범위, REQ/AC, FLOW, SCREEN, METRIC, 추적표를 함께 갱신했다.
- 구현계획과 SDD 진행표의 Task 의존성을 갱신했다.
- 진행도 이미지의 자동 테스트 수를 실제 최근 결과인 221개로 고쳤다.
- 이번 단계에서는 제품 코드를 변경하지 않아 테스트를 다시 실행하지 않았다.

1. 비공개 첨부의 부분 실패 복구와 Preview 저장소 검증
2. 임대인·임차인 초대와 계약 종료
3. 승인 명세 기반 집별 채팅 테스트 우선 구현
4. 실제 브라우저·RLS·스트레스·접근성·80% 커버리지 검수
5. 사용자 최종 승인 뒤에만 원격 push·migration·배포

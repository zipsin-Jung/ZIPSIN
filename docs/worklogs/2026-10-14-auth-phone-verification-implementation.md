## 독립 검수 후 보안 수정

- 문자 발송 전에 사용자·전화번호 HMAC·요청 출처별 60초/시간/일 제한을 DB 원자 잠금으로 확보하도록 바꿨다.
- 복구 코드는 새 발급 시 이전 코드를 폐기하고, 검증·오답 증가·단일 소비를 행 잠금 RPC 한 트랜잭션으로 처리한다.
- 휴대폰 복구 성공 시 10분짜리 HttpOnly 세션을 발급하고, 이 세션을 한 번 소비해야 새 비밀번호를 설정할 수 있게 했다.
- 집신체크 서버 저장 API와 직접 DB 쓰기 정책 모두 인증된 휴대폰을 요구하도록 보강했다.
- OAuth 포함 모든 휴대폰 인증 완료 화면에서 이용약관·개인정보 동의를 실제 입력받는다. 사용자가 제거를 지시한 14세 체크는 동의 기록에서도 제거했다.
- 아이디 확인 API에 출처·아이디별 제한을 추가하고, 늦게 도착한 이전 응답이 바뀐 아이디를 승인하지 못하게 했다.
- SOLAPI 호출에 8초 제한과 성공 응답 ID 검증을 추가했다.

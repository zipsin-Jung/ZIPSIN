# 유료 출시 완성 프롬프트 작업기록

날짜: 2026-10-13

## 수행 순서

1. 필수 인수인계·운영·제품 문서와 Git 상태를 확인했다.
2. 제품·사업, 설계·품질, UX·시간선 역할로 현재 갭을 독립 검토했다.
3. 기존 유료 파일럿·결제 계획·가격 결정을 대조했다.
4. 유료 전환 전체 흐름, 출시 중단 조건, 테스트, 운영, 외부 준비를 통합했다.
5. 복사·붙여넣기용 통합 프롬프트와 결정·회의·대화 문서를 작성했다.
6. 후속 요구에 따라 사무소 구성원·임대인·임차인 초대 링크의 생성·복사·공유·가입 복귀·즉시 합류 수용 기준을 추가했다.

## 검증

- 기존 제품 정의와 권한 원칙을 보존했다.
- 기존 결정인 99,000원/8주/자동 전환 없음과 249,000원 가격 가설을 구분했다.
- 현재 구현, 부분 구현, 미구현을 구분했다.
- 실결제·법정 고지·보안·운영·백업·장애·지표·종료까지 출시 범위를 확장했다.
- 현재 초대 링크 생성 구현과 새로 필요한 절대주소 복사·기기 공유·가입 뒤 복귀·즉시 합류 UX를 구분했다.
- 영원한 완벽을 주장하지 않고 `승인 범위의 P0·P1 0건 + 실제 증거`로 완료를 정의했다.
- 통합 프롬프트의 코드 블록 시작·종료와 Git diff 형식을 확인했다.
- 새 통합 문서와 충돌 없는 갱신 문서를 바탕화면 집신 문서함에 복사하고 원본과 일치함을 확인했다.
- 바탕화면의 `docs/02-feature-definition.md`, `docs/04-core-workflows.md`는 Git 기준본과 다른 기존 내용이 있어 자동으로 덮어쓰지 않았다. Git 기준본에는 이번 초대 링크 요구가 반영되어 있으며, 두 바탕화면 문서는 별도 병합이 필요하다.

## 남은 일

- 사용자에게 통합 프롬프트와 핵심 판단을 제출하고 승인받는다.
- 승인 뒤 해당 프롬프트를 기준으로 기존 구현계획을 재정렬하고 실제 코드 작업을 이어간다.
- Production과 실결제는 별도 사용자 승인 전 실행하지 않는다.

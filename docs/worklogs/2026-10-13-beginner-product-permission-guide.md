# 집신 초보자 제품·권한 학습자료 작업일지

- 일자: 2026-10-13
- 상태: 문서 작성·공식 자료 확인 완료

## 수행 순서

1. 기존 제품·권한·연간계획 문서를 확인했다.
2. 최신 공인중개사법과 AWS 공식 권한 문서를 확인했다.
3. 공식 경쟁 서비스 페이지에서 공개 가격과 확인 범위를 조사했다.
4. 웹앱까지 남은 순서와 요청한 20개 학습 항목을 작성했다.
5. 사실·가설·추천·미결정을 구분하고 출처를 연결했다.
6. 문서 링크, 바탕화면 사본과 Git 변경을 검증한다.

## 확인한 공식 자료

- 국가법령정보센터 공인중개사법 제2조·제15조·제25조
- AWS IAM 소개·정책 평가·최소 권한·Verified Permissions
- 카카오톡 채널, 네이버 MYBOX, Google One, Dropbox, Notion과 Trello 공식 페이지

## 변경 내용

- 웹앱까지 남은 10단계와 최소 완성 흐름을 정의했다.
- 역할별 허용·금지 행동과 직원·임대인·임차인 초대 및 종료 흐름을 쉬운 말로 작성했다.
- 고객 인터뷰 15문항, 가격 검증 단계, 7일 공부 계획, 시험과 말하기 연습문을 작성했다.

## 검증 결과

- 공개 가격은 확인일과 공식 링크를 표시했다.
- 확인되지 않은 매물관리·광고·문자·전자계약 비용은 실제 청구서 또는 업체 문의 대상으로 분리했다.
- 법률 자문으로 표현하지 않고 제품 기획상 안전 원칙으로 설명했다.
- 코드와 배포는 변경하지 않았다.

## 남은 일

- 사용자가 혼합 권한 모델을 제품 기준으로 승인할지 결정
- 승인 후 MVP 화면·상태·수용 기준을 최신 역할 5종에 맞춰 재정리
- 공인중개사 10곳 인터뷰와 유료 설계 파트너 모집

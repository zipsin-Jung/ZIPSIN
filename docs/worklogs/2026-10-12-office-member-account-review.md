# 2026-10-12 사무소 구성원 개인 계정 검토

## 요청

보조원별 아이디를 발급하고 공인중개사가 권한을 부여하는 구조의 적절성을 검토했다.

## 수행

1. 기존 권한 모델과 공개형 V1 명세 확인
2. 현행 공인중개사법과 법제처 해석 확인
3. 공유 계정, 관리자 발급 계정, 개인 초대 계정 비교
4. 권고안·대화 기록·제품 명세 갱신

## 결과

- 대표 초대와 구성원 개인 계정 구조를 권고했다.
- `개업공인중개사`, `소속공인중개사`, `중개보조원`을 제품에서 구분하도록 했다.
- 중개보조원에게 법적 업무 범위를 넘는 기능을 부여하지 않는 상한선을 제안했다.
- 실제 기능과 계정은 구현하지 않았다.

## 검증과 남은 일

- 국가법령정보센터의 2026-08-28 시행 공인중개사법과 법제처 해석을 확인했다.
- 실제 서비스 공개 전 전문 법률 검토가 필요하다.
- 사용자 세부 승인 후 요구사항 ID, 권한표와 테스트 명세를 확정한다.

# 정식 출시 핵심 흐름·챗·고객지원 구현계획 작업기록

- 일자: 2026-10-13
- 상태: 구현계획 사용자 검토 대기

## 요청

집신을 화면 시안이나 데모가 아니라 실제 정식 출시 제품 기준으로 신중하게 완성한다.

## 수행

승인 명세 재확인 → 기존 DB·화면·권한 의존 조사 → 독립적으로 검수 가능한 아홉 Task로 분해 → 파일·인터페이스·실패 테스트·검증·커밋 단위 지정 → 명세 대비 자체 검토

## 핵심 결정

- 첫 Task에서 담당 배정 없는 사무소 권한으로 통일한다.
- 기존 assignment 테이블과 이력은 삭제하지 않고 새 권한 경로에서 사용하지 않는다.
- Preview 인증 검증과 Production 배포를 분리한다.
- 관계자 연결을 채팅보다 먼저 완성한다.
- 채팅 저장 원본과 Realtime 수신을 분리한다.
- 집신 고객지원 권한이 다른 대화 열람 권한이 되지 않게 별도 검사한다.

## 자체 검토

- REQ-CHAT-CORE, ROOM, FILE, SUPPORT, SAFETY가 각각 구현 Task와 테스트를 가진다.
- 방 종류, RPC, 테이블, 파일 제한과 화면 경로의 이름을 일치시켰다.
- 각 Task는 실패 테스트 → 최소 구현 → 전체 회귀 → 커밋으로 끝난다.
- 실행 전에 사용자 검토와 실행 방식 확정이 필요하다.

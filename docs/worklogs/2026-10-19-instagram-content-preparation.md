# 2026-10-19 인스타그램 콘텐츠 준비

## 수행 순서

1. 집신의 핵심 구현 방식이 노출되지 않는 이미지 방향을 정했다.
2. 정사각형 이미지 3장을 생성해 프로젝트에 보관했다.
3. 공인중개사무소의 기록 단절 문제를 중심으로 캡션을 작성했다.
4. 인스타그램 게시 화면 접속을 시도했다.

## 검증 결과와 남은 일

- 이미지 3장 생성과 로컬 보관을 확인했다.
- 기존 인스타그램 게시물은 변경하지 않았다.
- 인스타그램 로그인 상태가 아니며 저장된 로그인 정보도 유효하지 않아 게시 입력 전 단계에서 중단했다.
- 사용자가 브라우저에서 직접 로그인하면 이미지 3장과 캡션을 입력하고, 최종 `공유` 직전에 확인을 받아 발행한다.

# 로그인 홈 재설계 개발 프롬프트 작업 보고

- 날짜: 2026-10-13
- 상태: 문서 완료, 사용자 승인 대기

## 요청

사용자가 직접 그린 로그인 홈·체크리스트 시안을 참고하고 실제 이미지 배치까지 포함해, 집신이 복잡하거나 글뿐인 제품이 되지 않도록 심층 조사 기반의 전체 개발 프롬프트를 작성한다.

## 수행 순서

1. 필수 인수인계·제품·운영 문서 확인
2. 첨부 시안 원본 확인과 안정적인 참고 경로 저장
3. 최신 실제 개발 작업트리의 홈 코드·설계 명세·구현 계획 확인
4. 제품기획·UX, 설계·검수, 총괄·시간선 역할 회의
5. 디자인 시스템·온보딩·빈 상태·접근성·이미지 공식 자료 조사
6. 정보구조·상태·이미지 배치·권한·테스트를 통합한 개발 프롬프트 작성
7. 결정·회의·대화·작업기록 갱신
8. 바탕화면 문서함 비파괴 동기화
9. Git 변경 검토·커밋·푸시

## 주요 결과

- 사용자 시안은 완성 디자인이 아니라 정보구조 참고로 분류했다.
- 공통 앱 셸과 세 가지 데이터 상태의 점진 공개를 권고했다.
- MVP 체크리스트를 실제 기록 6개 준비 안내로 제한했다.
- 교육용 이미지 세 장의 장면, 위치, 경로, 개인정보 규칙을 정의했다.
- 실제 기록 사진과 교육용 이미지를 분리했다.
- 디자인 승인 한 번 뒤 구현하는 G1~G6 게이트를 정의했다.
- 존재하지 않는 AI, 가짜 완료율, 역할별 별도 홈을 제외했다.

## 검증

- 첨부 PNG 2개의 파일 형식과 크기를 확인했다.
- 최신 작업트리의 기존 홈 재설계 명세와 계획을 읽어 중복 기획을 피했다.
- 공식 디자인·접근성·Next.js 자료를 개발 프롬프트에 연결했다.
- 이번 작업에서는 제품 코드를 수정하거나 배포하지 않았다.

## 남은 일

- 1440px·390px 첫 사용자/활동 사용자 시안 4장 제작
- 교육용 이미지 세 장 생성·검수
- 승인 후 기존 구현 계획 Task 1~6 실행

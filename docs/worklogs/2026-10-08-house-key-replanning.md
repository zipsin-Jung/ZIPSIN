# 2026-10-08 집 키·사무소 우선 MVP 재기획

## 수행 순서

1. 사용자가 제시한 집 키, 임대인 확인, 여러 사무소 중복과 초기 유료 가설을 핵심 문제로 재정의
2. 기획·설계·검수 역할의 독립 검토
3. 집 키 발급 대안 비교
4. 접근 공간과 권한 기본값 설계
5. 공인중개사 유료 MVP 범위와 파읿럿 가설 정리
6. 공식 법령 출처에서 주민등록번호 처리 제한과 공인중개사 확인·설명 의무 확인

## 결과

- `사무소 내부 집 업무공간`과 `임대인 승인 집 공간`을 분리하는 단계형 구조를 총괄 권고안으로 정리했다.
- 주소는 공개 검색 키가 아니라 서버 내부 중복 후보 확인에만 사용한다.
- 휴대전화 본인확인과 소유권 확인을 구분했다.
- 사용자 표현으로 `집 키`보다 `집 연결 초대`를 권장했다.
- PDF는 후속 범위로 유지했다.
- 아직 사용자 승인 전이므로 실행 결정이나 코드로 처리하지 않았다.

## 검증

- 제품·기획·설계·검수 관점에서 사무소 내부 공간 분리에 동일한 권고가 나왔다.
- 로그인·주소·집 권한을 서로 다른 개념으로 분리했다.
- 이 단계는 제품 권고안 검토이며, 법률 자문이나 구현 검수가 아니다.

## 남은 일

- 사용자의 2단계 구조 승인
- 승인 후 새 의사결정 기록, 역할·권한 문서, 로그인·첫 화면·사용자 흐름 갱신
- 유료 파일럿 설계와 실제 공인중개사 인터뷰
- 사진 촬영·보관 근거, 임대인 확인, 공동소유·법인·대리인 예외에 대한 별도 법률 검토

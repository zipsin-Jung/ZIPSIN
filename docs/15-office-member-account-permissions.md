# 사무소 구성원 개인 계정과 권한 제안

- 작성일: 2026-10-12
- 상태: 사용자 제안 반영 · 세부 승인 대기
- 연결 문서: `docs/14-access-control-model-recommendation.md`, `DEC-013`

## 1. 사용자 제안

보조원의 업무상 행위가 개업공인중개사의 책임과 연결되므로, 대표 공인중개사가 보조원별 계정을 발급하고 권한을 부여하는 구조를 사용한다.

## 2. 정확한 제품 표현

방향은 맞지만 `공인중개사 아이디`라는 이름은 사용하지 않는다. 중개보조원은 공인중개사 자격자가 아니므로 사용자가 자격을 오해할 수 있다.

권장 구조는 다음과 같다.

```text
대표 공인중개사 개인 계정
→ 확인된 사무소 공간 개설
→ 구성원 개인 계정 초대
→ 소속공인중개사 또는 중개보조원 구분
→ 허용된 역할과 담당 집 부여
→ 개인별 활동 기록
→ 퇴사·고용 종료 시 즉시 접근 종료
```

대표의 아이디나 비밀번호를 함께 사용하지 않는다. 대표가 계정을 대신 만들어 비밀번호를 알려주는 방식보다, 초대받은 사람이 본인 확인 후 자신의 계정을 만드는 방식을 우선한다.

## 3. 법령에서 확인한 사실

- 공인중개사법 제2조는 `소속공인중개사`와 `중개보조원`을 구분한다.
- 중개보조원은 공인중개사가 아닌 사람으로서 현장 안내와 일반 서무 등 단순 업무를 보조한다.
- 공인중개사법 제15조제2항은 소속공인중개사 또는 중개보조원의 업무상 행위를 고용한 개업공인중개사의 행위로 본다.
- 그렇더라도 중개보조원이 확인·설명, 거래조건 조율, 계약서 작성 등 공인중개사에게 맡겨진 업무를 수행할 수 있는 것은 아니다.
- 개업공인중개사는 고용과 고용관계 종료를 등록관청에 신고해야 한다.

이 문서는 제품 설계 검토이며 법률 자문이 아니다. 실제 서비스 공개 전에는 최신 법령과 전문 검토를 다시 거친다.

## 4. 계정 종류와 기본 권한

| 구성원 | 계정 표시 | 기본 허용 | 기본 금지 |
|---|---|---|---|
| 대표 개업공인중개사 | 대표·사무소 관리자 | 구성원 초대·종료, 담당 배정, 사무소 기록 관리 | 다른 사무소 자료 접근 |
| 소속공인중개사 | 소속공인중개사 | 배정된 중개업무와 집 기록 처리 | 대표 전용 구성원·결제 관리 |
| 중개보조원 | 중개보조원 | 배정된 집의 현장 사진, 일정, 단순 업무 기록 | 확인·설명, 계약 조율, 계약서 작성·승인 |

제품 권한은 법에서 금지된 업무를 허용할 수 없다. 대표가 버튼을 켜더라도 중개보조원의 법적 업무 범위를 넘는 기능은 활성화되지 않아야 한다.

## 5. 필요한 안전장치

1. 한 사람당 하나의 개인 계정을 사용한다.
2. 화면에 실제 자격 구분을 분명히 표시한다.
3. 사무소 가입은 대표의 초대와 본인 확인을 거친다.
4. 보조원은 배정된 집만 본다.
5. 계약 관련 최종 확인·설명·승인은 권한 있는 공인중개사만 한다.
6. 누가 언제 무엇을 열람·수정했는지 기록한다.
7. 퇴사·고용 종료 시 로그인 세션과 파일 접근을 즉시 끊는다.
8. 담당 업무는 삭제하지 않고 새 담당자에게 인계한다.

## 6. 대안 비교

| 방식 | 장점 | 위험 | 판단 |
|---|---|---|---|
| 대표 아이디 공동 사용 | 시작이 빠름 | 누가 행동했는지 알 수 없고 비밀번호·퇴사자 통제가 어려움 | 제외 |
| 대표가 보조원 비밀번호까지 발급 | 관리가 쉬워 보임 | 대표가 비밀번호를 알게 되고 계정 탈취·책임 추적 문제가 생김 | 제외 |
| 대표 초대 + 보조원 개인 계정 | 개인별 권한·감사·종료 가능 | 초대와 본인 확인 과정 필요 | 권장 |

## 7. 실패를 미리 가정하면

| 실패 | 조기 신호 | 예방 |
|---|---|---|
| 보조원이 공인중개사로 오인됨 | 고객 문의, 잘못된 서명·설명 시도 | 계정 명칭과 자격 배지 분리 |
| 퇴사자가 계속 자료를 봄 | 종료 후 로그인·파일 접근 로그 | 종료 즉시 세션 폐기와 파일 URL 만료 |
| 대표가 모든 행동의 작성자로 남음 | 사고 발생 시 실제 행동자 확인 불가 | 개인 계정과 변경 이력 필수화 |
| 대표가 금지 업무 권한을 부여함 | 보조원 화면에 계약 승인 기능 노출 | 법적 상한선은 대표도 변경 불가 |

## 8. 권고와 미결정 사항

**권고:** 모든 사무소 구성원에게 개인 계정을 부여하고, 대표가 사무소 초대를 통해 역할과 담당 집을 배정한다. `공인중개사 아이디`가 아니라 `사무소 구성원 개인 계정`으로 부른다.

아직 정할 사항:

- 공인중개사 자격과 사무소 고용관계를 어떤 자료로 확인할지
- 중개보조원 고용 신고 완료 여부를 제품에서 어디까지 확인할지
- 계약 기능을 구현할 경우 소속공인중개사와 대표의 최종 승인 범위

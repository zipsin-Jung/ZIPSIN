# 2026-10-13 유료 파일럿 배포 전 단계 최초 회의

- 상태: 범위 승인 대기
- 목표: 한 사무소가 실제 집 5채를 등록하고 관계자와 기록을 이어갈 수 있는 유료 파일럿을 배포 직전 상태까지 완성한다.
- 참여 역할: 총괄비서, 제품기획, UX/UI 디자인, 설계·개발, 검수·비판, 시간선 분석

## 확인된 현재 상태

- 인증, 역할 선택, 사무소 생성과 보호된 홈이 로컬에 구현되어 있다.
- 사무소·집·계약·기록·첨부·초대·감사 기록의 DB 및 RLS 초안이 있다.
- 타입 검사, 126개 테스트, 빌드가 통과했다.
- 현재 측정 커버리지는 Statements 90.8%, Branches 84.81%, Functions 90.32%, Lines 91.25%다.
- 신규 migration은 Supabase Preview에 적용하지 않았다.
- 실제 DB 교차 계정, 모바일·PC 브라우저, 사진, 스트레스 검수는 남아 있다.

## 전체회의 결론

기존 공개형 개인 V1 문서는 장기 방향으로 보존한다. 이번 개발은 `DEC-013`에 따라 사무소 유료 파일럿을 별도 범위로 정의한다.

완결 흐름:

`대표 로그인 → 사무소 생성 → 첫 집 등록 → 직원 초대 → 담당 배정 → 첫 기록·사진·할 일 → 임대인·임차인 초대 → 권한 종료 검증`

사무소가 만드는 집은 공식 소유권이나 영구 공용 집 키가 아니라 해당 사무소의 비공개 관리 공간이다. 주소로 다른 공간을 찾거나 자동 병합하지 않는다.

## 포함 범위

1. 사무소 업무 홈
2. 첫 집 등록과 담당 배정
3. 소속공인중개사·보조원 초대
4. 메모·수리·문서·사진·할 일 기록
5. 비공개 사진·문서 저장과 다시 보기
6. 임대인·임차인 초대와 현재 계약 공간
7. 직원 퇴사·담당 해제·계약 종료·초대 철회
8. 역할별 권한과 감사 기록
9. 모바일·PC·접근성·권한·스트레스·커버리지 검수

## 제외 범위

- 실시간 채팅, PDF, OCR·AI, 수리기사 매칭
- 월간 캘린더와 외부 캘린더 연동
- 실제 카드 자동결제
- 등기·소유권 자동 인증과 영구 공용 집 키
- 주소 기반 공개 검색과 자동 중복 병합
- 고급 통계 대시보드와 일괄 인수인계

## 권한 기본값 제안

- 소속공인중개사를 개인 주 역할에도 추가한다.
- 임대인·임차인은 현재 계약 공간에서 읽기와 기록 작성을 허용한다.
- 사무소 내부 기록은 임대인·임차인에게 보이지 않는다.
- 보조원은 사진·할 일·일정·문서 정리만 가능하며 설명·협상·계약 승인은 불가하다.
- 초대는 원문 연락처 저장 없이 일회성 링크부터 시작한다.
- 파일럿 가격은 `8주 유료 파일럿 참가비 99,000원`, 자동 전환 없음으로 표시한다.

## 주요 위험과 선행 보완

1. 현재 계약 기록 생성 시 계약과 집의 일치를 서버에서 강제한다.
2. 기록 수정은 조회 권한만으로 허용하지 않고 작성자·대표·허용 역할로 제한한다.
3. 집 생성과 사무소 연결·대표 담당·감사 기록을 하나의 원자적 RPC로 처리한다.
4. 장기 공유 이력에는 개인정보·계약자료가 들어가지 않는 안전한 범위만 둔다.
5. SQL 문자열 검사를 넘어 실제 Supabase Preview에서 최소 6계정 교차 권한 테스트를 수행한다.

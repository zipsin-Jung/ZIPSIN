# 집별 채팅 최초 전체 회의

- 일자: 2026-10-13
- 상태: 사용자 승인 방향 반영
- 참가 역할: 사용자, 총괄비서, 기획, UX/UI, 설계·개발, 검수·비판

## 공동 결론

채팅은 유료 파일럿의 필수 기능이다. 일반 메신저를 복제하지 않고 집에 연결된 두 대화 공간만 제공한다.

1. `사무소 대화`: 대표와 해당 집의 활성 담당자만 본다.
2. `함께 보는 대화`: 정확히 같은 현재 계약의 임대인·임차인과 허용된 사무소 담당자만 본다.
3. 주소나 ID는 권한이 아니다.
4. 계약·담당·소속 종료 다음 요청부터 접근을 막는다.
5. 다음 계약에는 새 대화가 생기며 이전 계약 내용을 넘기지 않는다.

## 역할별 판단

- 총괄비서: 기존 기능을 보존하고 채팅을 기록 흐름 안에 추가한다.
- 기획: 개인 메신저에 남던 업무를 집의 맥락으로 이어가는 것이 핵심 가치다.
- UX/UI: 모바일 하단과 데스크톱 내비게이션에 `채팅`을 추가하고, 방 종류와 볼 수 있는 사람을 상단에 명확히 쓴다.
- 설계·개발: 권한 원본은 대화 참가자 목록이 아니라 활성 사무소·담당·계약 관계다. 서버와 RLS가 매 요청마다 검사한다.
- 검수·비판: 다른 사무소 노출, 이전 계약 노출, 종료 사용자 접근, 중복 전송을 출시 차단 결함으로 본다.

## 최소 범위

텍스트, 사진·PDF 첨부, 읽지 않은 수, 앱 안 알림, 실패 시 입력 보존을 포함한다. 개인 대화, 임의 단체방, 통화, 반응, 검색, 외부 알림, AI 요약은 제외한다.

## 미확정

최종 보존 기간과 계약 종료 뒤 외부 관계자의 과거 대화 열람 정책은 법률·운영 검토 뒤 확정한다. 파일럿 기본값은 종료 즉시 외부 열람 차단, 사무소 기록 보존이다.

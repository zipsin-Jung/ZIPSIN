# 계약 후부터 만기까지 집 홈 최초회의

- 일자: 2026-10-13
- 상태: 사용자 승인 대기
- 역할: 총괄비서, 제품기획, UX·UI, 설계·개발, 검수·비판, 시간선·대안

## 통합 결론

집신은 `계약 후부터 만기·연장·퇴거까지 필요한 기록과 다음 일을 순서대로 알려주는 집 홈`으로 정리한다. 네 역할 선택은 쉬운 안내 입구로 쓰되 실제 권한은 기존 사무소·집·계약·수리 사건 관계로 분리한다.

## 역할별 결론

- 제품기획: 계약 보관, 입주 기록, 거주관리, 만기퇴거의 네 단계와 최대 3개의 다음 행동으로 단순화한다.
- UX·UI: 한 집 사용자는 집 이름·D-day·만기 계획을 먼저 보고, 여러 집 사용자는 오늘 확인할 집과 만기 임박 집을 먼저 본다.
- 설계·개발: 현재 계약 날짜와 채팅·첨부 기반은 있으나 계약 입력 UI·캘린더·D-day·계획 상태·주소록 조회 모델은 신규 설계가 필요하다.
- 검수·비판: 역할 선택은 권한이 아니며, 자동 기능·법적 증거·안전 보관을 과장하면 안 된다.
- 시간선·대안: 모든 자동화를 한 번에 넣기보다 직접 등록·확인 후 즉시 반영하는 MVP가 가장 가역적이다.
- 총괄비서: 개인 시작 공간 연결, 보존기간, 메시지 수정·철회와 만기 계획 공유 정책은 구현 전에 별도 승인한다.

## 현재 구현과의 주요 차이

- 현재 영구 기본 역할은 대표·보조원·임대인·임차인이며, 실제 인가는 사무소 3역할과 집 관계로 나뉜다.
- 현재 문서는 사진·PDF 업로드·보관 기능이며 촬영 스캔, OCR, 사진→PDF, 기록 PDF 내보내기는 없다.
- 계약 시작·만기 데이터 기반은 있으나 입력 화면, 캘린더, D-day와 만기 계획 상태는 없다.
- 알림은 현재 채팅 중심이며 일정·만기 알림은 추가 설계가 필요하다.

## 추천

1. 집 문맥은 자동 입력한다.
2. 저장·분류·공개범위는 사용자가 확인한다.
3. 저장 성공 뒤 화면은 즉시 갱신한다.
4. 사용 데이터가 쌓인 뒤 자동 `확정`이 아니라 자동 `제안`을 추가한다.

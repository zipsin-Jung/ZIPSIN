# 회원가입 휴대전화 인증·PC 업무 최초회의

- 날짜: 2026-10-13
- 상태: 사용자 요청으로 범위 승인, 구현 진행

## 목표

회원가입 첫 화면부터 휴대전화 번호 인증이 필수임을 알리고, 가입한 개인 계정으로 휴대전화·노트북·PC에서 같은 집 기록을 안전하게 관리한다.

## 여섯 역할 결론

- 총괄: 가입 인증 가시화, 다중 집 탐색, 로그아웃을 이번 범위로 묶는다.
- 제품기획: `계정 → 이메일 확인 → 휴대전화 번호 인증 → 역할`을 고정한다.
- UX/UI: PC 집 목록에 검색·정렬·빠른 기록 행동을 제공하고 모바일 카드를 유지한다.
- 설계·개발: 전화번호는 세션 생성 뒤 인증 단계에서만 받고 현재 서버 강제를 유지한다.
- 검수·비판: 실제 SMS 미연결은 Production P1이며 성공처럼 표시하지 않는다.
- 시간선: PC 전면 ERP화보다 가입·집 목록·로그아웃의 작은 완결 흐름을 먼저 만든다.

## 범위

1. 회원가입 단계표와 휴대전화 인증 안내
2. 인증 오류 상태 구분
3. PC용 집 검색·정렬과 빠른 행동
4. 공용 PC 로그아웃
5. 320·390·768·1280·1440px 검수

## 제외·외부 의존

- 실제 SMS 전송은 공급자 계정·발신번호 승인·비밀키가 필요하다.
- 휴대전화 번호 인증은 공인중개사 자격이나 임대인 소유권 인증이 아니다.
- 다중 선택·일괄 수정·ERP형 화면은 후속이다.

## 게이트

G1 제품·G2 UX는 사용자 요청으로 승인. G3~G5는 구현·독립 검수 후 보고하며 Production은 별도 사용자 승인 전 금지한다.

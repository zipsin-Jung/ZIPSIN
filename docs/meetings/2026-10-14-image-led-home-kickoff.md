# 이미지 중심 공개 홈·앱 홈 최초 회의

- 날짜: 2026-10-14
- 상태: 사용자 승인 범위 확정, 구현 진행
- 참여 역할: 총괄비서, 제품기획, UX·UI 디자인, 설계·개발, 검수·비판, 시간선·대안 분석

## 목표

공개 홈페이지에서는 실제 생활 문제를 이미지로 즉시 이해시키고, 로그인 후 홈에서는 실제 집 데이터와 다음 행동을 이미지가 보조하게 한다. 기존 계약 D-day, 다음 행동, 채팅, 초대와 권한 구조는 보존한다.

## 확인된 사실

- 공개 홈의 여섯 사례와 React 제품 증거 화면은 구현되어 있으나 실제 생활 이미지는 연결되지 않았다.
- 로그인 후 홈은 집 없음·한 채·여러 채 상태와 실제 D-day·다음 행동을 제공하지만 사진 요소가 없다.
- 기존 `public/images`의 전체 화면 합성 시안은 참고 자료이며 제품 자산으로 직접 삽입하지 않는다.
- 실제 첨부는 비공개 저장소와 짧은 signed URL을 사용하지만, 안전한 대표사진 선정 정책과 홈용 조회 모델은 아직 없다.

## 통합 결론

1. 공개 홈에는 흩어진 사진, 외부에서 필요한 계약서, 천장형 에어컨 기록, 도배·장판 전후 비교의 네 장면을 적용한다.
2. 장면 선택 시 `생활 문제 이미지 → 짧은 질문 → 실제 React 해결 화면`이 함께 바뀐다.
3. 기존 사무소 인수인계와 퇴거 가치는 삭제하지 않고 별도 가치 영역에서 유지한다.
4. 로그인 후 홈은 D-day와 다음 행동이 먼저다. 교육 이미지를 실제 집 사진처럼 붙이지 않는다.
5. 안전한 실제 집 썸네일 조회가 이번 범위에서 검증되기 전에는 중립적인 사진 없음 상태만 쓴다.
6. 계약서, 영수증, PDF, 채팅 첨부와 개인정보가 포함된 이미지는 대표사진으로 자동 선택하지 않는다.
7. Preview DB 권한 검증 P1은 시각 개선과 별도의 출시 차단 항목으로 유지한다.

## 범위 제외

- OCR, PDF 생성·내보내기, 사진 자동 분류
- 자동 대표사진 선정과 얼굴 판별
- 전체 앱 화면 전면 재설계
- Production 배포와 Preview DB 권한 변경

## 역할 인계

- 제품·UX: RC-PUB-IMG-001, RC-PUB-EVIDENCE-001, ZH-HOME-MEDIA-001, ZH-HOME-SUMMARY-001, ZH-VIS-A11Y-001 수용 기준 확정
- 설계·개발: 정적 교육 이미지와 비공개 실제 이미지를 분리하고 Next Image, 크기, 폴백, 테스트 구현
- 검수: 320·390·768·1440px, 키보드, 대체텍스트, 콘솔·hydration, 이미지 실패와 기존 동작 회귀 검사
- 총괄: 문서·Git·Preview 증거 통합 후 사용자 승인 요청

## 승인 게이트

- G1 제품: 사용자 승인 완료
- G2 UX·자산: 네 장면 생성·실제 코드 적용 후 Preview 시각 검수
- G3 기술: 실제 집 썸네일은 안전한 조회·권한 검증 전까지 보류
- G4 테스트 설계: 구현 전 TEST-ID와 실패 증거 작성
- G5 검수: 자동검사와 실제 브라우저 증거
- G6 사용자: Preview 확인 후 Production 별도 승인

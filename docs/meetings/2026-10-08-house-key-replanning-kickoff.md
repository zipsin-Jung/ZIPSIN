# 2026-10-08 집 키·임대인 확인·사무소 우선 MVP 재기획

- 상태: 총괄 권고안 · 사용자 승인 대기
- 참여 역할: 총괄비서, 기획·디자인, 설계·개발, 검수·비판

## 1. 목표

공인중개사무소가 임대인의 집신 가입을 기다리지 않고도 사진·문서·업무·인수인계를 안전하게 관리할 수 있게 하면서, 임대인 동의 없이 사무소 자료가 집의 공식·공유 기록으로 표시되는 일을 막는다.

## 2. 확정된 현장 문제

- 공인중개사는 광고를 위해 현장을 방문하고 사진을 찍는다.
- 사진과 계약 자료는 사무실 PC, 개인 휴대폰과 종이 파일에 흩어져 있다.
- 외부에서 자료를 확인하기 어렵고 누락이 발생한다.
- 보조원·직원이 바뀌면 연락, 사진, 일정과 다음 행동이 단절된다.
- 하나의 집을 여러 사무소가 관리할 수 있으며, 주소를 기준으로 모든 기록을 자동 병합하면 중복·추적·분쟁 위험이 크다.
- 임대인은 집신을 모를 수 있으며, 자신의 집 사진이 동의 없이 공개·공유된다고 인식하면 큰 신뢰 문제가 발생한다.

## 3. 핵심 개념 분리

| 개념 | 용도 | 접근 수단 여부 |
|---|---|---|
| `home_id` | 집신 내부에서 집 한 채를 구분하는 영구 ID | 아님 |
| 사무소 내부 집 업무공간 | 해당 사무소가 직접 만든 사진·문서·업무 | 사무소 권한으로만 접근 |
| 임대인 승인 집 공간 | 임대인이 확인하고 승인한 공유 기록 | 관계·기간·범위별 권한으로 접근 |
| 집 연결 초대 | 특정 사람을 특정 집과 연결하는 1회성 수단 | 로그인·본인확인 후 1회 사용 |

`home_id`를 알거나 같은 주소를 입력해도 기록을 볼 수 없어야 한다. 사용자에게는 `집 키`보다 `집 연결 초대`라는 표현이 더 안전하다.

## 4. 대안 비교

| 대안 | 공인중개사 즉시 가치 | 임대인 통제 | 중복·분쟁 위험 | 판단 |
|---|---:|---:|---:|---|
| 임대인이 먼저 인증한 후만 사용 | 낮음 | 높음 | 낮음 | 초기 유료 MVP에 부적합 |
| 공인중개사가 주소로 공용 집 키 발급 | 높음 | 낮음 | 매우 높음 | 제외 |
| 사무소 내부 공간 → 임대인 승인 시 공유 공간 | 높음 | 높음 | 낮춤 | **권장** |
| 모든 집을 집신이 수동 등기 심사 | 낮음 | 중간 | 중간 | 후속 예외 처리용 |

## 5. 권장 구조

```text
대표 공인중개사 확인
→ BUSINESS 사무소 공간 개설
→ 직원 초대
→ 사무소 내부 집 업무 생성
→ 사진·문서·메모·일정·담당·다음 행동 기록
→ 사무소 내부에서만 검색·인수인계
→ 외부 공유가 필요할 때 임대인에게 집 연결 요청
→ 임대인이 본인확인·관계 확인·공유 범위 승인
→ 승인된 기록만 임대인 승인 집 공간으로 연결
```

임대인이 응답하지 않아도 사무소 내부 기록은 계속 사용할 수 있다. 다만 다른 사무소·임대인·임차인에게는 보이지 않는다.

## 6. 인증 용어 구분

| 상태 | 의미 |
|---|---|
| 휴대전화 본인확인 | 이 번호를 사용하는 사람 확인 |
| 임대인 연결 확인 | 중개·임대 관계자로서 요청을 수락 |
| 공유 승인 | 특정 사무소·사람에게 특정 자료 범위를 공유 |
| 소유권 확인 | 등기·법인·공동소유·대리 관계까지 고려한 별도 확인 |

휴대전화 인증 성공과 동시에 `소유자 인증 완료`로 표시하거나 공식 집 권한을 자동 발급하지 않는다.

## 7. 로그인과 진입

- 계정은 공통 로그인으로 유지한다.
- `비즈니스로 로그인`은 따로된 계정이 아니라, 확인된 사무소 공간으로 전환하는 진입이다.
- 대표는 중개사무소 기본정보와 개설등록 정보를 확인받은 후 BUSINESS 대표 권한을 받는다.
- 직원은 대표가 보낸 초대로만 사무소에 참여한다.
- 임대인은 집 연결 요청 링크에서 간편 본인확인과 승인을 완료한다.

## 8. 열람 범위 기본값

| 공간 | 기본 열람자 | 보이지 않는 대상 |
|---|---|---|
| 사무소 내부 원본 | 대표, 배정 직원 | 임대인, 임차인, 타 사무소 |
| 임대인 공유함 | 임대인, 선택된 사무소 | 승인받지 않은 자료·사무소 |
| 현재 계약 공간 | 현재 임대인·임차인·참여 사무소 | 이전 계약의 개인정보 |
| 장기 집 이력 | 임대인과 명시적 승인 대상 | 승계 승인 없는 개인자료 |
| 외부·다른 사무소 | 기본 0명 | 모든 기록 |

## 9. 유료 MVP

### P0

1. 공통 로그인과 휴대전화 본인확인
2. 수동 검토를 포함한 공인중개사무소 BUSINESS 개설
3. 대표·직원 초대·배정·접근 종료
4. 사무소 비공개 집 업무공간
5. 현장 사진·메모·문서·일정 등록
6. 집별 타임라인, 검색, 담당자, 다음 행동
7. 담당자 변경과 인수인계
8. 초대·권한·공유 감사 기록

### P1

1. 임대인 집 연결 요청
2. 임대인 본인확인·수락·거절
3. 자료별 공유 승인·철회
4. 사무소 참여 추가·종료
5. 서버 내부 중복 주소 후보 검토

### 후속

- 등기 기반 공식 소유권 확인
- PDF 정리
- 개인정보를 제거한 장기 집 이력
- 매매 시 안전한 기록 승계

### 제외

- 주소 검색으로 기존 기록 열람·존재 확인
- 휴대전화 본인확인만으로 소유권 인증
- 여러 사무소 기록 자동 병합
- 임대인 동의 없는 외부 공유
- 실결제, PDF, 외부 공개 매물 페이지

## 10. 필수 수용 기준

- 주소 검색으로 기록 존재, 사진 수, 사건, 참여자를 알 수 없다.
- 임대인 미확인 자료는 다른 사무소·임대인·임차인에게 보이지 않는다.
- 역할 선택, 휴대전화 본인확인, 사업자 확인만으로 특정 집 권한이 생기지 않는다.
- 같은 주소를 이유로 다른 사무소 자료를 자동 병합하지 않는다.
- 직원 접근 종료 즉시 세션과 파일 접근을 차단한다.
- 이전 임차인의 이름·연락처·대화·문서·원본 사진을 다음 계약에 자동 승계하지 않는다.
- 만료·폐기·사용된 초대는 재사용할 수 없다.

## 11. 법률·정책 주의

- 민감한 주민등록번호 뒷자리를 인증 수단으로 수집하지 않는다.
- 휴대전화 본인확인은 번호 사용자를 확인할 뿐 소유권을 증명하지 않는다.
- 공식 소유권 자동 확인은 법률·개인정보·제휴 가능성을 별도 검토한 후에만 추진한다.
- 이 문서는 제품 설계 권고안이며 법률 자문이 아니다.

## 12. 파일럿 검증 가설

1. 임대인 가입 없이도 사무소 내부 기록·인수인계만으로 월 이용료를 낼 의향이 있는가.
2. 실제 집 5~20개를 4주 동안 계속 등록·재열람하는가.
3. 외근·현장에서 필요한 사진과 문서를 다시 찾는가.
4. 직원 변경 시 새 담당자가 별도 설명 없이 다음 행동을 찾는가.
5. 임대인 연결 요청의 수락률과 거절 이유는 무엇인가.
6. 권한·삭제·분쟁 문의를 현실적으로 운영할 수 있는가.

## 13. 승인 게이트

사용자가 다음 방향을 승인한 후 새 의사결정 기록과 제품 명세를 작성한다.

> 공인중개사 유료 MVP는 사무소 비공개 집 업무공간으로 시작하고, 임대인이 확인·승인한 자료만 별도 공유 집 공간으로 연결한다.

승인 전에는 로그인, 집 키, 권한, 화면 흐름을 개발하지 않는다.

# 2026-10-14 로그인·회원가입·휴대폰 인증 킥오프

## 목적

집신체크 유입 사용자를 실제 집신 회원으로 안전하게 전환하기 위해 로그인 이미지, 아이디 중복확인, 실제 휴대폰 인증과 이메일·휴대폰 계정 복구를 한 흐름으로 정리한다.

## 여섯 역할 결론

- 총괄비서: 실제 연결 가능한 인증수단, 개인정보·비용과 G1~G6 증거를 먼저 고정해야 한다.
- 제품기획: 아이디 중복확인은 사전 안내이며 DB unique가 최종 방어다. 가입·복구의 모든 오류·제한 상태가 필요하다.
- UX·UI: 데스크톱 왼쪽은 제공 이미지로 교체하고 모바일은 폼을 우선한다. 가입은 계정 정보와 휴대폰 인증 두 단계로 단순화한다.
- 설계·개발: 실제 SMS 공급자 없이 완료 주장은 불가능하다. 기존 custom provider 경계에 SOLAPI transport를 추가하는 것이 최소 변경이다.
- 검수·비판: `/ck` SMS 우회, 계정 열거, OTP 재사용, production mock은 P0/P1 출시 차단 조건이다.
- 시간선·대안: 집신체크 익명 사용은 유지하고 계정 생성 시에만 실제 SMS를 요구하는 안을 추천한다.

## 결정·가정·미결정

- 사용자 결정: 실제 휴대폰 인증까지 연결한다.
- 추천 결정: 월 기본료 없이 건당 과금되는 SOLAPI를 사용한다.
- 가정: 제공 이미지는 사용자가 집신 로그인 화면에 사용할 권리를 가진 자산이다.
- 미결정: SOLAPI 계정·발신번호·충전 방식과 비밀키 입력은 서면 명세 승인 뒤 외부 설정 단계에서 진행한다.

## 게이트

- G1/G2: `AUTHUX-001~006`과 두 단계 흐름 사용자 서면 검토
- G3: SOLAPI transport, OTP DB/RPC, 휴대폰 복구 세션 설계 승인
- G4: 보안·실패·접근성 TEST-ID 계획 승인
- G5: 실제 SMS Preview 왕복과 독립 품질검수
- G6: 운영 배포 전 사용자 최종 승인

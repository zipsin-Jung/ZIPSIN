# 집신체크 홈·전체목록·모션 최초회의

## 목표

홈의 중복을 줄이고 최근 3채와 시작 행동에 집중시킨다. 저장된 모든 집은 별도 `내가 본 집` 화면에서 안전하게 열고 삭제하며, 클릭 가능한 요소에만 절제된 마이크로 인터랙션을 제공한다.

## 여섯 역할 결론

- 총괄비서: 승인 프롬프트를 ZCC-011~012와 G1~G6으로 묶고 운영 배포는 제외한다.
- 제품기획: 최근 노출 3채와 전체 보관 수를 분리하고 전체목록을 독립 화면으로 만든다.
- UX·UI: 홈 캐릭터는 히어로 1개, 문의 캐릭터 1개만 유지하고 상세·메모 안내는 화면별 한 번만 제공한다.
- 설계·개발: `Screen`에 `list`를 추가하고 기존 `StoredCheckStateV2`를 그대로 재사용한다. 저장 키·후보 ID·사진 키는 바꾸지 않는다.
- 품질·비판: 홈/목록 handler, popstate, 삭제 실패, 0·1·4·10채, 긴 별명, 320px와 reduced-motion을 검증한다.
- 시간선·대안: 홈에 전체목록을 계속 두는 안은 단기 구현량은 적지만 중복과 내비 의미 불일치가 누적된다. 별도 목록은 가역적이며 계정 동기화 이후에도 확장하기 쉽다.

## 확정 범위

- 등록 최신순(`createdAt`)으로 홈 최대 3채와 전체목록을 일관되게 정렬한다.
- 홈 하단 전체목록과 삭제를 제거하고 `내가 본 집` 별도 화면으로 이동한다.
- 승인된 빈 카드 3개, 기존 등록·체크·메모·사진·비교·원자적 삭제를 유지한다.
- 홈 안내 캐릭터를 제거하고 전구 아이콘으로 대체한다.
- 홈 미리보기에 상세 체크·메모·사진 안내를 한 번 표시하고 실제 체크의 카드별 반복 안내를 제거한다.
- 클릭 가능한 요소에만 hover·press·focus 피드백을 추가하고 reduced-motion에서 이동을 제거한다.

## 제외

- 저장 스키마 변경, 서버·계정 동기화, 검색·필터·페이지네이션, 새 애니메이션 라이브러리, 운영 배포.

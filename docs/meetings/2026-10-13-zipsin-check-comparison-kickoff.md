# 집신체크 비교 중심 V2 최초회의

- 일자: 2026-10-13
- 역할: 총괄비서, 제품기획, UX·UI, 설계·개발, 검수·비판, 시간선·대안

## 통합 결론

집신체크의 중심 결과를 집별 카드 묶음에서 동일 행 비교표로 바꾼다. 현장은 필수 5개로 줄이고 메모 안에 사진을 둔다. 집 기록은 여러 채 보관하되 비교 선택은 2~3채로 분리한다. 서버 계정 이전보다 로컬 비교 가치를 먼저 검증한다.

## 역할별 핵심 의견

- 제품기획: 사회초년생의 `빠른 기록→동일 기준 비교→재연락`을 MVP 완결 흐름으로 정의한다.
- UX·UI: 모바일에서 왼쪽 항목 열과 상단 집 헤더를 유지하고 집 열만 가로 이동한다.
- 설계·개발: schema v2, 구조화 가격·연락처, 비교 ID 목록과 v1 비파괴 이전이 필요하다.
- 검수·비판: 후보 보관/비교 선택 분리, 행동 체크/결과 분리, 영구 삭제, 무손실 이전이 구현 선행 조건이다.
- 시간선·대안: 현재 카드 유지나 즉시 서버화보다 로컬 비교표+5항목이 가장 작고 가역적인 실험이다.
- 총괄비서: 위 조건을 `ZCC-001~008`과 G1~G6 승인 게이트로 통합한다.

## 게이트

- G1 제품: ZCC-001~008과 MVP 범위 사용자 승인
- G2 UX: 등록·현장·후보 선택·비교표 상태 승인
- G3 설계: v2 마이그레이션·삭제·개인정보 경계 승인
- G4 테스트: TEST-ID와 브라우저·접근성 범위 승인
- G5 검수: 자동검사, 실제 브라우저, 독립 P0/P1 0건
- G6 완료: 사용자 최종 승인 뒤에만 운영 배포 검토

## 제외

운영 배포, 실제 로그인, 서버 저장, 계정 이전, 자동 매물 수집, 추천 점수와 안전 판정은 이번 승인 범위가 아니다.

# 로그인 홈 시각 재설계 최초회의

## 목표

로그인 후 홈에서 사용자가 5초 안에 집신이 필요한 이유를 이해하고, 자기 집에 필요한 첫 기록을 바로 남기게 한다.

## 여섯 역할 결론

- 총괄비서: 거대한 홍보 배너를 제거하고 문제 장면과 실제 행동을 연결한다.
- 제품기획: 신규 사용자는 필요 기록을 모를 수 있으므로 집별 체크리스트와 상세 이유를 제공한다.
- UX·UI: 에디토리얼 워크스페이스를 채택하고, 실제 생활 사진과 절제된 한글 타이포를 사용한다.
- 설계·개발: 기존 비공개 첨부와 RLS를 유지하고 새 DB 구조 없이 홈 조회와 컴포넌트를 보완한다.
- 검수·비판: 가짜 데이터 금지, 정상 빈 상태와 조회 오류 구분, 모바일·PC 실제 검수를 요구한다.
- 시간선·대안: `/home`과 앱 헤더부터 완성한 뒤 승인된 시각 체계를 다른 화면으로 확장한다.

## 범위

- 신규·초기 사용자를 위한 문제 인식 장면
- 집별 기록 시작 체크리스트
- 항목별 `왜 필요한가요?` 상세 설명
- 기록이 쌓인 사용자의 실제 집·할 일·대화 홈
- 모바일 390px, 데스크톱 1440px 우선 시안과 구현

## 제외

- 새 분석 시스템과 가짜 완성도
- 이미지 변환 파이프라인
- 다른 모든 앱 화면의 동시 전면 개편
- Production 배포

## 게이트

- G1 제품: 사용자 방향 승인 완료
- G2 UX: 본 명세 사용자 검토 필요
- G3 아키텍처: 구현계획에서 쿼리·이미지 경계 확정
- G4 테스트 설계: 요구사항별 테스트 ID 확정
- G5 검증: 모바일·PC·접근성·권한 검수
- G6 사용자: Preview 승인 후에만 Production 검토

# 집신 챗·공식 고객지원 전체회의

- 일자: 2026-10-13
- 참가: 사용자, 총괄비서, 제품기획, UX/UI, 설계개발, 검수비판, 시간선 분석

## 사용자 확정

- 카카오톡처럼 집신 자체 채팅이 필요하다.
- 중개사·임대인·임차인·수리기사가 서로 대화한다.
- 집신 고객지원은 대표와 직통이며 초기에는 대표가 직접 답한다.
- 별도 담당자 개념은 없다.
- 지금은 사진을 직접 올리고 자동 집 기록 업데이트는 후속이다.

## 공동 결론

공통 메신저 기반을 만들고 여섯 방 종류를 관계에 맞게 분리한다. 전화번호와 주소록을 사용하지 않는다. 공식 고객지원 권한은 다른 대화 열람으로 확장되지 않는다.

## 주요 위험

- 공식계정 사칭과 운영자 과잉 접근
- 이전 계약자·종료된 수리기사 정보 노출
- 자유 채팅의 스팸·신고·차단 운영
- 실시간 연결과 파일 저장 비용
- 자동 기록 기능을 성급히 붙였을 때 잘못된 집으로 복사될 위험

## 단계

G1 제품: 방 종류와 직접 업로드 확정
G2 UX: 채팅 목록·방·초대·지원·신고 상태 확정
G3 설계: 권한·RLS·실시간 복구·공식계정 분리
G4 테스트 설계: 교차 권한·사칭·중복·종료 시나리오
G5 검증: 실제 두 계정·Preview·브라우저·스트레스·80% 커버리지
G6 사용자: Production 배포 전 최종 승인

## 다음 행동

정식 명세를 사용자에게 제출하고 승인받은 뒤 구현계획을 작성한다.

# 공개 홈 설치·모션 최초 회의

- 날짜: 2026-10-14
- 상태: 회의 완료, 사용자 문서 검토 대기

## 요청

공개 홈 오른쪽 위에 실제 `앱으로 다운로드`를 넣고, 첫 이미지가 잘 보이지 않는 문제를 해결하며 네 장 모두 의미에 맞는 고급 애니메이션을 적용한다.

## 역할별 결론

### 총괄비서

기존 한 화면·가로 캐러셀·가입·로그인을 보존한다. 작업은 설치 메타데이터, 설치 UX, 네 장 모션, 검증과 Preview로 제한한다.

### 제품기획

설치 가능·iOS 안내·일반 안내·설치됨 네 상태를 구분한다. 앱스토어와 네이티브 앱을 제공하는 것처럼 표현하지 않는다.

### UX·UI 디자인

첫 이미지의 `contain` 축소가 가시성 저하의 주원인이다. 확장 배경과 선명한 전경을 사용하고, 나머지 세 장도 각 메시지를 설명하는 1회성 모션을 갖게 한다. 큰 외곽 카드와 중첩 테두리를 약화한다.

### 설계·개발

`app/manifest.ts`와 독립 Install 컴포넌트를 사용한다. 지원 브라우저에서만 `beforeinstallprompt`를 호출하고 iOS·미지원은 안내로 처리한다. 서비스 워커와 외부 PWA 패키지는 사용하지 않는다.

### 검수·비판

단위 테스트의 가짜 이벤트만으로 실제 설치 완료를 주장하지 않는다. 네 viewport, reduced-motion, dialog 포커스, CLS, axe·console과 HTTPS Preview 설치를 분리 검증한다.

### 시간선·대안 분석

현 상태 유지는 설치 요구를 충족하지 못하고, 네이티브 앱은 현재 근거와 준비가 부족하다. Manifest 기반의 되돌릴 수 있는 PWA 실험이 현재 최선이다.

## 통합 결론

`온라인 전용 PWA 설치 CTA + 승인 합성 이미지를 살리는 네 장의 1회성 시네마틱 모션`으로 진행한다. 푸시·오프라인·네이티브 앱·로그인 후 제품 변경은 제외한다.

## 승인 게이트

G1 제품 방향은 사용자 승인 완료다. G2 UX·G3 설계·G4 테스트는 설계 문서 검토 뒤 확정하고, G5 구현 검증과 G6 Preview 사용자 승인을 분리한다. Production은 G6 전까지 변경하지 않는다.

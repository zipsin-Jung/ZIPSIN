# 2026-10-08 미션 5 CRUD 최초 회의

## 목표

기존 집신 랜딩과 데모를 보존하면서 Supabase에 저장되는 가상 수리 기록 CRUD 1개로 부트캠프 미션 5를 완성한다.

## 사실·가정·추천·제외

- 사실: 기존 `/`는 랜딩, `/demo`는 저장 없는 영업 데모이다.
- 사실: 현재 `output: export`는 Server Action과 함께 사용할 수 없다.
- 가정: 평가자는 가상 데이터로 CRUD와 이미지 저장을 확인한다.
- 추천: 비공개 Storage, 서버 전용 Supabase 클라이언트, 고정 개인정보 경고를 사용한다.
- 제외: 인증, RLS, 실제 주소·연락처·계약서, 결제·알림·채팅.

## 네 역할 결론

- 총괄비서: 기존 자료와 미완료 작업을 보존하고 미션 요구를 별도 기능으로 관리한다.
- 기획·디자인: `M5-REC-001~006`과 `/records` 흐름, 모든 화면 상태를 정의한다.
- 설계·개발: Next.js 서버 런타임, Supabase DB·Storage, 서버 검증과 부분 실패 정리를 구현한다.
- 검수·비판: 실 DB CRUD, 파일, 404, 접근성, 반응형, 로컬·배포 결과를 분리 판정한다.

## 순서와 승인

1. 명세·DB·보안 경계 기록
2. 테스트 우선 구현
3. 정적·타입·단위·빌드 검사
4. 브라우저와 배포 CRUD 검수
5. README·QA·작업기록 반영, Git 저장과 제출 정리

사용자는 2026-10-08 중간 확인 없이 완성까지 진행하라고 지시했다. 이를 기능 범위와 네 역할 인계의 승인으로 기록한다. 외부 계정 로그인·비밀값 입력은 권한이 없으면 최종 미검증으로 분리한다.

# 카카오톡 문의 버튼 최초 회의

날짜: 2026-10-13
참여 역할: 총괄비서, 제품기획, UX·UI, 설계·개발, 품질·비판, 시간선·대안

## 목표

모든 화면에서 집신 대표에게 바로 문의할 수 있는 카카오 채널 진입 버튼을 제공한다.

## 역할별 결론

- **총괄비서:** 내부 고객지원은 기록 원본으로 유지하고 카카오는 외부 유입창구로 병행한다.
- **제품기획:** 가입 전·로그인 장애·간단 문의를 해결하며 집·계약 업무대화를 대신하지 않는다.
- **UX·UI:** 오른쪽 아래에 고정하고 모바일 하단 메뉴와 입력창 위에 배치한다.
- **설계·개발:** 루트 레이아웃의 단일 서버 컴포넌트와 일반 HTTPS 링크만 사용한다.
- **품질·비판:** 정확한 주소, 새 창 보안 속성, 접근성 이름, 320·390·768·1440px 비가림을 검증한다.
- **시간선·대안:** 지금은 가역적인 외부 링크가 적합하고 API·AI 통합은 후속 승인으로 미룬다.

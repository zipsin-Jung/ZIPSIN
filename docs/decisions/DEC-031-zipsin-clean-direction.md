# DEC-031 집신클린 방향: 고객은 판단하지 않고, 가격은 예약할 때 확정

- 결정일: 2026-10-18
- 상태: 사용자 결정(방향). 2026-10-18 오후 대표 지시로 개발 시작: 집신체크처럼 같은 앱 안의 별도 서비스(`/cl`, 나중에 cl.zipsin.net), 회원가입·로그인은 집신과 통합. 첫 화면은 가격 바로 보기. 매칭·결제는 아직 만들지 않음.
- 결정한 사람: 대표(정민선)
- 관련: DEC-030(집신클린은 집신 아래 하위 서비스, cl.zipsin.net), DEC-029(기록 세 칸·집 이력)
- 상세 기획안: Claude Docs "집신 클린 기획안 v0.1" (https://claude.ai/code/artifact/3d2cbefe-cd17-4fad-9e1a-4ad31e105742)

## 결정

1. 집신클린은 **청소 중개**다. 집신 본체(집 기록)는 중개 플랫폼이 아니며, 클린은 메뉴로만 연결되는 하위 서비스로 둔다.
2. 주소는 `cl.zipsin.net`(집신체크 `ck.zipsin.net`과 짝).
3. **가격은 예약할 때 확정하고 현장에서 바뀌지 않는다.** 오염에 관한 모든 것은 등급(1·2·3) 안에 넣는다.
   - 이 집에 집신 사진(집신체크·퇴거 기록, 고정 부위·최근 사진만)이 있으면 집신 또는 인증 파트너가 등급을 판정한다.
   - 없으면 고객이 고른 사실(평수·준공 연도·베란다 모양 그림·공실 기간 등, "모름" 가능)로 계산한다.
   - 고객은 물때·기름때를 판단하지 않는다.
4. 현장 변경은 확인 가능한 사실이 틀렸을 때만. "등급 외"(쓰레기집·화재·누수)는 가격 인상이 아니라 위약금 없는 취소.
5. 처음에는 한 구, 집신이 직접 만나 검증한 인증 업체 5곳(+예비 1~2곳). 기준은 금액이 아니라 실력·약속·태도. 작업 시작 후 추가금 요구는 즉시 퇴출.
6. 동네 이모님은 평가·배제하지 않고 "사무소 직접 연결"로 표시만 구분한다.
7. 중개사 추천 보상은 현금이 아닌 구독료 크레딧, 작업 완료·고객 만족 확인 후 지급, 운영자 스위치로 켜고 끈다(처음엔 끔).

# DEC-024 공개 홈을 단일 화면 가로 이야기로 전환

- 날짜: 2026-10-14
- 상태: 적용 완료, Production 반영 전 사용자 승인 대기

## 결정

공개 홈에서 세로 장문 섹션을 제거하고 `헤더 + 한 화면짜리 네 장 가로 캐러셀`만 제공한다. 첫 장은 승인 이미지의 합성 구도를 활용한 1회 카메라 이동과 오른쪽 구절 reveal로 집신의 핵심 메시지를 전달한다.

## 이유

- 사용자는 공개 홈을 긴 랜딩페이지가 아니라 한 화면에서 바로 이해하고 좌우로 넘기는 제품 소개로 요청했다.
- 중복 설명과 제품 증거 카드가 이미지와 핵심 문장의 집중도를 낮췄다.
- 현재 이미지는 한 장으로 합쳐져 있어 개별 물체 애니메이션보다 팬·줌 방식이 자연스럽고 되돌리기 쉽다.

## 영향

- 헤더의 세로 앵커 메뉴와 공개 홈 아래 섹션·푸터가 사라진다.
- 회원가입·로그인·카카오 문의와 로그인 후 제품은 유지한다.
- 상세 설명이 필요하면 이후 별도 소개·도움말 경로에서 제공한다.

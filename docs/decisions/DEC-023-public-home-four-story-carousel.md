# DEC-023 공개 메인 4장 스토리 캐러셀

- 날짜: 2026-10-14
- 상태: 사용자 수정사항 반영, 서면 명세 최종 검토 대기

## 결정

공개 메인의 기존 Hero와 별도 네 사례 탐색을 하나의 4장 스토리 캐러셀로 통합한다. 네 장의 순서는 `모인다 → 이어진다 → 연결된다 → 가치가 된다`로 확정한다. 전환은 과한 3D 종이 말림이 아니라 얕은 그림자와 수평 이동을 사용한다. 7초 간격으로 한 번만 자동재생하고 4장에서 멈춘다.

점은 장면 목차로 사용한다. 250ms hover 시 해당 장을 미리 선택하고, click·tap·키보드·swipe 같은 명시적 조작 뒤에는 자동재생을 멈춘다. 이전·다음과 재생·일시정지 버튼을 함께 제공한다.

## 이유

- 첫 장의 `흩어진 기록이 집신으로 모인다`는 이미지만으로 제품 정의를 설명할 수 있다.
- 두 번째 장은 같은 집에서 사람이 바뀌어도 비개인 관리 기록이 이어진다는 제품 원칙을 보여준다.
- 세 번째 장은 통화·개인 메신저·주소록을 집과 관계 기준으로 연결하는 사용 가치를 보여준다.
- 네 번째 장은 집의 관리 이력이 흠이 아니라 신뢰와 자산 설명의 근거가 되는 주거 문화를 제안한다.
- 무한재생과 과한 3D는 내용을 읽는 사람과 경쟁하며 모바일 성능과 접근성을 해칠 수 있다.
- 기존 사례 데이터와 React 증거 UI를 재사용하면 설명과 실제 구현의 간격을 줄일 수 있다.

## 결과

- 기존 별도 `ScenarioExplorer`는 중복되지 않도록 Hero에 통합한다.
- 로그인 홈, DB, 권한과 Production 배포는 바꾸지 않는다.
- 이전 계약자의 개인정보와 비공개 대화를 다음 사람에게 자동으로 넘기는 표현을 금지한다.
- 법적 검증, 하자 없음 또는 자산 가격 상승을 보장하는 표현을 금지한다.
- 모션 감소 설정에서는 자동재생과 책장형 모션을 제공하지 않는다.
- 사용성 검수에서 자동전환이 방해되면 수동 전용으로 되돌릴 수 있다.

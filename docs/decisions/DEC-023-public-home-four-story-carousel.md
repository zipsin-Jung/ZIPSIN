# DEC-023 공개 메인 4장 스토리 캐러셀

- 날짜: 2026-10-14
- 상태: 사용자 재승인 반영·로컬 검증, Vercel Preview 재검증 대기

## 결정

공개 메인의 기존 Hero와 별도 네 사례 탐색을 하나의 4장 스토리 캐러셀로 통합한다. 사용자 재승인에 따라 네 장의 순서는 `살펴본다 → 정리한다 → 모은다 → 이어간다`로 확정한다. 이는 이미지 원본 기준 `4 → 3 → 1 → 2`이며, `서론 → 본론 → 과정 → 결론`의 이야기 구조다. 전환은 과한 3D 종이 말림이 아니라 얕은 그림자와 수평 이동을 사용한다. 7초 간격으로 한 번만 자동재생하고 4장에서 멈춘다.

점은 장면 목차로 사용한다. 250ms hover 시 해당 장을 미리 선택하고, click·tap·키보드·swipe 같은 명시적 조작 뒤에는 자동재생을 멈춘다. 이전·다음과 재생·일시정지 버튼을 함께 제공한다.

## 이유

- 첫 장은 위치와 계약 서류만 보던 관성을 질문하고 집 내부 관리 이력까지 살펴봐야 한다는 문제를 제시한다.
- 두 번째 장은 외부 통화·문자·개인 메신저·주소록이 섞이는 현재 문제를 보여주되, 외부 기록선은 집신 앞에서 끝낸다. 집신에서는 직접 초대·연락처 저장·전용 채팅을 사용한 시점부터 집별 새 기록이 시작된다.
- 세 번째 장은 흩어진 사진·문서·대화·일정이 집 한 채에 모이는 제품 정의를 가장 강한 카메라 이동으로 증명한다.
- 네 번째 장은 같은 집에서 사람이 바뀌어도 비개인 관리 기록은 이어진다는 제품 원칙으로 결론을 맺는다.
- 무한재생과 과한 3D는 내용을 읽는 사람과 경쟁하며 모바일 성능과 접근성을 해칠 수 있다.
- 기존 사례 데이터와 React 증거 UI를 재사용하면 설명과 실제 구현의 간격을 줄일 수 있다.

## 결과

- 기존 별도 `ScenarioExplorer`는 중복되지 않도록 Hero에 통합한다.
- 로그인 홈, DB, 권한과 Production 배포는 바꾸지 않는다.
- 이전 계약자의 개인정보와 비공개 대화를 다음 사람에게 자동으로 넘기는 표현을 금지한다.
- 법적 검증, 하자 없음 또는 자산 가격 상승을 보장하는 표현을 금지한다.
- 카카오톡·문자·통화 이력 연동 또는 자동 가져오기가 가능한 것처럼 표현하지 않는다.
- 모션 감소 설정에서는 자동재생과 책장형 모션을 제공하지 않는다.
- 사용성 검수에서 자동전환이 방해되면 수동 전용으로 되돌릴 수 있다.

## 적용 결과

- 네 장 캐러셀과 승인 이미지를 공개 `/`에 적용했다.
- 같은 높이로 고정하면 짧은 모바일 장면 아래 큰 빈 공간이 생겨, 활성 장면의 실제 높이를 측정해 550ms 동안 조절하는 방식으로 확정했다.
- 허용하는 장면 하단 여백은 최대 40px이다. 데스크톱의 의도한 34px 여백은 유지하고, 모바일에서 발견한 247px 공백은 재발 테스트로 막는다.
- 독립 검수 뒤 무대에 `touch-action: pan-y`를 적용해 실제 수평 손가락 이동을 보장하고 세로 스크롤은 유지한다.
- 손가락을 누르는 동안과 캐러셀이 화면 밖에 있을 때는 자동재생을 멈춘다. CTA 링크의 방향키는 장면 전환에 사용하지 않아 포커스를 잃지 않게 한다.
- 무대 밖에서 손가락이나 마우스를 놓아도 전역 pointer 종료 이벤트로 누름 상태를 해제해 자동재생이 잠기지 않게 한다.
- 모바일 순서는 설명→이미지·제품 증거→CTA이며 `n / 4` 페이지 숫자를 항상 표시한다.
- Production은 변경하지 않았다.

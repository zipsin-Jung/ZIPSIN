# DEC-023: 초기 영업·마케팅 채널 검증 순서

- 날짜: 2026-10-18
- 상태: 사용자 승인 대기

## 결정안

- 초기 고객은 대표와 직원이 함께 일하고 여러 집의 자료·업무가 흩어진 공인중개사무소로 좁힌다.
- 채널은 `대표 직접영업 → 소규모 소개 → 영업 지원 콘텐츠 → 검증 후 유료광고` 순서로 확장한다.
- 첫 4주는 매출 확대보다 최근 실제 문제, 데모 이해와 실제 자료·직원·일정 준비 약속을 검증한다.
- 실제 제품 준비 전에는 가상 데모를 무료 체험, 실제 접수, 반복 사용 또는 결제로 표현하지 않는다.
- 개인정보와 실제 계약 자료는 영업 검증표와 Git에 저장하지 않는다.

## 이유

- 현재는 실제 저장·초대·결제 제품이 아니라 랜딩페이지와 가상 데모 단계다.
- 직접영업은 적은 비용으로 고객의 현재 업무, 반대 이유와 실제 사용하는 언어를 확인할 수 있다.
- 소개와 광고를 먼저 확대하면 잘못된 고객군·문구를 큰 비용으로 반복할 위험이 있다.
- 실제 자료 준비와 직원 참여 같은 비용 있는 행동이 호감 표현보다 강한 수요 증거다.

## 전환 조건

- 직접영업에서 문제와 비용 있는 약속이 확인되면 소규모 소개 채널을 시험한다.
- 동일한 설명과 온보딩으로 실제 사용·결제·8주 유지가 확인되면 콘텐츠와 유료광고 실험으로 확대한다.
- 기준 미달이면 채널을 늘리지 않고 고객군·문구·핵심 흐름을 다시 정의한다.

## 제외

- 전국 광고 집행
- 대규모 영업 인력 채용
- 미구현 기능과 절감 효과의 과장
- 임대인·임차인 대상 대중 캠페인

세부 기준은 `docs/25-sales-marketing-validation-plan.md`를 따른다.

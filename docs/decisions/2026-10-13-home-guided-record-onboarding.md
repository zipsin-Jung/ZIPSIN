# 결정: 집신 홈은 문제 인식과 기록 체크리스트를 연결한다

- 날짜: 2026-10-13
- 상태: 사용자 방향 승인

## 결정

가입 직후 홈은 빈 대시보드나 서비스 소개가 아니라, 사용자가 미처 인지하지 못한 집 기록의 필요성을 실제 생활 장면으로 보여주고 해당 기록을 하나씩 남기도록 안내한다.

기본 장면 순서는 다음과 같다.

1. 컴퓨터 폴더와 휴대전화 사진첩에 흩어진 여러 집의 사진
2. 외출 중 급히 필요하지만 집 서랍에 있는 종이 계약서
3. 모델·설치·이전 수리 정보를 확인하기 어려운 천장형 에어컨

장면을 본 뒤에는 선택한 집의 기록 체크리스트로 바로 이어진다. 각 항목에는 `왜 필요한가요?` 상세 설명을 제공하며, 완료 여부는 실제 등록 데이터만으로 계산한다.

## 이유

- 고객은 어떤 기록이 필요한지 미리 알지 못할 수 있다.
- 추상적인 기능 설명은 집신의 사용 이유를 전달하지 못한다.
- 생활 장면과 즉시 실행할 행동을 연결하면 집신의 핵심인 반복·누락·단절 방지가 이해된다.

## 제외

- 가짜 집, 가짜 완료율, 가짜 통계
- AI 생성 이미지를 사용자의 실제 집 기록처럼 표시
- 공인중개사 전용 체크리스트
- 한 번에 전체 앱을 다시 디자인하는 작업

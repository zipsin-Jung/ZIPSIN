# DEC-022 집신체크 가입 확보 우선

- 일자: 2026-10-14
- 상태: 사용자 확정

## 결정

집신체크는 집신 본 서비스가 완성되기 전 사회초년생·임차인을 먼저 모으는 공개 유입 도구다. 따라서 Google·Kakao 간편가입을 핵심 결과로 열어 두고, 집신 본 서비스와 `내 집` 자동 등록만 준비 중으로 구분한다.

일반 가입은 후보 기록 이전 동의로 막지 않는다. 특정 후보를 `집신에 저장`하는 흐름에서만 이전 동의를 받는다. Naver는 실제 Custom OAuth가 준비되기 전까지 잘못된 가입 기대를 만들지 않도록 노출하지 않는다.

## 영향

- 사용자는 상단 `간편 로그인·회원가입`에서 바로 가입을 시작한다.
- 가입 유입 출처는 `zipsin_check`로 기록한다.
- OAuth 시작 버튼 노출과 실제 외부 인증 완료는 구분해 검수한다.
- 운영 배포 전에 Supabase URL·Anon Key·공급자 키·callback URL을 반드시 확인한다.

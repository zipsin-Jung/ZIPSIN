# DEC-017 집신체크 공개 도구와 대표 경로

- 날짜: 2026-10-13
- 상태: 사용자 승인

## 결정

집신체크를 데모가 아닌 로그인 없는 공개 유입 도구로 제공한다. 대표 경로는 `zipsin.net/ck`이며 기존 `/check`도 호환 경로로 유지한다. 빠른 9개와 꼼꼼 16개 항목은 페이지를 하나씩 넘기지 않고 한 화면에서 선택한다. 후보 비교는 카드와 공통 핵심 표를 함께 제공한다.

## 이유

현장에서는 반복적인 다음 버튼이 이탈과 누락을 만든다. 한 화면 방식은 전체 분량과 남은 일을 바로 보여주며 사용자가 원하는 순서로 확인하게 한다. 짧은 `/ck`는 홍보물과 공유 링크에 쓰기 쉽다.

## 계정과 개인정보

현재 V1은 로그인과 서버 저장을 구현하지 않고 브라우저에만 저장한다. 향후 인증을 붙일 때는 집신과 같은 세션·계정을 사용하며 집신체크 전용 계정을 만들지 않는다. 동네·건물 별칭만 선택 입력하고 상세 주소·동호수·연락처·출입 비밀번호는 받지 않는다.

## 결과와 되돌리기

`/ck`와 `/check`가 같은 앱을 사용하므로 한쪽 경로를 제거하지 않고 전환 효과를 검증할 수 있다. 운영 배포 전에는 로컬 구현만 유지한다.

# 홈노크 경쟁 참고 범위 결정

- 일자: 2026-10-13
- 상태: 확정

## 결정

홈노크를 집신의 주요 경쟁사이자 부동산 산업 신뢰 레퍼런스로 관리한다.

- 배움: 이득 중신 정보 구조, 실적의 기준일 표시, 약관·회사정보·제휴를 통한 신뢰, 개별 서비스 설명 페이지
- 금지: 문구, 색상, 그래픽, 3D 자산, 화면 배치, 애니메이션의 직접 복제
- 차별화: 홈노크의 `자산·임대료·세금`과 다른 `집·사건·기록·다자간 협업·권한`을 집신의 핵신으로 유지

## 이유

직접 복제는 지식재산·브랜드 신뢰 위험을 만들고, 자산관리 서비스와 집신의 정체성을 같게 만든다. 반면 경쟁사가 증명한 신뢰 형성 원리를 독자적 화면에 적용하는 것은 집신의 설명력과 완성도를 높인다.

## 영향

- 홈화면은 기능 목록보다 사용자 이득과 실제 제품 UI를 먼저 보여준다.
- 수납·세금·시세는 초기 MVP에 추가하지 않는다.
- 개발 전 스토리보드에서 홈노크와 혼동되는지를 다시 검수한다.

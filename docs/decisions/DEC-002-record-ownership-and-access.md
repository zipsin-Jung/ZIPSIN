# DEC-002: 기록 소유와 접근 원칙

- 날짜: 2026-09-30
- 상태: 1차 확정

## 결정

- 주소만으로 기록을 공개하지 않는다.
- 집 ID는 시스템이 자동 생성한다.
- 기록은 개인 직원이 아니라 집·계약·사무소 업무에 연결한다.
- 임대인은 집 연결과 중개사 참여를 관리한다.
- 임차인은 현재 계약과 본인이 참여한 사건에 접근한다.
- 이전 계약의 개인정보는 다음 계약으로 자동 전달하지 않는다.
- 공개 범위는 복잡한 사진별 설정보다 안전한 공간별 기본값으로 제공한다.

## 남은 결정

- 공식 소유권 확인 수준
- 집 매매 시 기록 이전 기준
- 사무소 폐업 시 기록 이전 절차

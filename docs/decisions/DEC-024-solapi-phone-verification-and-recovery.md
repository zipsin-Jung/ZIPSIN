# DEC-024: 집신 계정 생성 시 실제 휴대폰 인증과 SOLAPI 사용

- 날짜: 2026-10-14
- 상태: 제안 · 서면 명세 사용자 검토 대기
- 결정 책임자: 사용자
- 대체 대상: `DEC-023`의 집신체크 SMS 생략 부분

## 제안 결정

집신체크는 로그인 없이 계속 사용할 수 있다. 다만 집신 계정을 만들고 서버 저장을 선택하면 일반 가입과 동일하게 실제 휴대폰 인증을 완료해야 한다. 문자 전송은 SOLAPI를 사용하고 OTP 생성·검증·만료·소비는 집신 서버와 DB에서 처리한다.

## 근거

- 사용자는 고객 확보의 결과물이 실제 집신 회원이어야 하며 휴대폰 인증과 휴대폰 계정 찾기를 요구했다.
- 현재 `DEC-023`은 문자 공급자가 없어서 가입 차단을 피하기 위한 임시 결정이었다.
- SOLAPI는 월 기본료·API 사용료 없이 단문 SMS를 건당 과금하고 국내 발신번호 등록 절차를 제공한다.
- 기존 Supabase Auth와 아이디 계정 구조를 유지한 채 현재 provider 경계에 전송 어댑터만 추가할 수 있다.

## 비용·운영 영향

- 2026-10-14 공식 표준 단가: SMS 1건 18원, VAT 별도.
- 재발송·실패·공격 트래픽도 비용이 될 수 있어 사용자·번호·요청 출처별 제한과 일일 예산 경보가 필요하다.
- 발신번호 등록, SOLAPI API 비밀값, 개인정보 처리위탁 고지가 필요하다.

## 안전 조건

- SMS 인증은 번호 소지 확인이며 법적 본인확인·소유권·집 접근 권한이 아니다.
- 실제 공급자 장애 때 인증을 우회하지 않는다.
- 인증 전에는 계정 찾기에서 아이디·이메일·계정 존재를 노출하지 않는다.
- production mock은 금지한다.
- 기존 사용자·번호·아이디를 자동 삭제하거나 병합하지 않는다.

## 롤백

실제 발송과 휴대폰 복구 진입은 서버 기능 플래그로 닫을 수 있다. DB 변경은 additive로 유지하고 사용자 데이터는 삭제하지 않는다. 가입 필수 정책을 되돌리려면 별도 사용자 승인과 결정 기록을 남긴다.

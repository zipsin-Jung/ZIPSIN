# DEC-022 공개 교육 이미지와 비공개 집 이미지 분리

- 날짜: 2026-10-14
- 상태: 사용자 승인, 구현 진행

## 결정

공개 홈페이지의 생활 장면 이미지는 제품 이해를 돕는 교육용 자산으로만 사용한다. 로그인 후 실제 집 화면에는 교육 이미지나 임의의 주거 사진을 붙이지 않는다. 실제 집 사진은 권한과 자료 유형을 서버에서 확인한 뒤에만 표시하며, 그 기반이 검증되기 전에는 중립적인 사진 없음 상태를 사용한다.

## 이유

- 교육 이미지를 실제 집 사진처럼 보이면 사용자가 가짜 데이터로 오인한다.
- 계약서·연락처·얼굴·계좌 자료가 대표사진으로 노출될 수 있다.
- 공개 정적 이미지와 비공개 signed URL의 보안·수명·캐시 정책이 다르다.

## 결과

- 공개 장면은 `public/images/public-home/`에 저장한다.
- 실제 집 카드는 교육 이미지를 참조하지 않는다.
- 자동 대표사진 선정, 얼굴 판별과 크롭 편집은 후속 결정으로 남긴다.

# DEC-029 임대인 승인과 기록 열람 범위

- 결정일: 2026-10-16
- 상태: 사용자 승인 (기획 단계, 코드 미반영)
- 근거 회의: `meetings/2026-10-08-house-key-replanning-kickoff.md`, `meetings/2026-10-16-product-replan.md`
- 관련: DEC-002, DEC-013(혼합 권한 모델, 승인 대기), DEC-016, DEC-017

## 결정

1. **집 이력은 임대인 승인을 받은 사무소만 보고 업데이트한다.** 같은 집을 여러 사무소가 등록해도 기록은 합쳐지거나 보이지 않는다.
2. **임대인 승인 = 신원 → 관계 → 공유 범위 3단계.** 관계 확인의 근거는 **중개사의 확인 체크**(A안): 승인 요청 시 중개사가 "등기부상 소유자와 본인을 확인함"에 체크하고, 체크한 사람·시각을 기록한다. 임대인은 48시간·1회용 문자 링크 → 휴대폰 문자 인증 → 공유 범위 미리보기 → 승인/거절. 언제든 철회 가능.
3. **임대인이 사무소를 바꾸면** 예전 사무소는 자기가 쓴 기록만 보고 새 기록은 못 본다.
4. **계약이 끝난 임차인**은 본인이 올린 사진·기록과 본인 계약서를 언제든 열람한다(본인 개인정보). 계약 뒤 새 기록·다른 사람 기록은 보지 못한다.
5. 기록은 세 칸: 사무소 내부 / 이번 계약 공유 / 집 이력(개인정보 제외).

## 하지 않는 것 (첫 버전)

- 휴대폰 인증을 "소유자 인증"으로 표시
- 등기부 업로드·대조, 공동소유·법인·대리인 승인 (후속)
- 주소로 기존 기록 존재 여부 노출

## 남은 위험

- 중개사의 잘못된 체크 → 체크 이력 보존, 임대인 철회로 대응
- 계약 종료 후 임차인 열람 기간의 법적 기준은 법률 자문 회신 후 재확인

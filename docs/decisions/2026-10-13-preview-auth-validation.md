# 결정: Preview 인증 검수와 Production 분리

- 날짜: 2026-10-13
- 상태: 적용, Production 미적용

## 결정

Preview에서 제품 흐름을 검수하기 위해 현재 브랜치 전용 Supabase 공개키·서버키·요청 제한 비밀값을 사용하고, 이메일 확인은 Preview 프로젝트에서만 비활성화했습니다.

## 이유

Supabase 기본 이메일 발송 한도로 가상 계정 검수가 중단됐습니다. Production 보안을 낮추지 않으면서 사무소·집·기록·채팅·초대·권한 종료를 실제 데이터 왕복으로 확인해야 했습니다.

## Production 전 조건

전용 이메일 발송, 실제 문자 공급자, OAuth 공급자를 연결하고 이메일 확인 정책을 다시 확정합니다. 비밀값은 Git과 문서에 저장하지 않습니다.

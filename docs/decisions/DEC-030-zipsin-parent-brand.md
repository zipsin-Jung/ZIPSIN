# DEC-030 집신이 대표 브랜드, 하위 서비스는 메뉴로만 연결

- 결정일: 2026-10-18
- 상태: 사용자 결정
- 결정한 사람: 대표(정민선)
- 대체하는 내용: DEC-022(`zipsin-check-signup-acquisition-first`) 중 "집신체크를 집신 가입의 앞문으로 쓴다"는 부분

## 결정

1. **집신(zipsin.net)이 대표 서비스**다. 집신체크(ck.zipsin.net, 임차인용)·집신수리·집신클린은 집신 아래의 서비스다.
2. 집신 화면의 시작 버튼을 하위 서비스로 대신 보내지 않는다. 회원가입이 열리기 전에는 `집신 시작하기 · 준비 중`으로 둔다.
3. 하위 서비스는 집신 위쪽 메뉴에서만 연결한다(예: 메뉴 `집신체크` → ck.zipsin.net). 이 연결은 유지한다.
4. 공인중개사용 화면은 `집신중개` 같은 별도 앱으로 나누지 않고 집신 안의 사무소 화면으로 만든다. 영업 자료에서는 "집신 · 중개사무소용"처럼 부를 수 있다.

## 배경

- 2026-10-17 준비 중 모드를 만들 때 Claude가 요청 없이 첫 화면 버튼을 `집신체크 바로 쓰기`로 바꿨다. 대표가 "전혀 다른 플랫폼"이라고 바로잡았다.
- 2026-10-18 핫픽스(main 6d98238)로 운영 화면을 고쳤다.

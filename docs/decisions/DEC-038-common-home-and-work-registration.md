# DEC-038 모두 같은 홈, 거기서 일로 쓰기(공인중개사·수리기사·청소업체) 등록

- 결정일: 2026-10-18 17:41
- 상태: 대표 결정 · 시안(캔버스 "로그인 후 전체" ⓪줄) · 코드 없음
- 대표 말: "메인 홈에 모든 사람 같게 만들거고 거기서 나누자. 수리기사 청소업체 공인중개사 등록 하자"

## 결정

1. 로그인하면 **누구나 같은 홈**(내 집)으로 시작한다.
2. 홈의 "일로도 쓰고 있나요?"에서 **공인중개사 · 수리기사 · 청소업체**로 등록한다. 아이디는 하나 그대로.
3. 등록한 일은 위 이름(▾)에서 바꿔 쓴다. 예: 나 ↔ 공릉공인중개사사무소(직원 고르고 4자리, DEC-032).
4. 수리기사·청소업체는 집신수리·집신청소가 준비 중이므로 **등록만** 받고 일을 받는 기능이 없다고 화면에 적는다(지키지 못할 약속 금지).

## 남은 결정

- 수리기사·청소업체 등록에 필요한 것(사업자등록번호, 자격 등): 정해지지 않아 시안은 이름·지역·하는 일만.
- 등록 정보 저장(DB)과 집신수리·집신청소 사이트에서 쓰는 방식: 통합 로그인(한 계정)과 함께 설계.

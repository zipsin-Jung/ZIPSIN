# DEC-008 간편가입과 최소 개인정보 구조

- 날짜: 2026-10-02
- 상태: 사용자 승인
- 결정자: 사용자

## 결정

집신의 실제 회원가입은 카카오, 네이버, 구글 간편가입을 제공한다. 간편가입 이후 휴대전화번호를 별도로 인증하고 이름과 이메일을 확인한 뒤 필수 약관에 동의하면 가입이 완료된다.

## 가입 흐름

1. 카카오·네이버·구글 중 하나 선택
2. 휴대전화번호 인증
3. 이름과 이메일 확인·수정
4. 서비스 이용약관, 개인정보 수집·이용, 개인정보 처리방침 확인, 만 14세 이상 확인
5. 마케팅 문자와 이메일 수신은 각각 선택 동의
6. 가입 완료
7. 가입 후 역할과 첫 집 설정

## 필수·선택·후속 정보

| 구분 | 항목 |
|---|---|
| 가입 필수 | 소셜 제공자 식별자, 휴대전화 인증 결과, 이름 또는 표시 이름, 이메일, 필수 동의 버전과 시각 |
| 가입 선택 | 문자 마케팅 동의, 이메일 마케팅 동의 |
| 가입 후 | 사용자 역할, 활동 지역, 알림 설정, 프로필 사진, 이용 목적 |
| 해당 기능 사용 시 | 집 주소, 계약 관련 자료, 공인중개사 또는 사업자 확인 정보 |
| 가입 단계 제외 | 주민등록번호, 계좌번호, 계약서 원본, 소유권 증명서, 생년월일 전체, 성별 |

## 권한 원칙

- 사용자가 역할을 선택했다고 해당 역할의 업무 권한을 자동 부여하지 않는다.
- 공인중개사무소, 집, 계약과 연결되는 권한은 별도 확인 또는 초대를 거쳐 부여한다.
- 주소만으로 집 기록에 접근할 수 없다.
- 이전 계약자의 개인정보가 다음 계약자에게 자동으로 전달되지 않는다.

## 이유

- 세 로그인 제공사 사이의 제공 정보가 동일하지 않으므로 전화번호는 별도 인증한다.
- 가입 마찰과 개인정보 위험을 줄이기 위해 집 주소와 업무 증빙은 필요한 시점까지 받지 않는다.
- 마케팅 동의를 가입 필수 조건에서 분리한다.

## 구현 전 남은 결정

- 개인정보 수집 주체의 공식 명칭과 문의 이메일
- 개인정보 보유기간과 탈퇴·파기 기준
- 휴대전화 인증 서비스 업체
- 각 소셜 개발자 계정의 앱 등록과 승인
- 인증·데이터 저장 서비스의 운영 지역과 국외 이전·위탁 고지 내용

## 되돌림

필수 수집 항목은 이후 더 줄일 수 있다. 새로운 필수 개인정보를 추가하려면 목적, 고지, 동의와 영향 검토를 다시 수행한다.

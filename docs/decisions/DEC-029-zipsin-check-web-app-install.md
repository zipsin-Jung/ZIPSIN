# DEC-029 집신체크 앱 받기(웹앱 설치)

- 날짜: 2026-10-16
- 상태: 사용자 요청·시안 제공("집신과 똑같이") · 구현·로컬 검수 완료 · Preview 확인 대기
- 결정권자: 사용자
- 관련: DEC-025 공개 홈 웹앱 설치, DEC-026 ck.zipsin.net

## 결정

집신체크(`/ck`, `ck.zipsin.net`) 상단에 `앱 받기`를 둔다. 앱스토어 앱이 아니라 DEC-025와 같은 웹앱(PWA) 설치다.

- PC: QR과 세 단계 안내, `이 PC에 설치하기`(브라우저가 지원하면 실제 설치 요청, 아니면 주소창·메뉴 안내), `닫기`.
- 휴대폰: QR로 열린 `?install=1` 또는 버튼으로 `홈 화면에 집신체크 추가하기` 안내. 아이폰은 Safari 3단계, 갤럭시는 `집신체크 앱 설치하기` 버튼과 메뉴 안내. 기기를 알 수 없으면 둘 다 보여준다.
- 집신체크는 집신과 별도 앱(`id /ck`, `start_url /ck`, 이름 `집신체크`)으로 설치되고 계정은 같다.
- QR은 기기 안에서 만들며(`qrcode` 1.5.4) 외부 서비스로 주소를 보내지 않는다.

## 제한·후속

- 아이콘은 집신 아이콘을 함께 쓴다. 집신체크 전용 아이콘은 사용자 결정 후 교체.
- 오프라인·푸시는 포함하지 않는다(인터넷 필요 문구 유지).
- `zipsin.net`에서 집신 앱과 집신체크 앱을 둘 다 설치하면 범위가 겹친다. 운영 주소인 `ck.zipsin.net`에서는 문제없다.
- 집신 공개 홈의 기존 설치 안내는 바꾸지 않았다. 같은 시안으로 바꿀지는 사용자 결정.

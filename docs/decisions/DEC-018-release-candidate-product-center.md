# DEC-018 배포 직전 제품 중심과 홈페이지 사례 구조

- 결정일: 2026-10-13
- 상태: 사용자 지침 반영·명세 검토 대기

## 결정

집신 Release Candidate의 모든 화면과 기능은 `집에 관한 일의 반복·누락·단절 방지`를 판단 기준으로 삼는다. 공개 홈페이지는 긴 광고형 설명 대신 여섯 생활 사례를 좌우로 탐색하고, 선택한 사례에 해당하는 실제 집신 UI를 바로 보여준다.

공개 홈페이지, 로그인 후 제품과 모바일 내비게이션은 서로 다른 목적을 유지하되 같은 제품 구조와 언어를 사용한다. 수리, 공인중개사, 자산관리는 각각 일부 맥락일 뿐 제품 전체로 표현하지 않는다.

## 이유

기존 화면은 기능을 나열하거나 수리 사례를 반복해 집신이 무엇인지 한눈에 전달하지 못했다. 사용자는 에어컨 이력, 장기수선충당금 자료, 입주 전후 상태, 외부 계약 확인, 직원 변경, 퇴거 확인이라는 실제 순간에서 제품 필요성을 이해한다.

## 영향

- 공개 홈의 핵심 컴포넌트는 사례 선택기와 실제 제품 UI 증거가 된다.
- 전체 화면 이미지와 가짜 성과 수치, 가짜 다운로드는 사용하지 않는다.
- 모든 기능 변경은 어느 반복·누락·단절을 막는지 추적표에 기록한다.
- 별도 담당자 배정을 공식 사용자 흐름에 다시 넣지 않는다.

## 제외

- Production 배포
- 실결제
- 앱스토어 링크가 없는 다운로드 CTA
- PDF 자동 생성, OCR, AI 자동 분류
- 법적 효력을 보장하는 표현

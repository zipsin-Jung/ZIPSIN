# DEC-018 집신체크 현장 모드와 로컬 사진

- 날짜: 2026-10-13
- 상태: 사용자 승인 범위

## 결정

`/ck` 기본 화면을 현장 모드로 바꾸고 필수 입력 없이 한 번 눌러 시작한다. 핵심 9개에는 `괜찮음`, `확인 필요`, 짧은 메모와 선택 사진만 즉시 보여준다. 기존 이유·방법·근거와 추가 7개는 같은 기록을 사용하는 `꼼꼼히 보기`에 둔다.

사진은 계정이나 서버가 아닌 현재 브라우저의 IndexedDB에만 저장한다. 저장 전 재인코딩하여 원본 메타데이터를 제거하고 항목당 1장·후보당 6장으로 제한한다.

## 이유와 한계

남의 집을 보는 짧은 시간에 긴 입력과 설명은 이탈을 만든다. 한 손 즉시 기록은 현장 목적에 맞고, 같은 데이터의 꼼꼼한 표현을 남겨 기존 학습·비교 가치를 보존한다. 로컬 사진은 서버·권한 정책 없이 시작할 수 있지만 브라우저 데이터 삭제 시 복구되지 않고 다른 기기로 이동하지 않는다.

개별 사진은 민감정보가 찍혔을 때 사용자가 즉시 제거할 수 있도록 복구 불가 확인 후 삭제한다. 후보를 비교에서 제외하는 동작은 기록과 사진을 보존하며, 후보 전체 영구 삭제는 별도 데이터 정책 승인 전 제공하지 않는다. 저장 성공은 IndexedDB 트랜잭션 커밋 이후에만 표시하고 후보당 6장 제한도 같은 트랜잭션에서 검사한다.

## 제외

집신 계정 사진 백업, 기기 간 복원, 사진 공유, AI 분석, 원본 사진의 법적 증거 보장은 이번 범위가 아니다. 운영 배포도 별도 승인 대상이다.

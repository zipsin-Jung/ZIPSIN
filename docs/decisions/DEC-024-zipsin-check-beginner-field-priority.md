# DEC-024 집신체크 초보자 현장 우선순위

- 상태: 확정
- 날짜: 2026-10-14

## 결정

집을 처음 보는 사용자가 현장에서 짧게 쓸 수 있도록 전체 항목을 없애지 않되 `물·배수, 곰팡이·누수, 온수·난방`을 가장 먼저 보이는 3개로 고정한다. 물어볼 내용은 체크 도중 말을 걸었다가 흐름을 잃지 않도록 별도 탭과 명시적 우선순위로 제공한다.

## 이유

기존 목록은 `바닥 모서리`, `배관 주변`, `변기 흔들기`처럼 위치와 행동이 모호했고, 현장 확인과 질문이 섞여 있었다. 초보자는 무엇을 왜 보는지 모르는 상태이므로 설비 용어보다 실제 위치·행동·이상 신호가 필요하다.

## 영향

- 기존 후보 집과 답변 데이터는 삭제하지 않는다.
- 비교의 공통 핵심은 새 우선 3개로 바뀐다.
- 상세 체크와 질문 답변은 기존 답변 저장 구조를 재사용한다.
- 법률·하자 판정이 아닌 관찰 기록 도구라는 경계는 유지한다.

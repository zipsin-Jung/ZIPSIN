# DEC-025 집신체크 방문 요약 페이지 제거

## 상태

승인·적용 (2026-10-14)

## 배경

현장 체크를 마친 뒤 별도의 방문 요약 화면에서 `주의·미확인·전문가`를 다시 보여주는 흐름은 사용자가 이미 입력한 내용을 반복한다. 특히 `전문가`와 기호 중심의 결과는 사회초년생에게 다음 행동을 명확히 설명하지 못하고, 내가 본 집이나 비교 화면으로 가는 단계만 늘렸다.

## 결정

- 방문 요약 화면과 그 화면 전용 컴포넌트를 제거한다.
- 체크 완료 시 `저장하고 내가 본 집으로`를 제공하고 저장된 집 전체 목록으로 바로 이동한다.
- 후보 비교는 `내가 본 집`과 상단 `비교` 메뉴에서 계속 제공한다.
- 이전 브라우저 기록에 `summary` 상태가 남아 있으면 안전하게 `내가 본 집`으로 보낸다.
- 기존 체크·메모·사진·비교 데이터 구조는 바꾸지 않는다.

## 영향

- 한 단계가 줄어 현장 완료 흐름이 단순해진다.
- 사용자가 남긴 기록의 저장·복원 방식은 유지된다.
- 요약 계산 유틸리티는 비교와 향후 내부 계산의 호환성을 위해 즉시 제거하지 않지만 사용자 화면에는 노출하지 않는다.

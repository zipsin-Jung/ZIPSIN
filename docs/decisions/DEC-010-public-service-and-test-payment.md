# DEC-010 공개형 서비스와 테스트 결제 우선 개발

- 날짜: 2026-10-02
- 상태: 사용자 승인
- 결정자: 사용자

## 결정

집신의 최종 제품은 일부 사무소만 사용하는 비공개 도구가 아니라, 누구나 가입하고 자신의 권한 범위에서 사용할 수 있는 공개형 서비스로 만든다.

첫 구현은 `가입 → 역할 → 첫 집 → 기록 → 사진 → 캘린더 → 테스트 결제`를 하나의 세로 흐름으로 완성한다. 사업자 등록과 결제대행사 심사가 끝나기 전에는 실제 금액을 승인하거나 수납하지 않고 토스페이먼츠 테스트 환경만 사용한다.

## 이유

- 화면만 많은 데모보다 실제 계정과 기록 흐름을 먼저 검증할 수 있다.
- 사업자 등록 전에도 결제 기술 연동과 성공·취소·실패 처리를 안전하게 시험할 수 있다.
- 실제 결제 활성화를 코드 개발과 분리해 법률·PG 심사 준비가 끝난 시점에 통제할 수 있다.

## 영향

- 기존 정적 랜딩페이지는 유지하지만 앱 영역은 Next.js 서버 런타임으로 전환한다.
- 인증·데이터·비공개 파일 저장과 서버 권한 검사가 새로 필요하다.
- 공개 출시와 실결제 활성화는 서로 다른 승인 지점으로 관리한다.
- AI 챗봇, OCR, PDF와 수리기사 중개는 첫 구현에서 제외한다.

## 되돌림

테스트 결제 기능은 환경 설정으로 완전히 끌 수 있어야 한다. 공개 가입에 문제가 생기면 기존 랜딩페이지는 유지하고 앱 가입 진입만 비활성화한다.

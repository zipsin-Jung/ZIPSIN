# DEC-019 집신체크 비교 우선 V2

- 날짜: 2026-10-13
- 상태: 2026-10-13 사용자 승인

## 제안

집신체크 V2는 집별 요약 카드보다 동일 행 비교표를 중심으로 한다. 여러 집을 보관하고 그중 2~3채를 선택해 가격·생활조건·현장 5개·재연락 정보를 비교한다. 기존 v1 기록과 사진은 삭제하지 않고 새 v2 저장소로 비파괴 이전한다.

## 이유

사용자는 현장에서 긴 체크를 수행하기 어렵고, 방문 후 여러 집의 같은 조건을 기억에 의존해 비교한다. 서버 계정 이전보다 로컬 비교표를 먼저 검증하면 핵심 가치와 모바일 사용성을 더 작고 가역적으로 확인할 수 있다.

## 조건

- 주소·연락처는 현재 기기에만 저장하고 기본 비교표에서 전체 번호를 노출하지 않는다.
- 비교 제외와 영구 삭제를 분리한다.
- 행동 완료 체크와 집 상태 평가를 분리한다.
- 총점·순위·안전 판정을 만들지 않는다.

## 후속

로컬 비교 가치가 확인된 뒤 `ck.zipsin.net`, 집신 단일 로그인, 선택 기록 이전과 보존·삭제 정책을 별도 결정한다.

## 구현 결과

- V2 로컬 구현은 `/ck`에 완료했다.
- `집신에 저장하기`는 `zipsin.net` 가입 영역으로 이동하는 안내이며 아직 아이디·주소·사진을 서버에 연동하지 않는다.
- 실제 연동은 인증 방식, 이전 동의, 서버 저장, 취소·삭제 복구 정책을 포함한 별도 기능으로 다룬다.
- V1 항목 ID와 V2의 5개 ID가 다르므로, V1 원본은 유지하면서 대응표로 답·메모·사진을 읽는다. 이 대응은 이전 기록의 접근성을 위한 것이며 새 안전 판정을 만들지 않는다.

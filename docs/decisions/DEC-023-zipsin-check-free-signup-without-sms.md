# DEC-023: 집신체크 무료 가입은 SMS 없이 완료

- 상태: 사용자 승인, Preview 검수 대기
- 기준일: 2026-10-14

집신체크의 목적은 집을 보는 사회초년생이 즉시 기록하고 같은 집신 계정으로 다시 열도록 하는 것이다. 문자 공급자가 비활성인 상태에서 휴대전화 인증을 가입 필수 조건으로 두면 고객 확보라는 핵심 가치가 막힌다.

따라서 `/ck`에서 시작한 아이디·이메일 가입은 SMS를 거치지 않고 안전한 복귀 경로로 돌아간다. 이때 필수 약관 동의와 집신체크 유입 경로는 서버에 기록하며, 기록 실패 시 불완전 계정을 정리한다. 집신 본체의 계약·사무소·권한 기능은 기존 추가 온보딩을 유지한다. 실제 신원 확인을 계약 기능에 확대하려면 별도 승인과 전문 검토가 필요하다.

롤백은 집신체크 `next` 분기를 제거하고 기존 `/signup/verify`로 다시 연결하는 방식으로 한다.

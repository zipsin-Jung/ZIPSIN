# DEC-013 미션 5는 가상 수리 기록 CRUD로 분리한다

일자: 2026-10-08  
상태: 확정

## 결정

부트캠프 미션 5의 Supabase CRUD는 기존 랜딩·영업 데모와 분리한 `/records` 가상 수리 기록으로 구현한다. 실제 주소·연락처·계약서는 금지하고 인증·소유권·RLS 정책 완성 전에는 운영 기능으로 사용하지 않는다.

## 이유

- 집신의 `집 중심 기록`과 가장 직접 연결된다.
- 등록·목록·상세·수정·삭제와 이미지 업로드를 작은 범위로 보여 줄 수 있다.
- 사전가입 정보를 공개 CRUD로 만들면 개인정보 노출 위험이 커진다.

## 영향과 롤백

- Next.js 정적 export를 제거하고 Vercel 서버 런타임을 사용한다.
- 배포하면 인증 없는 공개 수정·삭제 한계가 있다.
- 롤백은 기능 커미을 되돌리고 Vercel을 이전 커밋으로 재배포하며, 평가용 Supabase 테이블·버킷을 비활성화하는 순서로 한다.

# DEC-015 집신 챗과 공식 고객지원

- 결정일: 2026-10-13
- 상태: 사용자 승인
- 대체 범위: `DEC-014`의 제한된 집별 채팅 범위

## 결정

집신은 개인·단체·집·사무소·수리·고객지원 대화를 제공하는 자체 메신저로 확장한다.

- 채팅 권한에 별도 담당자 개념을 사용하지 않는다.
- 집신 고객지원은 사용자별 공식 1:1 방이며 초기에는 집신 대표가 직접 답한다.
- 대표는 지원방 외의 사용자 대화를 열람할 수 없다.
- 첫 출시 사진은 사용자가 직접 올리고 집 기록 자동 저장은 후속이다.
- 향후 AI는 발신 주체를 분리하고 AI임을 명시한다.

## 이유

업무 대화를 개인 전화번호와 카카오톡에서 분리하면서 중개사·임대인·임차인·수리기사가 집신 안에서 직접 소통해야 한다. 공식 고객지원은 초기 고객의 문제를 대표가 바로 듣는 통로가 된다.

## 영향

메시지 저장뿐 아니라 초대, 차단, 신고, 공식계정 위조 방지, 운영자 접근 감사가 필수다. 기존 담당 배정 코드는 삭제하지 않지만 채팅 접근의 전제나 공식 출시 흐름으로 사용하지 않는다.

## 되돌리기

일반 채팅, 관계기반 채팅, 고객지원, 실시간 수신을 각각 기능 플래그로 끌 수 있어야 한다. 롤백 시 기존 메시지와 신고 기록을 삭제하지 않는다.

# DEC-021 계약 후부터 만기까지 안내하는 집 홈

- 날짜: 2026-10-13
- 상태: 승인 — 2026-10-13

## 결정 제안

집신의 로그인 홈은 기능 목록이 아니라 현재 집의 계약 만기와 다음 행동을 보여준다. 제품 흐름은 계약 보관, 입주 기록, 거주·관리, 만기·퇴거의 네 단계로 구성한다.

가입 후 임차인, 임대인, 공인중개사, 관리·기타의 네 입구를 제공하되 이는 안내 개인화용이다. 실제 접근은 사무소 역할, 집·계약·사건 관계, 초대, 기간과 범위로 결정한다.

## 권고 MVP

사용자가 사진·PDF·날짜를 직접 등록하고, 시스템은 현재 집·작성자·시간을 자동으로 채운다. 사용자가 저장과 공개 범위를 확인하면 집 홈과 시간선을 즉시 갱신한다.

계약서 OCR, AI 분류, 사진 자동 공개, PDF 자동 내보내기와 법적 증거 보장은 후속 범위로 둔다.

## 만기 상태

`퇴거/연장` 이분법 대신 다음 세 상태를 사용한다.

- 아직 결정 전
- 연장 생각 중
- 퇴거 준비

이 상태는 집신 안의 준비 순서를 정하기 위한 것이며 계약 변경이나 법적 통지가 아니다. 임대인과 임차인의 상태는 각각 보존한다.

## 주소록

휴대전화 주소록을 가져오지 않는다. `이 집 사람들`은 현재 유효한 집·계약·사무소·수리 사건 관계자만 보여주고 개인 연락처를 기본 노출하지 않는다.

## 이유

- 모든 자동화를 처음부터 넣으면 잘못된 집·공개범위로 사진이나 계약 자료가 노출될 위험이 크다.
- 직접 확인 뒤 즉시 반영하면 현재 출시 가능성과 이후 자동화에 필요한 정확한 기록을 모두 확보할 수 있다.
- 네 개의 쉬운 입구와 실제 권한을 분리하면 초보자도 시작하기 쉽고 기존 RLS 원칙을 지킬 수 있다.

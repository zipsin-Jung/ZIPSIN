# DEC-004: 바탕화면 문서함과 GitHub 이중 보관

- 날짜: 2026-09-30
- 상태: 확정

## 결정

- 집신의 기획, 결정, 대화와 작업 보고서를 바탕화면의 `코덱스랑/집신` 폴더에 지속해서 정리한다.
- 같은 문서를 GitHub 저장소의 `docs/`에도 보관한다.
- 저장소 문서는 변경 이력과 협업을 위한 기준본으로, 바탕화면 폴더는 사용자가 쉽게 열어보는 정리본으로 사용한다.
- 두 위치는 동일한 하위 폴더 구조를 유지한다.

## 이유

- 사용자가 대화와 기획 문서를 한곳에서 직접 확인할 수 있어야 한다.
- 로컬 폴더만 사용하면 변경 이력과 원격 백업이 없고, GitHub만 사용하면 일상적으로 찾아보기 불편할 수 있다.
- 두 위치를 함께 관리하면 접근성과 변경 이력을 모두 확보할 수 있다.

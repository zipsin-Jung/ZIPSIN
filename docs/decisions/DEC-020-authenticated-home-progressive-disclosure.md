# DEC-020 로그인 홈 공통 셸과 점진 공개

- 날짜: 2026-10-13
- 상태: 제안 — 사용자 승인 대기

## 제안

로그인 후 홈은 역할별 별도 앱이나 모든 기능이 펼쳐진 대시보드로 만들지 않는다. 모든 역할이 같은 집 중심 앱 셸을 사용하고, 실제 데이터 상태에 따라 `집 없음`, `집 있음·기록 적음`, `기록 쌓임`의 세 홈을 제공한다.

최상위 메뉴는 홈·집·할 일·채팅을 중심으로 제한한다. 계약·입주·수리·퇴거·문서는 선택한 집의 기록 종류와 탭으로 제공한다. 체크리스트는 24개 검사표가 아니라 실제 집 기록 6개를 준비하는 시작 안내로 사용한다.

## 이유

- 사용자의 직접 시안은 여러 집 관리와 체크 진행을 잘 보여주지만, 첫 화면에 메뉴와 빈 카드가 동시에 많다.
- 현재 구현은 대형 홍보 영역이 업무보다 앞서 로그인 홈의 목적과 맞지 않는다.
- 첫 사용자는 다음 행동 하나가 필요하고, 반복 사용자는 최근 집·기록·채팅·일정이 필요하다.
- 공통 셸은 공인중개사 전용 인상을 줄이고 역할별 중복 화면을 막는다.

## 이미지 정책

- 교육용 이미지 세 장은 `예시 장면`으로만 사용한다.
- 실제 집 카드에는 권한 확인된 실제 사진 또는 중립 표지만 사용한다.
- 교육 이미지, 실제 기록 이미지, 첨부 디자인 참고 이미지를 서로 혼용하지 않는다.

## 제외

- 집신 AI
- 관리비 계산
- 집 찾기·매물 비교
- 계약 전 24개 검사표
- 역할별 별도 홈
- 가짜 데이터와 가짜 완료율

## 영향

- 즉시: 상태별 화면과 데이터 기준 설계가 필요하다.
- 6개월: 교육 화면에서 업무 화면으로 자연스럽게 전환되고 메뉴 증가를 억제할 수 있다.
- 2년: 새 기능을 전역 메뉴가 아니라 집 내부 탭과 기록 종류로 확장할 수 있다.

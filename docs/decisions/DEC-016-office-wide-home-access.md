# DEC-016 사무소 전체 집 접근

- 결정일: 2026-10-13
- 상태: 사용자 승인
- 대체 범위: `DEC-013`의 집 담당 배정 의존

## 결정

활성 사무소 구성원은 별도의 집 담당 배정 없이 자기 사무소의 활성 집과 사무소 기록을 사용한다.

- 대표·소속공인중개사·중개보조원 모두 활성 사무소 소속을 집 접근의 근거로 사용한다.
- 다른 사무소의 집은 볼 수 없다.
- 사무소 소속이 종료되면 다음 요청부터 접근을 차단한다.
- 임대인·임차인은 현재 활성 계약 관계로만 해당 범위를 본다.
- `office_home_assignments`는 기존 이력으로 보존하지만 신규 조회·쓰기·화면 흐름에서 사용하지 않는다.

## 이유

집신의 기록은 개인 직원이 아니라 사무소·집·계약에 연결된다. 담당 배정을 필수 관문으로 두면 인수인계를 줄이려는 제품이 다시 개인에 종속된다.

## 보안·복구

주소·집 ID·계정 주 역할만으로는 접근할 수 없다. 후속 migration은 트랜잭션으로 적용하며, 운영 적용 전 백업·행 수·권한 교차 검증이 필요하다. 되돌릴 때도 이력을 삭제하지 않고 새 migration으로 권한 helper만 교체한다.

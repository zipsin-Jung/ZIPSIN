# DEC-007: 테스트 홈은 세 가지 기본 행동만 보여준다

- 날짜: 2026-10-02
- 상태: 사용자 방향 확인, 세부 화면 승인 대기

## 배경

첫 예시 화면은 담당자, 역할 전환, 업무 수치, 표와 여러 메뉴를 한 화면에 보여줬다. 사용자는 담당자가 왜 필요한지 이해하기 어렵고, 나이 든 사람을 포함한 누구나 바로 쓰기에는 너무 복잡하다고 지적했다.

## 결정

테스트 플랫폼 첫 화면에는 다음 세 가지 기본 행동만 크게 보여준다.

1. 내 집 보기
2. 새 기록 남기기
3. 진행 중인 일

담당자, 역할 전환, 상세 통계와 업무 표는 첫 화면에서 제외한다. 담당자 개념은 여러 직원이 있는 사무소의 내부 인수인계가 실제로 필요한지 검증한 뒤 별도 관리 화면에서만 후속 검토한다.

## 이유

- 사용자가 설명 없이 첫 행동을 고를 수 있다.
- 역할이 달라도 공통 언어로 이해할 수 있다.
- 큰 글자와 적은 선택지로 고령 사용자에게도 부담이 적다.
- 사무소 내부 구조보다 집과 기록이라는 제품 가치를 먼저 전달한다.

## 영향

- T-01 사무소 인수인계 중심 홈 구성은 재검토한다.
- 첫 사용성 검증은 세 기본 행동의 이해도와 완료율을 우선 측정한다.
- 담당자 기능 자체를 확정 삭제한 것은 아니다.

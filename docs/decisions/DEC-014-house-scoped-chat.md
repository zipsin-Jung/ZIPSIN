# DEC-014 집별 채팅을 유료 파일럿 필수 범위로 포함

- 결정일: 2026-10-13
- 상태: 사용자 승인

## 결정

집신의 채팅은 범용 메신저가 아니라 집과 현재 관계를 따르는 기록 기능으로 만든다.

- 집마다 `사무소 대화` 한 개를 둔다.
- 현재 계약마다 `함께 보는 대화` 한 개를 새로 만든다.
- 일대일 대화와 임의 단체방은 만들지 않는다.
- 관계 종료 즉시 다음 조회·전송·파일 열기를 차단한다.
- 이전 계약 대화는 다음 계약자에게 넘기지 않는다.
- 원문 수정·삭제 대신 새 정정 메시지를 남긴다.
- 앱 안 알림부터 제공하고 외부 알림은 후속 검증으로 미룬다.

## 이유

전화와 개인 카카오톡에 남은 업무는 담당 변경 때 끊긴다. 대화를 집·사무소·계약 관계에 연결하면 사진과 처리 과정이 집의 업무 기록으로 이어진다. 동시에 두 공간을 분리해야 사무소 내부 정보와 이전 계약자의 개인정보 노출을 막을 수 있다.

## 영향

기존 명세의 `실시간 채팅 제외`는 이 결정으로 대체한다. 단, 실시간 통신 자체를 저장의 필수 조건으로 만들지 않는다. 서버 저장과 재조회가 기본이며 실시간 갱신은 기능 플래그로 켤 수 있는 향상 기능이다.

## 되돌리기

문제 발생 시 `PILOT_CHAT_ENABLED=false`로 화면과 전송을 닫는다. 저장된 메시지와 파일은 삭제하지 않고 보존하며 기존 집·기록 기능은 계속 사용할 수 있어야 한다.

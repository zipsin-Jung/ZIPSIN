# DEC-013 사무소 우선 유료 파일럿

- 상태: 승인
- 결정일: 2026-10-13

## 결정

- 집신은 누구나 관계에 따라 참여하는 집 중심 기록 서비스다.
- 첫 결제 고객과 첫 구축 흐름은 공인중개사무소로 시작한다.
- 파일럿 가격은 사무소당 99,000원으로 검증한다.
- 파일럿 기간은 8주, 모집 기준은 첫 20개 사무소로 잡는다.
- 정식 출시 예정가는 249,000원으로 안내하되, 실제 판매 이력이 생기기 전에는 할인율이나 기존 정가처럼 표현하지 않는다.
- 파일럿 종료 후 자동 결제하지 않으며 정식 상품 전환은 별도 동의를 받는다.

## 제품 순서

로그인 → 사무소 만들기 → 구성원 초대·담당 배정 → 첫 집 등록 → 기록 작성 → 관계자 초대 순서로 구현한다.

집의 기록 접근은 주소가 아니라 활성 사무소 소속, 집 담당, 계약 참여 관계로 판단한다.

## 아직 결정하지 않은 것

- 249,000원의 과금 주기와 포함 집 수
- 파일럿 이후 구체적인 요금제 단계
- 실제 결제대행사와 자동 결제 방식

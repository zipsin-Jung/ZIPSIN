# DEC-005: 네 에이전트와 여섯 스킬 공식 적용

- 날짜: 2026-09-30
- 상태: 확정·사용자 승인

## 결정

집신의 모든 큰 작업에 다음 네 역할을 공식 운영 체계로 적용한다.

- 총괄비서
- 기획·디자인
- 설계·개발
- 검수·비판

다음 여섯 스킬을 작업 성격에 따라 적용한다.

- `zipsin-project-kickoff`
- `zipsin-product-spec`
- `zipsin-feature-delivery`
- `zipsin-quality-gate`
- `zipsin-decision-review`
- `zipsin-memory-sync`

## 승인된 원칙

- 큰 신규 작업은 네 역할의 최초 회의로 시작한다.
- 요구사항 ID와 수락기준 없이 개발하지 않는다.
- 기획, 설계·개발과 독립 검수를 분리한다.
- 사용자 승인 없이 영구 삭제하거나 최종 완료 처리하지 않는다.
- 중요한 작업 결과는 문서, 바탕화면 문서함과 GitHub에 함께 보존한다.

## 사용자 승인

사용자는 “이걸 잘 활용해서 이제 모든 작업을 잘 부탁해”라고 확인해 공식 적용을 승인했다.

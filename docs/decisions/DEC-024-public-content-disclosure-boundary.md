# DEC-024 공개 콘텐츠 정보 경계

- 결정일: 2026-10-19
- 상태: 확정

## 결정

집신의 공개 블로그는 고객이 문제를 알아차리도록 돕는 채널로 사용한다. 제품의 핵심 해결 구조, 데이터 연결 방식, 권한 설계, 상태 전환과 구체적인 업무 운영법은 공개하지 않는다.

## 공개하는 내용

- 공인중개사무소가 겪을 수 있는 일반적인 상황과 불편
- 문제를 알아차릴 수 있는 징후와 질문
- 개인정보가 없는 일반 사례와 확인된 공개 사실
- 현재 제품이 실제 접수·저장 단계가 아니라는 정확한 안내

## 공개하지 않는 내용

- 집신만의 데이터 구조와 연결 규칙
- 역할별 권한, 개인정보 분리와 보존 로직
- 상태·담당·다음 행동을 연결하는 구체적인 흐름
- 그대로 복제 가능한 완결형 체크리스트와 운영 설계
- 검증 전 기능, 가격, 성과와 고객 사례

## 이유

공개 콘텐츠가 제품의 차별점을 과도하게 설명하면 경쟁자가 핵심 아이디어를 낮은 비용으로 모방할 수 있다. 반대로 문제만 나열하고 가치가 없으면 독자가 읽을 이유가 없다. 따라서 공개 글은 독자가 자기 상황을 진단할 만큼은 유용하되, 해결 구조는 상담과 데모에서 제한적으로 설명한다.

## 영향

- 블로그 초안마다 `독자 가치`, `핵심 노출`, `기능 오해`를 함께 검수한다.
- 제품 구조를 설명해야 하는 글은 공개 발행하지 않고 영업 자료 또는 내부 문서로 전환한다.
- 이미 공개된 글은 삭제하지 않으며 별도 승인 없이 공개 범위를 변경하지 않는다.

# 공인중개사 영업용 3분 데모 명세

- 작성일: 2026-10-06
- 상태: **사용자 승인 · 구현·자동검사 완료 · 최종 사용자 승인 대기**
- 대상 경로: `/demo`

## 목표

공인중개사 대표가 휴대전화에서 3분 안에 다음 가치를 직접 확인하게 한다.

> 개인 휴대전화와 카카오톡에 흩어진 집 업무가 집별로 정리되고, 담당 보조원이 바뀌어도 완료한 일과 다음 행동이 이어진다.

이번 결과물은 영업 현장에서 보여 주는 클릭형 데모다. 실제 로그인, 저장, 전송, 초대, PDF 생성 또는 법적 효력이 있는 기록을 제공하지 않는다.

## 가상 사례

- 사무소: 집신 공인중개사무소
- 집: 역삼동 다가구 201호(가상 주소)
- 상황: 기존 임차인 퇴거 후 욕실 누수를 발견했고 광고 재등록 전에 수리가 필요하다.
- 담당 흐름: 기존 담당 박보조 → 새 담당 최보조
- 기록 흐름: 임대인 요청 → 현장 확인 → 수리 전 사진 → 기사 방문 → 완료 사진·영수증 확인 → 광고 가능
- 모든 이름, 주소, 사진과 문서는 가상 자료이며 실제 연락처·계좌·계약서를 사용하지 않는다.

## 3분 사용자 흐름

1. 대표 홈에서 오늘 할 일·답변 대기·기한 초과를 확인한다.
2. `역삼동 다가구 201호 · 누수 처리`를 선택한다.
3. 집 상세에서 현재 상태, 담당자, 타임라인과 다음 행동을 확인한다.
4. 사건 상세에서 처리 상태와 수리 전·후 기록 예시를 확인한다.
5. 담당자를 박보조에서 최보조로 변경한다.
6. 보조원 화면으로 전환해 같은 집의 완료된 일·답변 대기·다음 행동이 이어지는지 확인한다.
7. 시간순 기록 요약과 PDF 예시를 확인하고 데모를 마친다.

## 요구사항

### DEMO-001 데모 진입과 고지

- 역할: 대표 공인중개사
- 트리거: 랜딩페이지의 `공인중개사 3분 데모` 선택
- 기본 흐름: 데모 안내 → 가상 사무소 홈
- 상태: 정상, 초기화
- 개인정보: 실제 개인정보 입력을 받지 않는다.
- 수용 기준:
  - 첫 화면에서 10초 안에 관리 집·오늘 할 일·멈춘 업무를 찾을 수 있다.
  - 모든 주요 화면에 `가상 자료이며 저장·전송되지 않음`을 표시한다.

### DEMO-002 사무소 업무 우선순위

- 역할: 대표·보조원
- 트리거: 데모 홈 진입
- 기본 흐름: 오늘 할 일·답변 대기·기한 초과 → 멈춘 집 선택
- 상태: 정상, 초기화 후 복구
- 권한: 대표는 사무소 전체, 보조원은 배정 업무를 우선 표시한다.
- 수용 기준:
  - 대표와 보조원의 첫 화면 차이가 텍스트로 드러난다.
  - 한 번의 선택으로 집 상세에 진입한다.

### DEMO-003 집 중심 타임라인

- 역할: 대표·보조원
- 트리거: 멈춘 업무 선택
- 기본 흐름: 집 상태·담당자·사건·최근 기록·다음 행동 확인
- 개인정보: 이전 계약자의 연락처·개인 대화·계좌정보를 표시하지 않는다.
- 수용 기준:
  - 집, 사건, 담당자, 상태, 다음 행동과 일정이 하나의 맥락으로 보인다.
  - 수리가 집에서 발생하는 여러 사건 중 하나라는 문구를 표시한다.

### DEMO-004 사건 처리 상태

- 역할: 대표·보조원
- 트리거: 누수 사건 선택
- 기본 흐름: 접수 → 처리 중 → 완료
- 상태: 기본, 변경 성공, 초기화
- 수용 기준:
  - 상태에 따라 다음 행동이 바뀐다.
  - 완료 상태에 수리 후 사진과 영수증 예시가 연결된다.
  - 변화는 가상 데이터에만 반영됨을 즉시 알린다.

### DEMO-005 담당자 인수인계

- 역할: 대표, 새 보조원
- 트리거: 대표가 담당자 변경 선택
- 기본 흐름: 박보조 → 최보조 → 보조원 화면 전환
- 권한: 담당자 변경은 대표만 가능하다.
- 수용 기준:
  - 변경 전후 담당자가 분명히 보인다.
  - 새 보조원 화면에 완료된 일·답변 대기·최근 기록·다음 행동이 유지된다.
  - 기존 담당자의 접근 종료는 설명하되 실제 계정 변경처럼 표현하지 않는다.

### DEMO-006 기록 요약과 종료

- 역할: 대표
- 트리거: 핵심 흐름 완료
- 기본 흐름: 시간순 기록 요약 → PDF 미리보기 예시 → 상담 안내
- 개인정보: 개인정보와 계좌정보가 기본 제외되었음을 표시한다.
- 수용 기준:
  - PDF는 다운로드가 아닌 `미리보기 예시`로 표시한다.
  - 법적 증거 효력을 보장하지 않는다.
  - 실제 접수 채널 연결 전에는 상담 신청이 전송된 것처럼 표현하지 않는다.

## 최소 화면

## 검수 기준

- 320px·390px 모바일에서 가로 스크롤 없이 핵심 흐름을 완료한다.
- 주요 조작 영역은 최소 44×44px이며 색상만으로 상태를 구분하지 않는다.
- 키보드로 주요 기능에 접근하고 포커스를 확인할 수 있다.
- 새로고침과 초기화 후 최초 가상 상태로 복귀한다.
- 입력·클릭으로 실제 개인정보나 자료가 외부 전송되지 않는다.
- 기존 랜딩페이지와 현재 PhoneDemo 기능에 회귀가 없다.
- 빌드 성공과 실제 브라우저 클릭 검수 결과를 분리해 기록한다.
- 영업 검증 시 5명 중 4명 이상이 3분 안에 흐름을 완료하고, 집신을 `집별 기록과 사무소 업무 인계 서비스`로 설명하는 것을 목표로 한다.

# `test` 페이지 기능 정의표

## 문서 상태

- 상태: **초안 · 사용자 승인 대기**
- 대상 경로: `/test`
- 목적: 실제 서비스를 개발하기 전에 집신의 핵심 흐름과 역할별 차이를 가상 데이터로 확인하는 클릭형 기획 페이지
- 기준 자료: 참조 대화 `집신 웹앱 기획 설계 준비`, `docs/01~05`, `docs/BRIEF.txt`

## 페이지의 역할

`test` 페이지는 광고용 랜딩페이지도, 실제 접수 서비스도 아니다. 공인중개사무소가 도입하고 대표 공인중개사·보조원·임대인·임차인이 집을 중심으로 함께 일하는 방식을 화면으로 검증하는 공간이다.

페이지 상단에는 다음 안내를 항상 표시한다.

> 이 화면은 기능 확인용 데모입니다. 입력한 내용은 저장·전송되지 않으며 실제 접수나 계약 효력이 없습니다.

## 이번 검증의 핵심 질문

1. 사용자는 집신이 수리 중개가 아니라 **집의 기록과 업무를 잇는 서비스**임을 이해하는가?
2. 네 역할은 첫 화면에서 자신이 지금 해야 할 일을 바로 찾는가?
3. 집 → 계약 → 업무/사건 → 기록의 관계가 어렵지 않은가?
4. 담당자나 계약 참여자가 바뀌어도 기록은 이어지고 개인정보는 분리된다는 점이 보이는가?
5. 선택한 기록을 PDF로 정리한다는 결과물이 분명한가?

## 대표 사용자 흐름

### 흐름 T-01: 사무소 업무 인수인계

`대표 역할 선택 → 오늘의 업무 → 기한 초과 업무 선택 → 담당자 변경 → 보조원 역할로 전환 → 같은 집의 요약·최근 기록·다음 행동 확인`

성공 기준: 담당자가 바뀌어도 업무 기록이 개인 휴대전화가 아니라 사무소와 집에 남는다는 점을 이해한다.

### 흐름 T-02: 임차인의 집 사건 기록

`임차인 역할 선택 → 현재 집 → 새 업무/사건 → 사진·설명 추가 → 함께 처리하는 일 확인 → 진행 상태 확인 → PDF 미리보기`

성공 기준: 수리업체를 찾는 흐름이 아니라 상태를 알리고 관계자가 함께 처리하며 기록을 남기는 흐름으로 보인다.

### 흐름 T-03: 공실 현황 공유

`임대인 역할 선택 → 공실 집 → 중개용 현황 공유 → 공개 항목 미리보기 → 중개사 선택 → 공유 결과 확인`

성공 기준: 복잡한 사진별 권한 설정 없이 안전한 기본 공개 범위가 적용되고 개인정보가 자동 제외된다.

## 공통 화면 상태

모든 핵심 화면은 다음 상태를 빠뜨리지 않는다.

| 상태 | 표시 원칙 |
|---|---|
| 빈 상태 | 왜 비어 있는지와 가능한 다음 행동 한 가지를 안내 |
| 불러오는 중 | 중복 조작을 막고 진행 중임을 명확히 표시 |
| 성공 | 결과가 반영된 위치와 다음 행동을 함께 안내 |
| 오류 | 쉬운 원인 설명과 다시 시도·이전 화면 복귀 제공 |
| 권한 부족 | 볼 수 없는 이유와 권한 요청 방법 안내 |
| 참여 종료 | 과거 참여가 끝났음을 표시하고 입력 기능 비활성 |

## 접근성과 사용성 기준

- 모바일 320px부터 PC 1440px까지 핵심 기능을 사용할 수 있게 한다.
- 글자만으로 상태를 구분하며 색상만으로 의미를 전달하지 않는다.
- 주요 버튼의 누르기 영역은 최소 44×44px로 한다.
- 한 화면의 기본 행동은 하나를 우선한다.
- 주소·계약·권한 용어는 쉬운 설명을 함께 쓴다.
- 키보드 이동과 화면 읽기 프로그램용 이름을 제공한다.

## 포함하지 않는 범위

- 실제 로그인·휴대전화 본인 확인
- 데이터베이스 저장과 실제 개인정보 입력
- 실제 문자·알림·초대 발송
- 실제 파일 업로드·다운로드와 PDF 생성
- 수리기사 검색·견적 비교·결제·송금
- 법적 소유권 인증 또는 법적 효력 보장
- 실제 사전가입 접수

## 성공 측정 제안

- 역할 선택 후 첫 핵심 행동 시작까지 걸린 시간
- 대표 흐름 T-01~03의 완료율
- “집신은 어떤 서비스인가”를 올바르게 설명한 비율
- 권한·개인정보 공개 범위를 잘못 이해한 참여자 비율
- 흐름별 막힌 지점과 뒤로 가기 횟수

## 승인 전에 확인할 항목

1. `/test`를 우선 **클릭형 데모**로 만드는 방향이 맞는가?
2. 첫 검증 흐름은 T-01~03 중 무엇을 가장 앞에 둘 것인가?
3. 임대인의 공식 소유권 확인 수준과 계약 종료 후 열람 기간은 별도 정책 결정이 필요하다.

# 기능 정의

상세한 개발 전 검증용 화면과 수용 기준은 [`test` 페이지 기능 정의표](09-test-page-feature-definition.md)에서 관리한다. 이 페이지는 실제 접수나 저장 기능이 없는 클릭형 데모 초안이다.

실제 계정·데이터 저장·테스트 결제를 포함한 다음 개발 단계는 [`공개형 서비스 V1 제품 명세`](12-public-self-service-v1-spec.md)에서 관리한다. 클릭형 데모와 실제 서비스 기능을 혼동하지 않는다.

## 제품의 중심 기능

캘린더·사진첩·알림·채팅은 개별 기능이다. 집신의 중심 기능은 이 정보들을 집과 업무에 연결해 다음 질문에 답하는 것이다.

> 어느 집에서, 누가, 무엇을, 어디까지 했고, 다음에는 누가 무엇을 해야 하는가?

## 1. 중개사무소와 직원

- 대표 공인중개사가 사무소 계정을 만든다.
- 대표가 소속공인중개사 또는 중개보조원의 역할을 선택해 보안 초대 링크를 만든다.
- 초대 링크는 완전한 HTTPS 주소로 복사하거나 휴대전화 공유 메뉴를 통해 문자·카카오톡·이메일 등에 전달할 수 있다.
- 상대가 미가입자이면 가입·휴대전화 인증 뒤 원래 초대 화면으로 돌아오며, 유효한 초대를 수락하면 사무소에 즉시 합류한다.
- 활성 사무소 구성원은 별도 집 담당 배정 없이 자기 역할에서 허용된 사무소 집과 업무를 사용한다.
- 직원이 바뀌어도 사무소의 업무와 기록은 유지된다.
- 대표는 직원의 사무소 접근을 종료할 수 있다.

## 2. 집과 건물

- 주소와 동·호를 등록하면 시스템이 내부 집 ID를 자동 생성한다.
- 단독 호실과 다가구 건물 아래 여러 호실을 모두 표현한다.
- 사용자는 내부 집 ID를 직접 만들거나 기억하지 않는다.
- 같은 주소라는 이유만으로 기록 접근 권한을 부여하지 않는다.

## 3. 관계자 연결

- 권한 있는 공인중개사가 현재 활성 계약을 선택해 임대인 또는 임차인 초대 링크를 만든다.
- 생성된 초대 링크는 `링크 복사`와 기기 `공유하기`로 바로 전달하며, 상대는 로그인 또는 가입 후 원래 초대로 돌아와 수락한다.
- 유효한 초대 수락과 현재 계약 관계 생성은 한 작업으로 처리하고, 수락 직후 허용된 집과 대화를 보여준다.
- 수리기사는 수리 참여 범위와 종료 시간을 지정한 별도 초대로 연결한다.
- 초대 수락 전에는 사무소명·역할·공유 범위만 보이며 주소·계약서·연락처는 공개하지 않는다.
- 초대 링크는 48시간 동안 한 번만 사용할 수 있고 원문 토큰은 데이터베이스에 저장하지 않는다.
- 초대 토큰은 로그·분석 이벤트·외부 미리보기 메타데이터에도 남기지 않으며 초대 페이지는 안전한 Referrer-Policy를 사용한다.
- 계약 종료, 수리 참여 만료 또는 명시적 권한 종료 즉시 사람의 접근을 막는다.
- 관계가 끝나도 이미 남긴 집·계약·사무소 업무 기록은 삭제하지 않는다.

초기 임대인 확인은 법적 소유권 인증이 아니라 계약 관계자 확인으로 정의한다. 공식 소유권 확인은 후속 검토 사항이다.

## 4. 업무 진행판

- 업무 종류: 매물 의뢰, 광고 준비, 계약, 입주, 점검, 변경사항, 수리, 퇴거
- 업무별 담당자, 상태, 예정일, 다음 행동과 완료 여부를 저장한다.
- 대표 화면에는 오늘 할 일, 답변 대기, 기한 초과, 멈춰 있는 집을 보여준다.
- 미리 정의된 업무 흐름을 사용해 빈 화면에서 사용자가 모든 단계를 직접 만들지 않게 한다.

## 5. 사진첩

- 공간별: 방, 거실, 주방, 화장실, 외부 등
- 시점별: 광고, 계약 전, 입주 전, 입주 중, 퇴거 후
- 사건별: 수리 전, 수리 중, 수리 후 등
- 촬영 시각, 등록자, 설명과 관련 업무를 함께 저장한다.

## 6. 문서함

- 종이 계약서를 촬영해 집과 계약에 연결한다.
- 영수증, 확인 자료와 기타 문서를 사건에 첨부한다.
- 초기 MVP에서는 안전한 이미지·파일 저장을 우선한다.
- 글자 자동 인식과 계약정보 자동 추출은 후속 기능으로 검토한다.

## 7. 집 중심 채팅

- 대화는 일반 메신저 방이 아니라 집 또는 특정 사건에 연결된다.
- 사진, 문서, 일정, 영수증과 처리 상태를 대화 안에서 공유한다.
- 특정 메시지를 할 일로 전환할 수 있게 설계한다.
- 담당자가 바뀌어도 권한이 있는 새 담당자가 업무 맥락을 확인한다.

### 채팅 저장·읽음 기본 규칙

- 메시지는 방의 활성 참여자만 보내고 읽을 수 있다.
- 메시지는 앞뒤 공백을 정리한 뒤 최대 2,000자로 저장한다.
- 네트워크 재시도로 같은 메시지가 여러 번 요청되어도 한 건만 저장한다.
- 읽음 위치는 사용자별로 보존하며 이미 읽은 위치보다 뒤로 돌아가지 않는다.
- 알림에는 메시지 본문·이름·전화번호·이메일을 복사하지 않고 방과 메시지 식별자만 둔다.
- 실시간 연결이 끊겨도 저장된 최근 메시지를 다시 불러오는 방식을 기본으로 한다.

### 채팅방 종류와 참여 기준

| 방 | 참여 기준 |
|---|---|
| 개인 대화 | 같은 사무소 또는 현재 집 관계로 이미 연결된 두 사용자 |
| 단체 대화 | 방장이 기존 관계자 중 직접 초대한 사용자 |
| 집 대화 | 해당 집의 활성 현재 계약 관계자와 사무소 구성원 |
| 사무소 대화 | 해당 사무소의 활성 구성원 |
| 수리 대화 | 정확한 수리 참여자, 현재 계약의 임대인·임차인, 해당 사무소 구성원 |
| 집신 고객지원 | 사용자와 위조할 수 없는 집신 공식계정 |

모르는 전체 사용자를 검색하는 기능은 제공하지 않는다. 방 참여만으로 관계 권한을 우회할 수 없으며 사무소·계약·수리 관계가 끝나면 관계형 방 접근도 끝난다.

### 채팅 화면과 직접 첨부

- 채팅 목록은 마지막 메시지와 읽지 않은 수를 보여준다.
- 작성 중인 문장은 전송 실패·오프라인에도 현재 기기에 보관한다.
- 사진과 PDF는 메시지에 직접 첨부하며 파일당 20MB, 메시지당 10개로 제한한다.
- 채팅 첨부는 비공개 저장소에 두고 권한을 다시 확인한 5분 링크로만 연다.
- 채팅 사진은 첫 출시에서 집 기록에 자동 저장하지 않으며 화면에 이를 명확히 표시한다.
- 실시간 수신이 실패하면 저장된 마지막 메시지 뒤를 다시 조회한다.

### 채팅 안전과 집신 고객지원

- 개인 대화에서 차단하면 양쪽 모두 그 개인방에 즉시 접근할 수 없다.
- 신고는 신고자가 볼 수 있는 메시지만 가능하며 메시지 본문을 신고 테이블에 복사하지 않는다.
- 사용자마다 `집신 고객지원` 공식 1:1 방은 하나만 만든다.
- 초기 고객지원 답변 권한은 승인된 대표 한 명에게만 주며 일반 사용자 방 열람 권한은 주지 않는다.
- 공식 답변은 실제 답변 계정을 감사용으로 남기면서 화면에는 위조할 수 없는 `집신 고객지원 ✓`로 표시한다.
- 주민등록번호·계좌 비밀번호·인증번호·실제 계약서 원본을 보내지 말라는 경고를 항상 보여준다.
- 답변 대기·답변 완료·해결 상태와 사용자별 알림 끄기를 제공한다.

## 8. 캘린더

- 광고 사진 촬영, 방문, 계약, 입주, 퇴거, 수리기사 방문과 처리 기한을 관리한다.
- 사무소 전체 일정과 집별 일정을 연결한다.
- 일정 변경은 관련 참여자에게 알림으로 전달한다.

## 9. 알림

- 새 요청, 답변 필요, 담당자 지정, 일정 변경, 기한 임박과 완료를 알린다.
- 단순 활동 알림보다 사용자가 다음에 해야 할 행동을 우선 표시한다.
- 과도한 알림을 방지하기 위한 묶음 알림과 중요도 설정은 상세 설계가 필요하다.

### 정식 서비스 홈과 내비게이션

- 홈은 서비스 설명과 `집 등록 → 기록 → 대화`의 시작 순서를 짧게 보여준다.
- 기존 사용자는 실제 최근 집, 읽지 않은 메시지와 다음 할 일만 확인한다.
- 자료가 없을 때는 0이라는 가상 수치 대신 무엇을 하면 되는지 보여준다.
- 모바일 하단 메뉴는 `홈 · 집 · 추가 · 채팅 · 마이`로 고정하며 모두 실제 경로로 연결한다.
- 앱 화면에는 사전가입·데모·체험·담당자 중심 표현을 사용하지 않는다.

## 10. PDF 기록 생성

- 사용자가 선택한 사진, 문서, 대화 요약, 처리 상태와 영수증을 시간순으로 정리한다.
- 집·계약 기본정보, 등록자와 등록 시각을 포함한다.
- 개인정보와 계좌정보는 기본적으로 제외하고 필요할 때 명시적으로 포함한다.
- 법적 효력을 보장한다는 표현은 사용하지 않는다.

## 공유 공간 기본값

| 공간 | 기본 공개 대상 |
|---|---|
| 내 집 기록 | 임대인 또는 작성자 |
| 함께 처리하는 일 | 해당 사건 참여자 |
| 중개용 집 현황 | 임대인이 선택한 중개사무소 |
| 계약 기록 | 현재 계약의 권한 있는 관계자 |

사용자에게 사진마다 복잡한 공개 설정을 요구하지 않고, 기록을 올린 공간에 따라 기본 공개 범위가 결정되게 한다.

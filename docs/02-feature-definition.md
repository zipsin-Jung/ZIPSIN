# 기능 정의

상세한 개발 전 검증용 화면과 수용 기준은 [`test` 페이지 기능 정의표](09-test-page-feature-definition.md)에서 관리한다. 이 페이지는 실제 접수나 저장 기능이 없는 클릭형 데모 초안이다.

## 제품의 중심 기능

캘린더·사진첩·알림·채팅은 개별 기능이다. 집신의 중심 기능은 이 정보들을 집과 업무에 연결해 다음 질문에 답하는 것이다.

> 어느 집에서, 누가, 무엇을, 어디까지 했고, 다음에는 누가 무엇을 해야 하는가?

## 1. 중개사무소와 직원

- 대표 공인중개사가 사무소 계정을 만든다.
- 대표가 보조원을 초대하고 담당 집을 배정한다.
- 직원이 바뀌어도 사무소의 업무와 기록은 유지된다.
- 대표는 직원의 접근을 종료하고 담당 업무를 다른 직원에게 이전할 수 있다.

## 2. 집과 건물

- 주소와 동·호를 등록하면 시스템이 내부 집 ID를 자동 생성한다.
- 단독 호실과 다가구 건물 아래 여러 호실을 모두 표현한다.
- 사용자는 내부 집 ID를 직접 만들거나 기억하지 않는다.
- 같은 주소라는 이유만으로 기록 접근 권한을 부여하지 않는다.

## 3. 관계자 연결

- 공인중개사무소가 임대인 연락처로 참여 요청을 보낸다.
- 임대인은 휴대전화 본인 확인 후 집과 계약 정보를 확인한다.
- 계약 체결 후 임대인 또는 중개사무소가 임차인을 초대한다.
- 참여 종료 시 접근 권한을 종료하되 허용된 집 이력은 보존한다.

초기 임대인 확인은 법적 소유권 인증이 아니라 계약 관계자 확인으로 정의한다. 공식 소유권 확인은 후속 검토 사항이다.

## 4. 업무 진행판

- 업무 종류: 매물 의뢰, 광고 준비, 계약, 입주, 점검, 변경사항, 수리, 퇴거
- 업무별 담당자, 상태, 예정일, 다음 행동과 완료 여부를 저장한다.
- 대표 화면에는 오늘 할 일, 답변 대기, 기한 초과, 멈춰 있는 집을 보여준다.
- 미리 정의된 업무 흐름을 사용해 빈 화면에서 사용자가 모든 단계를 직접 만들지 않게 한다.

## 5. 사진첩

- 공간별: 방, 거실, 주방, 화장실, 외부 등
- 시점별: 광고, 계약 전, 입주 전, 입주 중, 퇴거 후
- 사건별: 수리 전, 수리 중, 수리 후 등
- 촬영 시각, 등록자, 설명과 관련 업무를 함께 저장한다.

## 6. 문서함

- 종이 계약서를 촬영해 집과 계약에 연결한다.
- 영수증, 확인 자료와 기타 문서를 사건에 첨부한다.
- 초기 MVP에서는 안전한 이미지·파일 저장을 우선한다.
- 글자 자동 인식과 계약정보 자동 추출은 후속 기능으로 검토한다.

## 7. 집 중심 채팅

- 대화는 일반 메신저 방이 아니라 집 또는 특정 사건에 연결된다.
- 사진, 문서, 일정, 영수증과 처리 상태를 대화 안에서 공유한다.
- 특정 메시지를 할 일로 전환할 수 있게 설계한다.
- 담당자가 바뀌어도 권한이 있는 새 담당자가 업무 맥락을 확인한다.

## 8. 캘린더

- 광고 사진 촬영, 방문, 계약, 입주, 퇴거, 수리기사 방문과 처리 기한을 관리한다.
- 사무소 전체 일정과 집별 일정을 연결한다.
- 일정 변경은 관련 참여자에게 알림으로 전달한다.

## 9. 알림

- 새 요청, 답변 필요, 담당자 지정, 일정 변경, 기한 임박과 완료를 알린다.
- 단순 활동 알림보다 사용자가 다음에 해야 할 행동을 우선 표시한다.
- 과도한 알림을 방지하기 위한 묶음 알림과 중요도 설정은 상세 설계가 필요하다.

## 10. PDF 기록 생성

- 사용자가 선택한 사진, 문서, 대화 요약, 처리 상태와 영수증을 시간순으로 정리한다.
- 집·계약 기본정보, 등록자와 등록 시각을 포함한다.
- 개인정보와 계좌정보는 기본적으로 제외하고 필요할 때 명시적으로 포함한다.
- 법적 효력을 보장한다는 표현은 사용하지 않는다.

## 공유 공간 기본값

| 공간 | 기본 공개 대상 |
|---|---|
| 내 집 기록 | 임대인 또는 작성자 |
| 함께 처리하는 일 | 해당 사건 참여자 |
| 중개용 집 현황 | 임대인이 선택한 중개사무소 |
| 계약 기록 | 현재 계약의 권한 있는 관계자 |

사용자에게 사진마다 복잡한 공개 설정을 요구하지 않고, 기록을 올린 공간에 따라 기본 공개 범위가 결정되게 한다.

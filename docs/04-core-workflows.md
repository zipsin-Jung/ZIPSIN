# 핵심 업무 흐름

## 흐름 H: 계약 중심 집 홈과 만기 준비

1. 사용자가 로그인하고 사용 목적을 선택한다. 목적 선택만으로 집 권한은 생기지 않는다.
2. 유효한 사무소 또는 계약 초대를 통해 볼 수 있는 집이 홈에 나타난다.
3. 집이 한 채면 집 이름·보호된 주소·계약 D-day·지금 할 일을 먼저 본다.
4. 집이 여러 채면 만기 임박→열린 일→최근 기록 순으로 오늘 확인할 집을 본다.
5. 권한 있는 대표·소속공인중개사는 계약 종류·시작일·만기일을 계약서와 대조해 입력한다.
6. 현재 계약의 임대인·임차인은 자기 계획을 `아직 결정 전·연장 생각 중·퇴거 준비` 중에서 고른다.
7. 임대인과 임차인의 선택은 각각 저장되며 서로 다르면 확인 필요 상태로 표시한다.
8. 집신은 실제 계약·문서·입주 사진·열린 일·퇴거 사진만 보고 최대 3개의 다음 행동을 제안한다.
9. 사용자는 같은 집 화면에서 새 기록, 집 대화, 이 집 사람들로 이동한다.
10. 계약 종료·퇴사·공유 철회가 발생하면 다음 요청부터 접근을 막고 기록은 보존한다.

이 흐름의 만기 선택은 법적 통지나 계약 변경이 아니다. 타인의 선택을 대신 입력하지 않는다.

## 흐름 0: 공개 가입부터 첫 기록과 테스트 결제

1. 사용자가 Google·카카오·네이버 중 하나로 간편가입을 시작한다.
2. 별도 휴대전화 인증과 필수 약관 동의를 완료한다.
3. 대표 공인중개사·보조원·임대인·임차인 중 주 역할을 선택한다.
4. 역할에 따라 첫 집을 만들거나 받은 초대를 확인한다.
5. 첫 집에 사진이 포함된 기록을 남긴다.
6. 기록과 연결된 일정을 캘린더에서 확인한다.
7. 요금제를 확인하고 실제 청구가 없는 테스트 결제를 진행한다.
8. 테스트 성공·취소·실패 상태를 확인한다.

역할 선택은 접근 권한 부여가 아니다. 주소만으로 기존 집 기록에 연결하지 않으며, 실결제는 사업자 등록과 PG 심사가 끝난 뒤 별도 승인으로 활성화한다.

## 흐름 0-A: 로그인 후 사무소 구성원 초대와 즉시 합류

1. 대표 공인중개사가 로그인하고 `사람 초대`를 연다.
2. 소속공인중개사 또는 중개보조원 역할을 선택한다.
3. 집신이 48시간 동안 한 번만 사용할 수 있는 완전한 HTTPS 초대 링크를 만든다.
4. 대표는 `링크 복사` 또는 기기 `공유하기`로 상대의 문자·카카오톡·이메일 등에 전달한다.
5. 상대가 미가입자이면 가입·휴대전화 인증 뒤 원래 초대 화면으로 돌아온다.
6. 상대는 사무소명·예정 역할·열리는 범위·종료 조건을 확인하고 수락한다.
7. 수락과 사무소 소속 생성이 원자적으로 처리되고, 별도 대기 없이 허용된 사무소 집과 대화가 홈에 나타난다.
8. 중개보조원에게 공인중개사 전용 행동은 열리지 않는다.
9. 소속이 종료되면 다음 요청부터 집·파일·채팅·직접 URL 접근이 차단된다.

## 흐름 A: 일반 매물 의뢰

1. 임대인 또는 임차인이 중개사무소에 전화해 매물을 의뢰한다.
2. 대표 또는 보조원이 주소와 최소 연락정보를 등록한다.
3. 집신이 집 공간과 `매물 의뢰` 업무를 생성한다.
4. 담당 보조원과 현장 확인 일정을 지정한다.
5. 임대인에게 집 연결 확인 요청을 보낸다.
6. 보조원이 현장을 방문해 공간별 광고 사진을 촬영한다.
7. 광고 등록과 문의 대응 상태를 기록한다.
8. 계약이 체결되면 계약서 촬영본을 저장한다.
9. 임차인을 초대하고 입주 전 상태를 기록한다.
10. 계약 기간 중 변경사항과 사건을 같은 집에 이어서 기록한다.

## 흐름 B: 다가구 건물 통합관리

1. 사무소가 건물과 각 호실을 등록한다.
2. 기존 사진과 계약 자료를 호실별로 정리한다.
3. 임대인을 건물 또는 해당 호실에 연결한다.
4. 현재 임차인을 계약별로 초대한다.
5. 각 호실의 현재 상태, 공실 여부와 변경사항을 확인한다.
6. 임차인이 변경사항이나 사건을 등록한다.
7. 담당 보조원이 다음 행동과 일정을 지정한다.
8. 임대인과 사무소가 처리 과정을 함께 확인한다.
9. 계약 또는 담당자가 바뀌어도 집 기록을 유지한다.

## 흐름 C: 집에서 사건 발생

1. 임차인 또는 관계자가 사진과 설명을 등록한다.
2. 집신이 해당 집에 사건 채팅과 기본 업무 단계를 만든다.
3. 담당 사무소와 임대인에게 알린다.
4. 담당자·다음 행동·예정일을 지정한다.
5. 수리 등 처리가 필요하면 전·중·후 사진을 저장한다.
6. 영수증과 비용 처리 내용을 첨부한다.
7. 관계자가 완료 상태를 확인한다.
8. 필요한 내용을 장기 집 이력으로 전환한다.
9. 선택한 기록을 PDF로 생성한다.

## 흐름 D: 보조원 인수인계

1. 대표가 퇴사 또는 변경 예정 보조원의 담당 집을 확인한다.
2. 진행 중, 답변 대기, 기한 초과 업무를 분류한다.
3. 새 보조원을 지정한다.
4. 새 보조원은 집별 요약, 최근 대화와 다음 행동을 확인한다.
5. 이전 보조원의 접근을 종료한다.
6. 업무 기록은 사무소와 집에 그대로 유지된다.

## 흐름 E: 공실 수리 현황을 여러 중개사에 공유

1. 임대인이 집의 공실 상태와 변경사항을 기록한다.
2. 수리 진행 상황과 공개할 사진을 선택한다.
3. `중개용 현황 공유`를 실행한다.
4. 선택한 여러 중개사무소가 같은 최신 현황을 확인한다.
5. 수리 상태가 갱신되면 공유 화면도 갱신된다.
6. 계약서, 임차인 개인정보, 내부 대화와 계좌정보는 공유하지 않는다.

## 흐름 F: 임대인·임차인·수리기사 초대와 종료

1. 권한 있는 공인중개사가 집의 `함께하는 사람` 화면을 연다.
2. 임대인·임차인은 현재 활성 계약을 선택하고, 수리기사는 접근 종료 시간을 지정한다.
3. 집신이 48시간 동안 한 번만 쓸 수 있는 보안 초대 링크를 만든다.
4. 공인중개사는 `링크 복사` 또는 기기 `공유하기`로 문자·카카오톡·이메일 등에 전달한다.
5. 초대받은 사람이 미가입자이면 가입·휴대전화 인증 뒤 원래 초대로 돌아온다.
6. 상대는 사무소명·역할·공유 범위·종료 조건만 확인하고 수락한다.
7. 초대를 수락하면 현재 계약 또는 수리 참여 범위의 관계가 원자적으로 생성되고 허용된 집과 대화가 즉시 나타난다.
8. 이전 계약이 되었거나 수리 참여 시간이 끝나면 접근할 수 없다.
9. 본인 또는 권한 있는 공인중개사가 관계를 종료하면 접근이 즉시 끝난다.
10. 초대 생성·복사·수락·철회·만료·종료는 감사 기록으로 남고 집 업무 기록은 보존된다. 복사 기록에는 토큰 원문을 남기지 않는다.

## 흐름 G: 카카오톡으로 대표에게 빠르게 문의

1. 방문자 또는 로그인 사용자가 모든 화면 오른쪽 아래의 `카카오톡 문의`를 누른다.
2. 집신 화면은 유지되고 공식 카카오 채널 채팅이 새 창에서 열린다.
3. 초기에는 집신 대표가 직접 답변한다. AI·챗봇·24시간 상담으로 표시하지 않는다.
4. 카카오 문의는 집신 내부 기록에 자동 저장되지 않는다.
5. 계약·집·업무에 남겨야 할 상담은 집신 내부 `/support` 또는 해당 집 대화에서 이어간다.
6. 주민등록번호, 계좌 비밀번호, 인증번호와 실제 계약서 원본은 카카오로 보내지 않도록 안내한다.
7. 카카오 링크 접근은 집·계약·사무소 권한을 만들거나 변경하지 않는다.

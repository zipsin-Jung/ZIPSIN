# 핵심 업무 흐름

## 흐름 0: 공개 가입부터 첫 기록과 테스트 결제

1. 사용자가 Google·카카오·네이버 중 하나로 간편가입을 시작한다.
2. 별도 휴대전화 인증과 필수 약관 동의를 완료한다.
3. 대표 공인중개사·보조원·임대인·임차인 중 주 역할을 선택한다.
4. 역할에 따라 첫 집을 만들거나 받은 초대를 확인한다.
5. 첫 집에 사진이 포함된 기록을 남긴다.
6. 기록과 연결된 일정을 캘린더에서 확인한다.
7. 요금제를 확인하고 실제 청구가 없는 테스트 결제를 진행한다.
8. 테스트 성공·취소·실패 상태를 확인한다.

역할 선택은 접근 권한 부여가 아니다. 주소만으로 기존 집 기록에 연결하지 않으며, 실결제는 사업자 등록과 PG 심사가 끝난 뒤 별도 승인으로 활성화한다.

## 흐름 A: 일반 매물 의뢰

1. 임대인 또는 임차인이 중개사무소에 전화해 매물을 의뢰한다.
2. 대표 또는 보조원이 주소와 최소 연락정보를 등록한다.
3. 집신이 집 공간과 `매물 의뢰` 업무를 생성한다.
4. 담당 보조원과 현장 확인 일정을 지정한다.
5. 임대인에게 집 연결 확인 요청을 보낸다.
6. 보조원이 현장을 방문해 공간별 광고 사진을 촬영한다.
7. 광고 등록과 문의 대응 상태를 기록한다.
8. 계약이 체결되면 계약서 촬영본을 저장한다.
9. 임차인을 초대하고 입주 전 상태를 기록한다.
10. 계약 기간 중 변경사항과 사건을 같은 집에 이어서 기록한다.

## 흐름 B: 다가구 건물 통합관리

1. 사무소가 건물과 각 호실을 등록한다.
2. 기존 사진과 계약 자료를 호실별로 정리한다.
3. 임대인을 건물 또는 해당 호실에 연결한다.
4. 현재 임차인을 계약별로 초대한다.
5. 각 호실의 현재 상태, 공실 여부와 변경사항을 확인한다.
6. 임차인이 변경사항이나 사건을 등록한다.
7. 담당 보조원이 다음 행동과 일정을 지정한다.
8. 임대인과 사무소가 처리 과정을 함께 확인한다.
9. 계약 또는 담당자가 바뀌어도 집 기록을 유지한다.

## 흐름 C: 집에서 사건 발생

1. 임차인 또는 관계자가 사진과 설명을 등록한다.
2. 집신이 해당 집에 사건 채팅과 기본 업무 단계를 만든다.
3. 담당 사무소와 임대인에게 알린다.
4. 담당자·다음 행동·예정일을 지정한다.
5. 수리 등 처리가 필요하면 전·중·후 사진을 저장한다.
6. 영수증과 비용 처리 내용을 첨부한다.
7. 관계자가 완료 상태를 확인한다.
8. 필요한 내용을 장기 집 이력으로 전환한다.
9. 선택한 기록을 PDF로 생성한다.

## 흐름 D: 보조원 인수인계

1. 대표가 퇴사 또는 변경 예정 보조원의 담당 집을 확인한다.
2. 진행 중, 답변 대기, 기한 초과 업무를 분류한다.
3. 새 보조원을 지정한다.
4. 새 보조원은 집별 요약, 최근 대화와 다음 행동을 확인한다.
5. 이전 보조원의 접근을 종료한다.
6. 업무 기록은 사무소와 집에 그대로 유지된다.

## 흐름 E: 공실 수리 현황을 여러 중개사에 공유

1. 임대인이 집의 공실 상태와 변경사항을 기록한다.
2. 수리 진행 상황과 공개할 사진을 선택한다.
3. `중개용 현황 공유`를 실행한다.
4. 선택한 여러 중개사무소가 같은 최신 현황을 확인한다.
5. 수리 상태가 갱신되면 공유 화면도 갱신된다.
6. 계약서, 임차인 개인정보, 내부 대화와 계좌정보는 공유하지 않는다.

# 사용자와 접근 권한

## 기본 원칙

1. 주소만으로 기록을 볼 수 없다.
2. 집 기록은 특정 보조원이나 공인중개사 개인에게 속하지 않는다.
3. 집의 이력은 이어지되 사람의 개인정보는 다음 계약으로 자동 전달하지 않는다.
4. 사용자는 역할과 참여 기간에 필요한 정보만 본다.
5. 사진마다 권한을 설정하기보다 안전한 기본 공개 범위를 제공한다.

## 역할

### 임대인

- 집 연결 승인
- 중개사무소 추가·종료
- 공실 및 중개용 현황 공유
- 집 상태와 사건 기록 확인
- 공유 가능한 장기 집 이력 관리

### 임차인

- 현재 계약과 관련된 집 정보 확인
- 입주 상태와 변경사항 등록
- 사건 접수와 진행상황 확인
- 본인이 참여한 기록의 PDF 생성 요청

### 대표 공인중개사

- 사무소 계정과 보조원 관리
- 집·계약 공간 생성과 관계자 초대
- 담당자 지정·변경
- 사무소가 참여한 업무 기록 확인

### 보조원

- 배정된 집과 업무 처리
- 사진·문서·대화·일정 등록
- 관계자 연락과 진행 상태 갱신
- 권한 변경과 직원 관리는 제한

## 집과 계약의 관계

```text
건물 또는 집
├─ 장기 집 이력
├─ 계약 A
│  ├─ 임대인
│  ├─ 임차인 A
│  └─ 참여 중개사무소
└─ 계약 B
   ├─ 임대인
   ├─ 임차인 B
   └─ 참여 중개사무소
```

- 계약마다 참여자와 접근 범위를 새로 만든다.
- 이전 임차인의 이름, 연락처, 대화와 개인 자료는 다음 임차인에게 공개하지 않는다.
- 보일러 교체 등 집 자체에 남겨야 할 정보는 개인정보를 제거한 집 이력으로 전환할 수 있다.

## 중개사무소 변경

- 임대인이 기존 중개사무소의 참여를 종료할 수 있다.
- 새 중개사무소를 초대할 수 있다.
- 새 중개사에게는 임대인이 공유한 집 현황과 필요한 장기 이력만 제공한다.
- 기존 중개사무소의 내부 직원 메모와 다른 계약의 개인정보는 전달하지 않는다.

## 보조원 변경

- 기록은 개인 계정이 아니라 사무소와 집·업무에 연결한다.
- 대표 공인중개사가 담당자를 변경한다.
- 새 보조원은 완료된 일, 진행 중인 일, 다음 행동과 관련 대화를 확인한다.
- 퇴사한 보조원의 접근은 즉시 종료할 수 있어야 한다.

## 미결정 사항

- 임대인의 공식 소유권 확인 수준
- 집 매매 시 장기 집 이력의 이전 기준
- 계약 종료 후 임차인의 열람·다운로드 기간
- 공인중개사무소 폐업 시 보존 및 이전 절차
- 계좌정보의 저장 기간과 마스킹 정책

8A. 로그인 후 사람 초대와 즉시 합류
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

로그인한 대표 공인중개사는 사무소 구성원을, 권한 있는 공인중개사는 현재 계약의 임대인·임차인을 초대할 수 있어야 합니다.

초대 종류를 정확히 분리하세요.

- 사무소 초대: 소속공인중개사 또는 중개보조원이 사무소에 합류
- 집·계약 초대: 임대인 또는 임차인이 초대받은 현재 계약 공유 공간에 합류

필수 흐름:

로그인
→ `사람 초대` 선택
→ 소속공인중개사·중개보조원·임대인·임차인 중 역할 선택
→ 사무소 또는 현재 계약과 열람 범위 확인
→ 48시간 동안 한 번만 쓸 수 있는 보안 초대 링크 생성
→ 완전한 HTTPS 링크 표시
→ `링크 복사` 또는 `공유하기`로 문자·카카오톡·이메일 등 사용자가 선택한 앱에 전달
→ 상대가 링크 열기
→ 가입 사용자는 로그인, 미가입 사용자는 가입·휴대전화 인증
→ 원래 초대 화면으로 자동 복귀
→ 초대 역할·사무소명·공유 범위·종료 조건 확인
→ 수락
→ 원자적으로 관계 생성
→ 별도 대기 없이 허용된 사무소 또는 집·대화가 즉시 홈에 표시

공유 UX:

- 데스크톱에는 `링크 복사` 버튼과 복사 완료 상태를 제공합니다.
- 모바일에는 Web Share API 기반 `공유하기`를 우선하고 지원하지 않는 기기에서는 링크 복사로 대체합니다.
- 사용자가 연락처를 집신에 미리 저장하지 않아도 자기 메신저로 링크를 보낼 수 있어야 합니다.
- 외부 문자 자동 발송은 실제 SMS 공급자와 사용자 동의가 준비된 뒤에만 켭니다.
- 가짜 카카오톡 발송 성공이나 가짜 문자 발송 성공을 표시하지 않습니다.

보안·개인정보:

- 링크를 열기 전과 수락 전에는 정확한 주소·동호수·계약서·연락처·기존 기록을 노출하지 않습니다.
- 초대 화면에는 필요한 최소 정보인 사무소명, 예정 역할, 열릴 범위, 종료 조건만 표시합니다.
- 초대 토큰 원문은 DB에 저장하지 않고 로그·분석 이벤트·외부 미리보기 메타데이터에 남기지 않습니다.
- 초대 페이지는 민감한 URL이 다른 사이트에 전달되지 않도록 안전한 Referrer-Policy를 적용합니다.
- 링크는 만료·철회·일회성 소비를 서버와 DB에서 강제합니다.
- 이미 사용·만료·철회된 링크는 아무 자료도 열지 않고 상태와 새 초대 요청 방법만 보여줍니다.
- 초대 역할은 자격증이나 집 소유권을 인증하지 않습니다. 자격이 필요한 행동은 별도 검증 없이 열지 않습니다.
- 주소나 링크만 전달받았다는 이유로 초대 범위 밖의 기록을 열 수 없습니다.

초대 관리:

- 보낸 초대 목록에서 역할, 생성 시각, 만료 시각, 대기·수락·만료·철회 상태를 봅니다.
- 수락 전에는 초대를 철회하거나 새 링크를 다시 발급할 수 있습니다.
- 수락 후에는 링크가 아니라 실제 사무소 소속 또는 현재 계약 관계를 종료해야 접근이 끝납니다.
- 초대 생성·복사·수락·철회·만료·관계 종료를 감사 기록으로 남깁니다. 복사 이벤트에는 토큰 원문을 저장하지 않습니다.

수용 기준:

- 로그인하지 않은 사람이 링크를 열어 가입해도 초대가 사라지지 않고 수락 화면으로 돌아옵니다.
- 유효한 초대를 수락하면 새로고침 없이 허용된 공간이 홈과 내비게이션에 나타납니다.
- 같은 링크를 동시에 두 번 수락해도 관계는 한 건만 만들어집니다.
- 다른 계정, 다른 사무소, 다른 계약으로 토큰을 바꿔 사용할 수 없습니다.
- 임대인·임차인은 현재 계약 공유 공간만 보고 사무소 내부 기록을 보지 못합니다.
- 중개보조원은 사무소에 합류해도 공인중개사 전용 행동을 할 수 없습니다.
- 사무소 소속 또는 계약 관계를 종료하면 다음 요청부터 집·파일·채팅·직접 URL 접근이 차단됩니다.
- 320·390·768·1440px에서 링크 생성·복사·공유·수락을 키보드와 터치로 완료합니다.

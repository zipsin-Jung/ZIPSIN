나는 IT 창업 과정의 미션 제출용이면서, 실제 광고에도 사용할 수 있는
집신(ZIPSIN) 랜딩페이지를 만들려고 한다.

아래 요구사항을 기준으로 프로젝트 생성부터 구현, 검수까지 한 번에 진행해줘.

중요:
- 나는 개발 초보자다.
- 중간에 개발 용어를 길게 설명하거나 계속 질문하지 말고, 합리적인 부분은 알아서 결정해서 구현해줘.
- 단, 중요한 선택이나 내가 직접 해야 하는 계정 로그인/권한 연결이 필요한 경우만 마지막에 알려줘.
- 단순한 이미지 한 장을 웹페이지에 붙이는 방식은 금지한다.
- 모든 주요 영역을 실제 HTML/React 컴포넌트로 구현해야 한다.
- 최종 결과는 실제 클릭과 화면 전환이 가능한 웹사이트여야 한다.
- 디자인보다 먼저 작동 가능한 상태를 완성하고, 그 다음 첨부한 디자인을 최대한 비슷하게 반영해줘.
- 과도하게 복잡한 기능은 구현하지 말고 이번 미션 통과에 필요한 수준으로 완성해줘.

==================================================
1. 프로젝트 목적
==================================================

서비스명:
ZIPSIN / 집신

핵심 정의:
계약 전부터 입주, 거주, 수리, 관리, 퇴거까지 흩어진 집의 기록을
'집 한 채' 기준으로 연결하는 주거 기록 관리 서비스

핵심 메시지:
"사람이 바뀌어도, 집의 기록은 남습니다."

보조 설명:
계약서, 사진, 수리, 일정, 영수증 등 흩어진 기록을
집 한 채를 기준으로 한곳에 정리한다.

이 랜딩페이지의 목적:
1. 광고를 통해 실제 사용자를 유입한다.
2. 방문자가 집신 서비스를 빠르게 이해한다.
3. 첫 화면의 휴대폰 데모를 직접 눌러본다.
4. 자신의 역할에 맞는 집신 화면을 확인한다.
5. 요금제를 확인한다.
6. 최종적으로 '사전 회원 가입 하기'를 완료한다.

현재 목표:
사전 가입자 1,000명 모집

8. Hero의 클릭 가능한 휴대폰 데모
==================================================

PhoneDemo 컴포넌트로 구현한다.

전체 앱이나 DB를 만들 필요는 없다.

하지만 실제 앱처럼 버튼을 누르면
휴대폰 프레임 안에서 화면이 바뀌어야 한다.

최소 5개의 화면을 만든다.

화면 1. 홈

예시:

집신 로고

검색
"집 · 사람 · 기사 · 기록 검색"

집 카드:

연결된 집 128건

새 요청 12건
진행 7건
오늘 일정 2건

[우리집 보기]

자주 사용하는 기능:
- 계약문서
- 수리관리
- 연락처
- 일정관리

사진/동영상 또는 최근 기록 일부

하단 탭:
홈 / 기록 / + / 채팅 / 마이


화면 2. 우리집

예시:

월계동 아파트 1203호

현재 상태
전세

계약 만기
D-187

수리 요청 1건
예정 일정 1건
보증 관련 3건

최근 기록:
- 수도 수리 완료
- 욕실 사진 등록
- 계약서 등록


화면 3. 수리관리

예시:

욕실 누수

접수
→ 처리중
→ 완료

처리 완료일

시간순 타임라인 형태:

전환은 너무 화려하지 않고 빠르고 자연스럽게 한다.

==================================================
10. 해결 및 주요 기능 섹션
==================================================

제목:

집신은 모든 기록을
'집 한 채' 기준으로 모읍니다.

기능은 너무 많이 보여주지 않는다.

5개 정도면 충분하다.

1. 집 카드
계약, 임차인, 수리, 사진, 일정 등을 한눈에 확인

2. 수리 기록
접수부터 처리 완료까지 진행 과정 확인

3. 만기 D-DAY
계약 만기와 주요 일정 알림

4. 사진·수리 이력
입주/퇴거/하자/수리 전후 사진 기록

5. 문서 관리
계약서와 영수증을 집별로 정리

카드 클릭은 필수는 아니지만
hover 또는 간단한 반응 정도는 넣어도 된다.

11. 역할별 소개 섹션

제목:

당신의 역할에 맞는 집신을 만나보세요.

4개 선택 버튼:

- 공인중개사
- 임대인
- 임차인

공인중개사:
고객과 매물의 기록을 사무소에 남긴다.
연결된 집 / 새 요청 / 진행 / 오늘 일정 중심.

임대인:
여러 집의 계약과 수리를 한눈에 본다.
보유 집 / 진행 수리 / 이번 달 일정 중심.

임차인:
거주 중인 집의 요청부터 처리까지 확인한다.
만기 D-DAY / 수리 요청 / 일정 / 보증 관련 중심.

수리기사:
오늘 방문부터 작업 완료까지 관리한다.
오늘 방문 / 의뢰 목록 / 작업 사진 / 비용·영수증 중심.

첨부한 '집신 역할별 모바일 UI' 이미지를
디자인 참고자료로 적극 활용한다.

단순히 이미지 전체를 그대로 삽입하지 말고,
가능한 부분은 실제 UI 컴포넌트로 재현한다.

12. Z 포인트 섹션
==================================================

지금 단계에서는 너무 복잡하게 만들지 않는다.

제목:
집을 기록할수록, Z가 쌓입니다.

설명:
Z는 집신 안에서 사용하는 전용 포인트입니다.
가입, 기록, 추천 등의 활동을 통해 Z를 모으고
다양한 기능과 혜택에 사용할 수 있습니다.

카드 3개 정도:

- 가입 보상
- 활동 적립
- 기능 사용

중요:
구체적으로 몇 Z를 지급하는지,
AI 요약이 몇 Z인지,
PDF 리포트가 몇 Z인지 등은 아직 정하지 않았다.

따라서 숫자는 임의로 만들지 않는다.

Z를 현금이나 코인처럼 과하게 표현하지 않는다.

15. 폼 동작
==================================================

이번 미션에서는 아직 실제 DB 연결이 필수는 아니다.

따라서 우선 프론트엔드에서 정상 작동하도록 만든다.

- 이름 없으면 제출 불가
- 전화번호 없으면 제출 불가
- 사용자 유형 선택 필요
- 개인정보 동의 필요

정상 제출 시:

집신이 캐릭터와 함께

"사전 가입이 완료되었습니다.
집신 출시 소식을 가장 먼저 알려드릴게요."

라는 완료 상태를 보여준다.

중요:
페이지 전체 새로고침 없이 처리한다.

추후 미션6에서 Supabase 등 DB를 연결할 수 있도록

- 휴대폰 데모 오른쪽

Mobile:
- 텍스트
- CTA
- 휴대폰 데모
순서로 1열

모든 카드와 요금제도

==================================================
17. JavaScript / React 인터랙션
==================================================

최소 요구사항은 1개지만,
아래 인터랙션은 모두 구현한다.

1. Header 메뉴 → 섹션 smooth scroll
2. Hero CTA → 사전가입으로 이동
3. 휴대폰 UI 버튼 클릭 → PhoneDemo 내부 화면 전환
4. 역할 선택 → 역할별 설명/휴대폰 화면 변경
5. 요금제 선택 → 사전가입으로 이동 + 요금제 자동 선택
6. 회원가입 폼 → validation + 성공 상태
7. 모바일 메뉴 토글

과한 animation은 사용하지 않는다.

22. Figma 관련 미션 요구사항
==================================================

이번 과제에는
"Figma MCP를 활용해 미션4 디자인 시안을 구현 맥락으로 전달"

- 타이포그래피
- 여백
- 모서리
- 역할별 화면

Figma 전체를 다시 디자인할 필요는 없다.

현재 첨부된 랜딩 시안과
역할별 모바일 UI가 더 최신이면
최신 시안을 우선 적용하고,
Figma는 미션 요구 충족을 위한 구현 참고자료로 사용한다.

28. 작업 방식
==================================================

지금 바로 프로젝트 상태를 먼저 확인해줘.

프로젝트가 없다면
Next.js 프로젝트 생성부터 시작한다.

이미 프로젝트가 있다면
현재 구조를 확인한 후 위 요구사항에 맞게 수정한다.

구현 중 사소한 디자인 판단은
나에게 계속 질문하지 말고 알아서 가장 자연스러운 방향으로 진행한다.

완료 후에는 다음 4가지만 간단히 보고한다.

1. 무엇을 만들었는지
2. 어떤 인터랙션이 작동하는지
3. npm run build 성공 여부
4. 내가 GitHub/Vercel에서 해야 할 다음 행동

이제 구현을 시작해줘.

# 법률 자문 추가 질문 (2026-10-19) — 파트너 · 크레딧 · 동의 화면

회원가입 자문과 함께 보낼 질문. 대표가 그대로 붙여 넣어 보낼 수 있게 썼다.

## 1. 개인 파트너(사업자 없는 가사 도우미·개인 기사) 연결
- 손님 요청 글을 보여 주고 개인이 지원하는 게시판형으로 연결하며, 가격·일정·돈은 둘이 직접 정할 때 **유료직업소개사업 등록**이 필요한가요, 아니면 직업정보제공사업 신고로 충분한가요?
- 가사근로자법상 "인증 가사서비스 제공기관"과 관계가 생기나요?

## 2. 크레딧(확정할 때 차감)
- 손님이 상대를 확정할 때 **손님과 상대(개인·업체) 모두에게** 크레딧을 차감하려 합니다. 개인 파트너에게 차감하는 것이 직업안정법상 구직자에게 받는 금품 제한에 걸리나요?
- 미리 충전하는 크레딧의 환불·유효기간 기준, 전자금융거래법상 선불전자지급수단 등록이 필요한 규모는?

## 3. 사업자 파트너 서류
- 사업자등록증, 중개사무소 등록증, 공인중개사 자격증 사진을 받을 때 보관 기간과 열람 권한 기준은? 확인 뒤 사진을 지우고 "확인함" 기록만 남겨도 되나요?

## 4. 가입 동의 화면
- 항목별 동의(이용약관, 개인정보 수집·이용, 하위 서비스 간 공유, 위치 등)를 한 화면에 "모두 동의"와 함께 둘 때, **필수와 선택을 어떻게 나눠야** 하나요? 서비스에 꼭 필요하지 않은 항목(마케팅 등)은 선택으로 둬야 하는지.
- 집신 계정 하나로 집신체크·집신수리·집신청소를 쓸 때 동의를 가입 때 한 번만 받아도 되나요, 서비스 첫 이용 때 따로 받아야 하나요?
- 확정 뒤 상대에게 연락처를 공개하는 동의는 언제·어떻게 받아야 하나요?
